# 몬스터 시스템 설계

> 2D 탑다운 방치형 핵앤슬래시 (Unity, 싱글플레이) — 몬스터 원형 / 스탯 / AI / 스킬 / 스폰 / 보스
> 관련 문서: `맵시스템_설계.md`, `보상시스템_설계.md`, `스킬시스템_설계.md`
> **이 문서는 현재 구현 상태를 기술한다.** 컬럼·행 수는 실제 테이블 기준, 동작 서술은 `GamePlay/Unit/`·`GamePlay/Field/`·`Contents/Monster/` 구현 기준이다.

### 1.2 핵심 설계 원칙

> **"몬스터 원형"과 "어디에 몇 레벨로 나오는가"를 완전히 분리한다.**

```
Monster (원형)
  ├─ StatGroupID      → MonsterStat      (스탯 + 레벨 성장)
  ├─ SkillSetGroupID  → MonsterSkillSet  (보유 스킬 + 우선순위)
  ├─ AIType / AggroType / DetectRange / LeashRange   ★ 행동 파라미터를 직접 갖는다
  └─ RewardGroupID    → Reward           (고유 드랍)

MonsterSpawn (조합)
  └─ GroupID 단위로 MonsterID + Level + Count + RespawnTime + 지역 보상
       ↑
  씬 스폰 포인트(필드) / DungeonStage.MonsterSpawnGroupIDs(던전)
```

고블린 전사는 **1종**이고, 1-1에 Lv3으로 나오느냐 1-10에 Lv25로 나오느냐는 스폰이 결정한다.

지역별로 몬스터 ID를 복제하면(`고블린전사1-1` ~ `고블린전사1-10`) 액트 5개 × 필드 10개일 때 같은 몬스터가 50종이 되고 스탯 그룹도 50개가 된다. "고블린 계열 전체를 10% 약하게"가 50군데 수정 작업이 된다.

### 1.3 스폰 흐름 요약

| | 필드 | 던전 |
|---|---|---|
| 위치 | 씬의 `MonsterSpawnPoint` 마커 | 씬의 `DungeonSpawnSlot`(익명) |
| 구성 지정 | **마커가** `SpawnGroupId` 를 지정 | **테이블이** `MonsterSpawnGroupIDs` 로 지정 |
| 레벨 | `MonsterSpawn.Level` | `DungeonStage.MonsterLevel` 오버라이드 |
| 리젠 | **있다** — 개체 단위 | **없다** |
| 진행 | 무한 사냥 | 모드가 클리어를 판정 |

## 2. Enum

```
!Enum   MonsterType
        Normal          일반
        Elite           엘리트
        Boss            보스

!Enum   MonsterAIType
        Melee           근접
        Ranged          원거리
        Stationary      제자리
        Boss            보스 (페이즈 진행)

!Enum   AggroType
        Aggressive      선공 — DetectRange 안에 들어오면 먼저 공격
        Neutral         비선공 — 맞기 전까지 움직이지 않는다
```

`MonsterType` 은 **표시 규칙과 브레이크 부착 여부**를 결정한다.

| MonsterType | HP바 | 브레이크 게이지 | 보스 배너 |
|---|---|---|---|
| `Normal` | 간이 | ✕ | ✕ |
| `Elite` | 전용 바 | **○** | ✕ |
| `Boss` | 전용 바 | **○** | ○ |

> **브레이크 컴포넌트는 프리팹이 아니라 `MonsterPool.CreateItem` 이 등급을 보고 붙인다.** 프리팹마다 손으로 달면 등급이 바뀔 때마다 프리팹을 고쳐야 한다.

`Stat_BossDamageBonus` 는 `MonsterType = Boss` 인 대상에게만 적용된다 (`스킬시스템_설계.md` 10.1 [4]).

## 3. `Monster` — 원형 (14컬럼)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `ID` | `!int` | 기본 키 |
| `Name` | `!string` | 표시명 |
| `Desc` | `!string` | 설명 |
| `MonsterType` | `!MonsterType` | Normal / Elite / Boss |
| `PrefabPath` | `!string` | 프리팹 어드레서블 주소 |
| `StatGroupID` | `!int` | `MonsterStat.GroupID` 참조 |
| `AIType` | `!MonsterAIType` | 행동 패턴 |
| `AggroType` | `!AggroType` | 선공 / 비선공 |
| `DetectRange` | `!float` | 탐지 반경 |
| `LeashRange` | `!float` | 스폰 지점에서 이 거리를 넘으면 복귀 |
| `SkillSetGroupID` | `!int` | `MonsterSkillSet.GroupID` 참조 |
| `BaseExp` | `!int` | 처치 경험치 기준값 |
| `PerLevelExp` | `!int` | 레벨당 추가 경험치 |
| `RewardGroupID` | `!int` | **고유** 드랍 보상 그룹 |

> **AI 전용 테이블이 없다.** 과거 설계의 `MonsterAI` 테이블은 만들지 않았고, 행동 파라미터 4개(`AIType` / `AggroType` / `DetectRange` / `LeashRange`)를 `Monster` 가 직접 갖는다.
>
> 파라미터가 4개뿐이고 몬스터마다 다르게 두는 일이 드물어, 그룹 테이블로 분리하면 **참조 한 단계만 늘고 얻는 것이 없다.** 파라미터가 늘어나면 그때 분리한다.

**`LeashRange` 를 쓰는 이유** — 스폰 지점 고정 배치라 배회가 없다. 추격 제한과 복귀를 이 값 하나로 판정한다. 별도의 `PatrolRange` / `ReturnOnLeash` 는 두지 않는다.

**`KeepDistance` 를 두지 않는 이유** — 원거리 몬스터가 도망가면 잡기 힘들고 몬스터가 흩어져 광역 효율이 떨어진다.

### 3.1 현재 5종

| ID | 이름 | 등급 | AIType | AggroType | 스탯 그룹 | 스킬셋 | BaseExp |
|---|---|---|---|---|---|---|---|
| `10001` | 고블린 전사 | Normal | Melee | Aggressive | 101 | 1001 | 10 |
| `10002` | 고블린 궁수 | Normal | Ranged | Aggressive | 101 | 1002 | 10 |
| `10003` | 고블린 법사 | Normal | Ranged | Aggressive | 101 | 1003 | 15 |
| `20001` | 고블린 장군 | Elite | Melee | Neutral | 20001 | 2001 | 50 |
| `30001` | 악마 | Boss | Boss | Neutral | 30001 | 3000 | 100 |

**ID 대역** — `1xxxx` 일반 / `2xxxx` 엘리트 / `3xxxx` 보스.

## 4. `MonsterStat` — 스탯 + 레벨 성장 (5컬럼)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `ID` | `!int` | 일련번호 |
| `GroupID` | `!int` | 스탯 그룹 |
| `StatDetailID` | `!StatDetail` | 대상 스탯. 반드시 `_Base` 계열 |
| `BaseValue` | `!float` | **1레벨 기준값** |
| `PerLevel` | `!float` | 레벨당 증가량 |

성장식은 캐릭터와 동일하다 (`StatContainerFactory.ForMonster`).

```
기본값 = BaseValue + PerLevel × (Level - 1)
```

**여러 몬스터가 한 그룹을 공유할 수 있다.** 현재 일반 3종이 전부 그룹 `101` 을 쓴다.

### 4.1 필수 스탯

`Atk` / `AtkSpeed` / `MaxHp` / `Def` 의 `_Base` 는 **필수**다. 특히 `AtkSpeed` 가 없으면 공격 주기가 0으로 나뉘어 붕괴한다 (`기반테이블_설계.md` 4.1).

**현재 3그룹**

| 그룹 | 소유 | 행 구성 |
|---|---|---|
| `101` | 일반 3종 공용 | Atk(10/+2) · AtkSpeed(1) · CritRate(0.1) · CritDamage(1.5) · MaxHp(850/+10) · HpRegen(5/+1) · Def(5) · MoveSpeed(1) |
| `20001` | 엘리트 | 위 8종 + **MaxBreakGauge** (MaxHp 4500) |
| `30001` | 보스 | 위 8종 + **MaxBreakGauge** |

**엘리트·보스에는 `Stat_MaxBreakGauge_Base` 가 필수다.** 없으면 게이지 최대치가 0이라 브레이크가 동작하지 않는다.

## 5. `MonsterSkillSet` — 보유 스킬 (4컬럼)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `ID` | `!int` | 일련번호 |
| `GroupID` | `!int` | 스킬셋 그룹 |
| `Priority` | `!int` | **낮을수록 먼저 시도한다** |
| `SkillID` | `!Skill` | 보유 스킬 |

`Monster.SkillSetGroupID` 와 `BossMonsterPhase.SkillSetGroupID` 가 이 그룹을 지목한다.

### 5.1 사용 규칙

`SkillSelector` 가 **`Priority` 순으로 순회하며 사거리·쿨타임을 확인하고 첫 성공에서 멈춘다.** 전부 실패하면 평타로 폴백한다.

```
Priority 1  →  범위 안? 쿨 됐나?  →  시전하고 종료
Priority 2  →  ...
(전부 실패) →  평타 (SkillCategory = Normal)
```

- 평타는 **배열 순서가 아니라 `SkillCategory` 로 판정**한다 (`SkillContainer.GetBasicAttack`).
- 몬스터 AI의 정지 거리 기준은 **평타 사거리**다. 다른 스킬은 접근 도중에 이미 나가므로, 끝까지 붙는 기준이 되지 못한다.

> **`SkillUseCondition` / 조건 컬럼을 두지 않는다.** 보스는 페이즈로 스킬셋을 통째로 갈아끼우고 일반·엘리트는 쿨마다 쓰므로, 조건은 우선순위 하나로 충분하다.

### 5.2 현재 8그룹

| 그룹 | 소유 | 스킬 |
|---|---|---|
| `1001` | 고블린 전사 | 근접 공격 |
| `1002` | 고블린 궁수 | 원거리 공격 |
| `1003` | 고블린 법사 | 캐스팅 공격 |
| `2001` | 고블린 장군 | 오크장군 액티브 → 근접 공격 |
| `3000` | 악마 (기본) | 근접 → 액티브 → 캐스팅 → 전멸기 |
| `3001` | 악마 1페이즈 | 액티브 → 근접 |
| `3002` | 악마 2페이즈 | 캐스팅 → 액티브 → 근접 |
| `3003` | 악마 3페이즈 | 액티브 → 캐스팅 → 근접 |

## 6. `MonsterSpawn` — 스폰 조합 (7컬럼)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `ID` | `!int` | 일련번호 |
| `GroupID` | `!int` | 스폰 그룹 |
| `MonsterID` | `!int` | 무엇을 |
| `Level` | `!int` | 몇 레벨로 |
| `Count` | `!int` | 몇 마리 |
| `RespawnTime` | `!float` | 개체 리젠 대기(초). **필드 전용** |
| `RewardGroupID` | `!int` | **지역** 드랍 보상 그룹 |

**좌표 컬럼이 없다.** 위치는 씬 마커가 소유한다.

> **`Wave` / `SpawnRule` 컬럼을 두지 않는다.** 스폰 테이블은 "무엇을 어디에 얼마나"만 안다. 언제·어떤 순서로 낼지는 매니저(필드 스포너 / 던전 모드)가 결정한다.

### 6.1 스폰 포인트에 고유 ID를 두지 않는 이유

필드 스폰 포인트는 **씬이 테이블을 가리킨다**(`MonsterSpawnPoint.SpawnGroupId`). 반대 방향이면 재배치·복제 때마다 테이블 전체가 어긋난다.

이름을 키로 쓰는 것도 안 된다 — 유니티가 복제 시 이름을 자동 변경(`(1)` 접미)하는데, 깨져도 에러 없이 몬스터만 안 나온다.

### 6.2 현재 6그룹

| 그룹 | 용도 | 구성 |
|---|---|---|
| `1001` | 필드 | 전사 5 + 궁수 2 + 법사 1, 리젠 5초 |
| `2001` / `2002` / `2003` | 던전 웨이브 | 100 / 125 / 160마리, 리젠 없음 |
| `20001` | 엘리트 | 장군 1마리 Lv5 |
| `30001` | 보스 | 악마 1마리 Lv10 |

## 7. `BossMonsterPhase` — 보스 페이즈 (9컬럼)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `ID` | `!int` | 일련번호 |
| `MonsterID` | `!int` | 소속 보스 |
| `PhaseOrder` | `!int` | 페이즈 순서 (1부터) |
| `HpThreshold` | `!float` | 이 HP 비율 **이하**가 되면 진입 (0~1) |
| `SkillSetGroupID` | `!int` | 이 페이즈의 스킬셋 |
| `PhaseSkillID` | `!Skill` | **페이즈 전환 시 시전하는 전멸기** |
| `GimmickCount` | `!int` | 살포할 기믹 코어 개수 |
| `GimmickRequired` | `!int` | 파훼에 필요한 개수 |
| `GimmickRadius` | `!float` | 코어 살포 반경 |

### 7.1 페이즈 전환 시퀀스

```
HP 비율 ≤ HpThreshold
  ↓
보스 무적(BUFF_Invincible) + PhaseSkillID 긴 캐스팅 시작
  ↓
GimmickCount 개의 기믹 코어를 GimmickRadius 안에 살포
  ↓
제한시간 = 캐스팅 시간
  ├ GimmickRequired 개를 채움  → 캐스팅 차단 + 보스 강제 브레이크(기절)
  └ 실패                       → 전멸기 발동
  ↓
어느 쪽이든 SkillSetGroupID 를 교체하고 다음 페이즈로
```

- **파훼 보상은 강제 브레이크다.** 남은 게이지와 무관하게 0으로 만들고 `SE_Boss_Break_Stun_Buff`(10초 기절 + 받는 피해 증가)를 부여한다.
- 그 기절이 `BUFF_Invincible` 에 막히지 않도록 `BUFF_BreakStun` 은 `IgnoreImmune = TRUE` 다.
- 제한시간의 출처는 별도 컬럼이 아니라 **`PhaseSkillID` 의 캐스팅 시간**이다. 둘을 따로 두면 어긋난다.

### 7.2 현재 데이터

악마(`30001`) 3페이즈 — 100% / 70% / 30%. 1페이즈는 기믹 없이 스킬셋만 지정하고, 2·3페이즈가 코어 4개 중 2개 파훼다.

> **1페이즈의 `HpThreshold` 가 1.0이다.** 전투 시작과 동시에 진입하는 기본 페이즈라는 뜻이며 `PhaseSkillID` 가 비어 있다.

## 8. 브레이크 (무력화)

엘리트·보스 전용 게이지다. 일반 몬스터에는 컴포넌트 자체가 붙지 않는다.

```
최대치 = 대상의 Stat_MaxBreakGauge
피격   = 공격한 스킬의 Skill.BreakDamage 만큼 차감
0 도달 = BUFF_BreakStun 부여 (기절 + 받는 피해 증가)
진행 중 = 추가 BreakDamage 무시 + 게이지 회복
```

- **브레이크 중에 게이지가 깎이지 않는다.** 막지 않으면 회복분이 깎여 기절이 끝나기도 전에 다시 0이 된다.
- 유지시간은 코드 상수가 아니라 **효과 테이블**이 소유한다 — 일반 `SE_Monster_Break_Stun_Buff`(5초), 보스 파훼 `SE_Boss_Break_Stun_Buff`(10초).
- 엘리트는 머리 위 게이지 스프라이트를 갖고 보스는 전용 UI를 쓴다.

## 9. 스폰과 리젠

### 9.1 필드 — 개체 단위 리젠

`FieldMonsterSpawner` 가 **히어로가 있는 필드 하나만** 관리한다.

```
Count = 3 인 스폰 중 1마리만 죽으면
  → 그 1마리만 RespawnTime 뒤에 그 자리에 복귀
```

전멸을 기다렸다 한꺼번에 채우는 방식(`MaxAlive` 유지형)이 아니다. **지정된 자리에 뜨고 죽으면 그 자리에 리젠되는** 일반적인 방식이다.

### 9.2 리젠 시각은 로컬 전용이다

`MonsterRespawnClock` 이 `(mapId, pointIndex, rowIndex, unitIndex)` 키로 리젠 시각을 관리한다.

- **필드를 떠나도 시각은 계속 흐른다.** 돌아오면 그동안 지난 만큼 살아 있다.
- **저장하지 않고 서버로 보내지도 않는다.** 재접속하면 전 몬스터가 살아 있는 상태에서 시작한다.

> 이것은 **의도된 동작**이다. 싱글플레이라 남에게 영향이 없고, 리젠 시각을 서버에 보내는 비용 대비 얻는 것이 없다.

### 9.3 던전 — 리젠 없음

`SpawnGroupRunner` 가 스폰만 하고 죽은 몬스터는 돌아오지 않는다. 클리어 조건은 모드가 판정한다 (`맵시스템_설계.md` 10장).

## 10. AI

`AiBrainFactory` 가 `MonsterAIType` 으로 분기한다. `None` 이거나 대응 비헤이비어가 없으면 **근접으로 폴백**한다.

| AIType | 비헤이비어 | 동작 |
|---|---|---|
| `Melee` | `MonsterApproachBehavior` | 접근 → 평타 사거리에서 정지 |
| `Ranged` | `MonsterRangedBehavior` | 사거리 유지, 구덩이는 플로우필드로 우회 |
| `Stationary` | `MonsterStationaryBehavior` | 제자리에서 사거리 안만 공격 |
| `Boss` | `BossBehavior` + `BossPhaseRunner` | 페이즈 진행 |

- `AggroType = Neutral` 은 **맞기 전까지 움직이지 않는다.** 엘리트·보스가 이 값을 쓴다.
- 이동 정지는 AI가 `SkillContainer.IsInAction` 을 보고 처리한다. 히어로 조작감에는 영향을 주지 않는다.
- 유닛 이동은 `Physics2D` 를 쓰지 않는다. 통과 규칙은 **히어로 → 엘리트/보스 한 방향**만 허용하고, 장애물은 타일맵 셀로 판정한다.

## 11. 처치 보상

`MonsterKillReward` 가 사망 이벤트를 구독해 처리한다.

### 11.1 경험치

```
획득 경험치 = (BaseExp + PerLevelExp × (Level - 1)) × (1 + Stat_ExpBonus)
```

`Stat_ExpBonus` 는 **적 처치분에만** 곱한다. 퀘스트·던전 클리어 경험치는 고정값이다.

경험치는 `Account.AddExp` 로 들어가 **캐릭터와 현재 무기 마스터리에 동시 적립**된다 (`무기마스터리시스템_설계.md` 5.2).

### 11.2 드랍

**두 보상 그룹을 모두 굴린다.**

```
Monster.RewardGroupID       고유 드랍 — 이 몬스터라서 나오는 것
MonsterSpawn.RewardGroupID  지역 드랍 — 이 지역이라서 나오는 것
```

굴린 결과는 즉시 지급되지 않고 **바닥에 산포**된다. 히어로가 획득 범위에 들어와야 인벤토리에 들어간다 (`보상시스템_설계.md` 7장).

## 12. 참조 관계

```
Monster.ID              ←  MonsterSpawn.MonsterID
                        ←  BossMonsterPhase.MonsterID
                        ←  Quest.QuestParam (KillMonster)

Monster.SkillSetGroupID →  MonsterSkillSet.GroupID

MonsterSpawn.GroupID    ←  DungeonStage.MonsterSpawnGroupIDs[]
                        ←  씬의 MonsterSpawnPoint.SpawnGroupId
MonsterSpawn.RewardGroupID → Reward.GroupID

BossMonsterPhase.SkillSetGroupID → MonsterSkillSet.GroupID

MonsterStat.StatDetailID         → StatDetail.ID  (_Base 계열)
```

## 13. 검증 규칙

| # | 항목 | 분류 |
|---|---|---|
| 1 | `StatGroupID` / `SkillSetGroupID` 가 실존하는가 | 오류 |
| 2 | 스탯 그룹에 `Atk` / `AtkSpeed` / `MaxHp` / `Def` 의 `_Base` 가 모두 있는가 | 오류 |
| 3 | `MonsterStat.StatDetailID` 가 `_Base` 계열인가 | 오류 |
| 4 | `MonsterType` 이 Elite/Boss인데 `Stat_MaxBreakGauge_Base` 가 없는가 | 오류 |
| 5 | `MonsterSkillSet` 그룹 안에 `SkillCategory = Normal` 스킬이 하나 있는가 | 오류 (폴백 평타가 없다) |
| 6 | 같은 그룹 안에서 `Priority` 가 중복되는가 | 경고 |
| 7 | `MonsterSpawn.MonsterID` 가 실존하는가 | 오류 |
| 8 | `MonsterSpawn.Count` 가 0 이하 | 오류 |
| 9 | `BossMonsterPhase` 의 `HpThreshold` 가 `PhaseOrder` 순으로 감소하는가 | 오류 |
| 10 | `GimmickRequired > GimmickCount` | 오류 (파훼 불가) |
| 11 | `GimmickCount > 0` 인데 `PhaseSkillID` 가 비었음 | 오류 (막을 대상이 없다) |
| 12 | `PhaseSkillID` 의 `CastingType` 이 `Casting` 인가 | 오류 (제한시간이 캐스팅 시간이다) |
| 13 | `AIType = Boss` 인데 `BossMonsterPhase` 행이 없는가 | 오류 |
| 14 | `DetectRange > LeashRange` | 경고 (탐지했는데 바로 복귀한다) |
| 15 | 어느 스폰 그룹에도 없는 몬스터 | 경고 (죽은 데이터) |
| 16 | `Monster.PrefabPath` 가 비었거나 어드레서블에 없음 | 런타임 로드 실패 |

## 14. 미결 / 다음 작업

- **보상 그룹이 전부 비어 있다** — `Monster.RewardGroupID` 5행, `MonsterSpawn.RewardGroupID` 11행이 모두 0이다. **몬스터를 잡아도 아무것도 떨어지지 않으며**, 현재는 `DropManager` 의 임시 연출로 대체돼 있다 (`보상시스템_설계.md` 7장).
- **`PerLevelExp` 가 전부 0이다** — 레벨이 올라도 처치 경험치가 늘지 않는다.
- **몬스터가 5종뿐이다** — 퀘스트가 `10004` ~ `10006` 을 목표로 지정하고 있으나 그런 몬스터가 없다 (`퀘스트시스템_설계.md` 9장).
- **`Endless` / 레이드** — 대응 구조가 없다.
- **던전 슬롯 역할 구분** — 보스전에서 "보스 자리"와 "잡몹 자리"가 필요해지면 `DungeonSpawnSlot` 에 `SlotType` 을 추가한다. 현재는 전부 익명이다.
