# 마스터리 스킬 디자인

*무기 마스터리별 스킬 컨셉 · 구성 | 2D 탑다운 핵앤슬래시 · 싱글플레이 · Unity C#*

> **이 문서는 컨셉과 스킬 구성만 다룬다.** 확률·데미지·범위 크기·주기·지속시간 같은 **수치는 확정하지 않는다.** 밸런스 단계에서 바뀔 가능성이 높기 때문이다. 문서에 수치가 보이면 방향을 설명하는 `가안`이며, 테이블 작성 단계에서 다시 정한다.
>
> 기존 쌍검 스킬(콤보 액티브, 스파크 소환, 기존 18노드 트리)은 고려하지 않는다. 새 스킬 세트로 전면 교체한다는 전제다.

**목차**

1. 설계 전제
2. 쌍검 (DualBlades)
3. 룬검 (RuneSword)
4. 쌍권총 (DualPistols)
5. 구현 시 확인할 사항 (쌍검)
6. 미정 항목

## 1. 설계 전제

### 1.1 마스터리당 스킬 구성

| 구분 | 개수 | 비고 |
|---|---|---|
| 기본 공격 | 1 | 평타. 공속 배율을 받는 유일한 스킬 |
| 메인 스킬 | 6 | 스킬 트리의 습득 노드로 배운다 |

이후 단계에서 각 스킬에 강화 노드를 붙여 확장한다. 이 문서는 **어떤 스킬을 만들지**만 정한다.

### 1.2 마스터리 정체성

직업 개념이 없으므로 무기마다 전투 방식이 구분되어야 한다. 구분 축은 **범위 형태**다.

| 무기 | 범위 형태 | 보상 |
|---|---|---|
| 쌍검 | 부채꼴·직선 위주, 범위가 작다 | 범위가 좁은 대신 데미지를 높게 잡는다 |
| 룬검 | 원형·착탄 폭발 등 **범위기 위주** | 범위기에 강한 마스터리 |
| 쌍권총 | 중거리 단일 평타 + 특수탄 소범위 폭발·관통, 원형 난사, 추적 레이저 | 평타를 특수탄이 범위로 번지게 한다 |
| 다른 무기 | 원형 범위 위주 | ‒ |

### 1.3 발동 방식 용어

| 용어 | 시스템 대응 | 설명 |
|---|---|---|
| N타 적중 | `OnCombo` | 평타가 **실제로 적중**한 횟수. 스윙 1회 = 1카운트이고 여러 명을 맞춰도 1이다 |
| 온히트 시 확률 | `OnHit` | `SkillEffect.OnHitTrigger = TRUE` 인 효과가 **적중할 때** 확률로 발동. 온히트를 켜는 공격은 마스터리마다 정한다 |

쌍검과 룬검은 온히트를 켜는 공격이 평타뿐이라 "평타 적중 시"와 "온히트 시"가 같은 뜻이다. 쌍권총도 평타의 발만 온히트를 켠다 (4.4절).

### 1.4 공통 전제

| 전제 | 내용 |
|---|---|
| 치명타율·공속 | 모든 캐릭터가 **치명타율 100%** 와 **공격 속도 300%** 에 어렵지 않게 도달하도록 설계한다. 쌍검만 초각성으로 공속 상한이 350%다. 그래서 치명타율 증가 효과는 가치가 낮고 치명타 피해가 데미지 배율의 중심이 된다 |
| 이동 | 이동은 플레이어가 **직접 조작**한다. 스킬이 캐릭터를 강제로 이동시키지 않는다 |
| 추가 게이지 | 마스터리의 폭주 구간은 **공통 게이지 위젯**으로 보여 준다. 충전 기준만 마스터리마다 다르다: 쌍검은 평타 적중 횟수, 쌍권총은 쿨타임 진행도. 룬검 개방은 확률 발동이라 폭주 게이지가 없다 (검 개수는 별도 자원) |
| 폭주 구간 규칙 | 3개 마스터리의 6번은 모두 **가끔 오는 시간제 폭주 구간**이다. 지속 시간이 끝나면 반드시 휴식 구간이 있고, 상시 발동 수단은 두지 않는다. 마스터리마다 발동 방식이 다르다: 쌍검 = 평타 N번 타격, 룬검 = 온히트 시 확률(쿨타임 ≥ 지속), 쌍권총 = 쿨타임 + 전투 중 자동 발동 |
| 전투 중 상태 | **공용 시스템.** 피해를 주거나 받으면 전투 중이 되고, 마지막 전투 행동 후 10초(`가안`) 동안 없으면 해제된다. 1.5절 참고 |

### 1.5 전투 중 상태 (공용 시스템)

마스터리와 무관한 **공용 시스템**이다. 전투 중에만 처리할 항목은 이 시스템에 붙인다.

| 항목 | 내용 |
|---|---|
| 진입 | 피해를 **주거나 받으면** 전투 중이 된다 |
| 해제 | 마지막 전투 행동(주거나 받음) 이후 **10초**(`가안`) 동안 아무 일도 없으면 해제된다 |
| 갱신 | 전투 행동이 있을 때마다 해제 시한이 새로 시작된다 |

**전투 중에 처리하는 항목**

| 항목 | 내용 |
|---|---|
| 쌍권총 6번 이퀼리브리엄 | 쿨타임이 돌아와 있고 전투 중이면 자동 발동 (4.3절) |
| 추후 추가 | 전투 중에만 동작해야 하는 항목이 생기면 여기에 더한다 |

- 구현은 "마지막 전투 행동 시각"을 저장하고 지금 시각과 비교하는 방식이 단순하다. 매 프레임 카운터를 돌릴 필요가 없다.
- 시각 갱신은 피해를 주고받는 처리 지점에서 한다. 스킬 발동 경로(`OnDamaged` 등)와는 별개라 그 경로가 미연결이어도 영향이 없다.
- 해제 시간, 장시간 보스전 예외, 무적 같은 특수 상태에서의 처리는 `미정`이다.

## 2. 쌍검 (DualBlades)

### 2.1 컨셉

> **연타 + 보스 딜러**

- **연타**: 평타를 계속 적중시키는 것이 곧 스킬 발동 조건이다. 공속이 곧 딜이 된다.
- **보스 딜러**: 한 대상에게 공격이 몰리는 구조. 대상이 적을수록 처형이 한 대상에게 집중된다.
- 범위는 작게, 데미지는 높게. 광역은 다른 무기에 맡기고 쌍검은 좁고 깊게 간다.

### 2.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 범위 | 역할 |
|---|---|---|---|---|
| 기본 | 기본 공격 | 평타 | 전방 작은 부채꼴 | 카운트·확률 발동의 기점 |
| 1 | 일섬 | N타 적중 (짧은 주기) | 직선 | 빠르게 도는 직선 공격 |
| 2 | 난무 | N타 적중 (중간 주기) | 중간 원형 | 주변 정리 |
| 3 | 가속 | 온히트 시 확률 | 자신 (버프) | 공격력·회피 스택 버프 |
| 4 | 처형 | N타 적중 (긴 주기) | 원형 탐색 → 랜덤 다수 | 보스 집중 딜 |
| 5 | 공간참 | 온히트 시 낮은 확률 | 전방 큰 부채꼴 | 드물게 터지는 큰 한 방 |
| 6 | 초각성 | 게이지 (평타 N번 타격, 노드 2개) | 자신 | 활성 중 확률·카운트 2배, 공속 상한 확장 |

주기는 **일섬 < 난무 < 처형** 순으로 길어지고, 서로 겹치는 일이 드물게 한다. 구체적인 타수는 `미정`이다.

### 2.3 스킬 상세

#### 기본 공격

- 전방 **작은 부채꼴** 범위의 근접 단발 공격.
- 이 공격의 적중이 모든 카운트·확률 발동의 기점이다. 평타 효과만 온히트를 켠다.

#### 일섬

- 평타가 일정 횟수 적중할 때마다 발동한다 (가장 짧은 주기).
- **직선** 범위를 타격한다.

#### 난무

- 평타가 일정 횟수 적중할 때마다 발동한다 (중간 주기).
- **중간 크기 원형** 범위를 타격한다. 쌍검에서 유일한 원형 범위다.

#### 가속

- 온히트 시 **확률로** 자신에게 버프를 건다.
- 버프는 **짧게 지속되고 여러 번 중첩**된다. 스택마다 **공격력 증폭**과 **회피율**이 오른다.
- 연타 컨셉의 딜 증가와 보스전 생존을 한 스킬로 맡는다. 확정 회피는 없다. 기존 회피 규칙(확률 판정)을 그대로 쓴다.
- 지속시간·최대 중첩·스택당 수치는 `미정`이다. 처음 구상은 5초 · 3중첩 · 공격력 증폭 +5% · 회피율 +10%였다.

#### 처형

- 평타가 일정 횟수 적중할 때마다 발동한다 (가장 긴 주기).
- 동작 순서

```
1. 시전자 중심 원형 범위 안의 적을 탐색한다
2. 그중 여러 체를 랜덤으로 선정한다 (최대 수는 가안 5체)
3. 선정된 적의 위치마다 작은 원형 범위 데미지를 입힌다
```

- **대상이 최대 수보다 적으면 중첩한다.** 타격 횟수를 선정된 대상에게 돌려가며 배분한다. 예: 최대 5회에 대상이 1체면 5회 전부 그 대상에게 들어간다.
- 보스 1체와 싸울 때 모든 타격이 보스에게 들어가므로 **보스 딜러 컨셉의 핵심 스킬**이다. 잡몹이 많으면 분산된다.

#### 공간참

- 온히트 시 **낮은 확률**로 발동한다 (가안 5%).
- 전방 **큰 부채꼴** 범위를 타격한다. 쌍검에서 가장 넓고 가장 드문 공격이다.

#### 초각성

**평타 N번 타격으로 게이지를 채워 터뜨리는 시간제 폭주 구간**이며, **두 개의 노드**로 나뉜다. 각각 따로 습득한다.

```
채우는 중   평타가 적중할 때마다 게이지가 차오른다 (필요 타수 N은 미정)
발동        가득 차면 자동 발동. 게이지가 빛난다
종료        지속 시간이 끝나면 게이지가 0으로 줄어들고 다시 채운다
```

| 노드 | 효과 |
|---|---|
| 초각성 I | 게이지 완충 시 활성된다. **활성 중에만** 확률 발동 확률 **2배**, N타 적중 카운트 **2배** |
| 초각성 II | **활성 중에만** 공격 속도 상한 **+50%p** (300% → 350%). I을 먼저 배워야 한다 |

- **확률 2배**: 활성 중 공간참과 가속의 발동 확률이 모두 2배가 된다 (100% 상한).
- **카운트 2배**: 활성 중 평타 1회 적중에 콤보 카운터가 2 오른다. 이를 위해 **카운트 스킬의 주기는 항상 짝수로 둔다.** 수치를 바꿀 때도 지킬 규칙이다.
- **공속 상한**: 공속 자체를 올려 주지는 않고 상한만 늘린다. 활성이 끝나면 300%로 돌아온다. 상한 수치(300% → 350%)만은 정해진 값이다.
- **카운터가 두 종류다.** N타 스킬용 **콤보 카운터**(공유, 리셋 없음, 활성 중 2배)와 초각성용 **폭주 게이지**(리셋됨)다. 폭주 게이지는 **평타 적중 횟수 그대로** 세며 카운트 2배의 영향을 받지 않는다.
- **상시 발동은 하지 않는다.** 지속이 끝나면 게이지가 0에서 다시 시작하므로 휴식 구간이 항상 있다. 후반 성장은 N 감소와 지속 증가로 하되 휴식이 사라지지 않도록 N의 하한을 밸런스 규칙으로 둔다. N은 공속 300%가 표준이라는 전제(1.4절)에서 정한다.
- 이 게이지는 1.4절의 공통 게이지 위젯의 사례다.

## 3. 룬검 (RuneSword)

### 3.1 컨셉

> **마검사 → 검 소환사**

- **초반 — 마검사**: 룬을 두른 검으로 직접 휘둘러 범위기를 터뜨린다. 검 개수와 무관하게 완결되는 스킬이다.
- **후반 — 검 소환**: 평타로 검을 모아 **등 뒤에 띄우고**, **칼질을 하면서** 그 검이 추가로 돕는다. 캐릭터가 원거리 유닛이 되지 않는다.
- 스킬 트리에서 후반 스킬을 뒤쪽에 두는 것으로 두 단계를 만든다. 별도의 단계 전환 장치는 없다.
- 룬검은 **범위기에 강한 마스터리**다. 모든 스킬이 범위 데미지로 귀결된다.
- 순환 구조: **모으기(충전) → 쓰기(소비) → 폭주(소모 면제 + 증폭)**. 검이 쌓이면 쓰고, 6번 버프가 걸리면 쓰면서도 줄지 않는다.

### 3.2 스킬 구성 한눈에 보기

| # | 단계 | 가칭 | 발동 | 효과 |
|---|---|---|---|---|
| 기본 | 초반 | 룬 베기 | 평타 | **쌍검보다 큰 부채꼴** 근접 범위 공격 |
| 1 | 초반 | 룬 폭발 | N타 적중 | **적 위치** 기준 원형 범위 공격 |
| 2 | 초반 | 룬 파동 | N타 적중 (1번과 다른 주기) | **내 캐릭터 주변** 원형 범위 공격 |
| 3 | 초반 | 룬 방패 | 온히트 시 확률 | 공격력 증폭 + 막기확률 버프 (공격 없음) |
| 4-① | 후반 | 검 소환 | 온히트 시 확률 | 검 **+1~3 충전** (연쇄 판정) |
| 4-② | 후반 | 검기 베기 | 온히트 시 **검이 있으면**, 쿨타임 5초 | 검 1개 소비, 전방 일직선 넓고 긴 범위 공격 |
| 5 | 후반 | 검 사출 | 온히트 시 확률 | 검 1개 소비, 발사해 목표 지점에서 원형 폭발 |
| 6 | 후반 | 검 개방 | 온히트 시 확률 | 버프: **검 소모 면제 + 최종 데미지 증폭**. N초 유지되고 유지 중에는 재발동하지 않음 |

- 메인 스킬은 6개이고, **4번만 노드 두 개짜리 체인**이다. 4-①(충전)을 배워야 이어진 노드 4-②(소비 공격)가 열린다.
- 초반 스킬(1~3)은 검을 쓰지 않는다. 후반 스킬(4~6)이 검 계열이다.

### 3.3 검 시스템

| 항목 | 내용 |
|---|---|
| 보유 수 | 최대 5개 (`가안`) |
| 표현 | 등 뒤에 보유 수만큼 검이 떠 있다 |
| 충전 | **4-① 하나뿐이다.** 온히트 시 확률로 +1~3 |
| 소비 | 4-②와 5번이 소비한다. 둘 다 1회에 검 1개 |
| 소비 면제 | 6번 버프가 걸려 있는 동안 4-②·5번이 검을 소비하지 않는다 |
| 가득 찬 상태 | 가득 차면 충전은 낭비된다. 소비 스킬이 이를 비워 준다 |

**소비 스킬이 둘이어도 되는 이유**

- 4-②는 **쿨타임 5초**로 소비량의 상한이 정해져 있다. 5초에 검 1개 이상을 쓰지 못한다.
- 5번은 확률 발동이라 검이 없을 때는 소비가 일어나지 않는다. 두 스킬이 같은 조건에서 경쟁하는 구조라 한쪽만 굶지 않는다.
- 충전이 부족한지는 밸런스 단계에서 확인한다. 기준은 `평균 충전량 ≥ 4-② 소비 + 5번 소비` 다.

**충전과 소비 공격을 한 스킬에 두지 않는 이유**

- 한 스킬은 발동 방식과 쿨타임을 하나씩만 가진다. 충전(확률)과 소비 공격(검 보유 + 쿨타임)을 같이 담을 수 없다.
- 소비 공격이 "검이 있을 때만 발동"하면 검 0개에서 충전도 못 하는 교착이 생긴다. 충전을 선행 노드로 분리해 해결한다.

### 3.4 스킬 상세

#### 기본 공격 — 룬 베기

- 전방 **큰 부채꼴** 근접 범위 공격. 쌍검 평타보다 넓다.
- 단발이며, 적중이 충전·소비·버프 발동의 기점이다. **평타 효과만 온히트를 켠다.**

#### 룬 폭발 (1)

- 평타가 일정 횟수 적중할 때마다 발동한다.
- **대상 적의 위치**를 중심으로 원형 범위를 타격한다. 주기는 `미정`.

#### 룬 파동 (2)

- 평타가 일정 횟수 적중할 때마다 발동한다. 1번과 **주기가 달라** 같은 타에 겹치지 않게 한다.
- **시전자 주변**을 원형으로 타격한다. 주기는 `미정`.
- 1번과 2번은 원형이라는 점은 같지만 **기준 위치가 다르다.** 1번은 적 위치, 2번은 내 위치다.

#### 룬 방패 (3)

- 온히트 시 **확률로** 발동한다. 공격은 하지 않는다.
- 버프 효과: **공격력 증폭 + 막기확률 증가.**
- 연출: 룬 방패가 캐릭터 주위를 돈다. 버프가 유지되는 동안만 표시한다.
- 지속시간·중첩 여부는 `미정`.
- 쌍검이 회피(가속)를 쓰므로 룬검은 **막기**를 방어 수단으로 쓴다. 회피와 막기는 표시가 구분된다 (MISS / BLOCK).

#### 검 소환 (4-①)

- 온히트 시 **확률로** 검을 충전한다. 한 번 발동하면 **+1~3개**다.
- **연쇄 판정**으로 개수를 정한다.

```
1차 판정 (가장 높은 확률)  → 통과하면 검 +1, 이어서
2차 판정 (더 낮은 확률)    → 통과하면 검 +1, 이어서
3차 판정 (가장 낮은 확률)  → 통과하면 검 +1
```

- 많이 나올수록 확률이 낮아져 가끔 3개가 한꺼번에 터지는 맛이 있다.
- 평균 충전량은 각 단계 확률로 조절한다. 수치는 밸런스 단계에서 정한다.
- 노드 레벨이 오르면 확률이 오르거나 연쇄 단계가 늘어나는 식으로 확장할 수 있다.
- 충전은 검 보유와 무관하게 돌아가므로 검이 0개여도 모인다.

#### 검기 베기 (4-②)

- 4-①을 배우면 열리는 **이어진 노드**다.
- 온히트 시 **검이 있으면** 발동한다. 확률이 아니라 확정 발동이며, **쿨타임은 5초**다 (`가안`).
- 검 1개를 소비해 **전방 일직선으로 넓고 긴 범위**를 타격한다.
- 쌍검 일섬도 직선이지만 이쪽은 **넓고 길어서** 구분된다. 쌍검은 작은 범위 위주다.

#### 검 사출 (5)

- 온히트 시 **확률로** 발동한다.
- 동작 순서

```
1. 온히트 시 확률 판정
2. 통과하면 검 1개를 소비한다 (검이 없으면 아무 일도 일어나지 않는다)
3. 등 뒤의 검이 적을 향해 날아간다
4. 목표 지점(적 위치) 땅에 닿으면 원형 범위로 폭발한다
```

- 검이 0개면 확률만 통과해도 발사가 없다.
- 검 1개당 폭발 1회다.

#### 검 개방 (6)

- 온히트 시 **확률로** 버프를 건다. 이 버프가 룬검의 **폭주 구간**이다.
- 버프 효과

| 효과 | 내용 |
|---|---|
| 검 소모 면제 | 4-②·5번이 검을 소비하지 않는다 |
| 최종 데미지 증폭 | 시전자의 **모든 데미지**에 적용된다 |

- **지속시간 N초(`미정`)** 동안 유지된다.
- **유지되는 동안은 재발동하지 않는다.** 확률 판정 자체를 건너뛰며, 지속 시간을 연장하거나 갱신하지 않는다. 지속이 끝나면 다시 온히트 시 확률 판정을 시작한다. 폭주가 끊김 없이 이어지는 "무한 발동"을 막기 위한 규칙이다.
- 3번 방패의 **공격력 증폭**과 6번의 **최종 데미지 증폭**은 서로 다른 레이어라, 두 버프가 동시에 걸리면 곱해진다. 둘 중 하나만 있을 때와 확연히 차이가 난다.
- 평타 범위 증가는 넣지 않는다. 구현이 어렵기 때문이다 (3.6 참고).

### 3.5 온히트 시 판정되는 스킬

| 스킬 | 판정 |
|---|---|
| 룬 방패 (3) | 확률 |
| 검 소환 (4-①) | 확률 |
| 검기 베기 (4-②) | **확정** (검 보유 + 쿨타임 5초) |
| 검 사출 (5) | 확률 |
| 검 개방 (6) | 확률 (활성 중에는 판정하지 않음) |

- 1·2번은 N타 적중 기준이라 이 표와 별개다.
- 평타 한 번에 최대 다섯 가지가 동시에 나갈 수 있다. 각자 독립적으로 판정한다.

### 3.6 구현 시 확인할 사항

| 항목 | 내용 |
|---|---|
| 검 = 버프 스택 | 검 개수를 버프 스택(최대 5)으로 관리한다. 소환물(`Summon`)은 최대 수 초과 시 가장 오래된 것부터 소멸하고, 하나를 골라 소비하는 경로가 없다 |
| 소비 게이트 | `BuffConsume`(스택 소모, 성공 시 `ChainEffectIDs` 실행)로 "검이 있을 때만 발동"을 만든다. 코드는 있으나 **실제 데이터 행이 0개**다 |
| 소모 면제 분기 | "버프가 있으면 소비를 건너뛴다"는 분기는 현재 없다. 신규 작업이다 |
| 충전 연쇄 판정 | 버프 효과는 `Chance` 판정을 통과해야 다음 효과(`ChainEffectIDs`)가 실행된다. 검 +1 효과를 3단으로 이으면 된다 |
| 4-② 쿨타임 | 확률 발동 계열(`OnHit`) 스킬에서 `Cooldown`이 정상 동작하는지 확인이 필요하다. 쿨타임은 공속 배율을 받지 않는 실제 시간이다 |
| 4-② 노드 체인 | 노드의 스킬 습득(`SkillGrant`)과 선행 노드 조건으로 구성한다 |
| 착탄 폭발 | 투사체의 착탄 폭발 속성을 사용한다. 목표 지점이 적 위치가 되도록 하는 방식은 구현 단계에서 정한다 |
| 등 뒤 검 비주얼 | 스택 수에 맞춰 등 뒤 검 개수를 표시하는 연출이 필요하다. 시스템에 없는 신규 작업이다 |
| 룬 방패 연출 | 방패가 캐릭터 주위를 도는 연출은 버프 유지 시간에 맞춰 켜고 끈다 |
| 온히트 연쇄 | 평타만 온히트를 켠다. 나머지 스킬의 데미지 효과는 모두 **FALSE** 로 둔다. TRUE 이면 스킬이 다시 확률을 굴린다. 평타는 단발이어야 한다 |
| 특정 스킬만 증폭 불가 | 공격력 증폭·피해 보너스·최종 증폭은 모두 시전자의 모든 데미지에 걸린다. 데미지 계산이 어느 스킬인지 모르기 때문이다. 스킬별 증폭은 스킬 트리 노드·장비의 `SkillModifier`로만 가능하고 버프에는 붙일 수 없다 |
| 평타 범위 증가 불가 | 범위 스탯이 없고 버프가 스킬 변형값을 붙이는 경로도 없다. 구현하려면 "버프 → 변형값 → 스킬 재계산 + 이펙트 크기 동기화"를 새로 만들어야 해서 보류했다 |
| 검 개방 재발동 방지 | 확률 발동 판정은 쿨타임 중인 스킬을 제외하고, 발동하면 그 스킬의 쿨타임을 시작한다. **검 개방의 쿨타임을 버프 지속시간 이상으로 설정**하면 활성 중에는 판정에서 빠져 재발동하지 않는다. 쿨타임은 공속 배율을 받지 않는 실제 시간이다. 버프 쪽 중첩 정책을 "이미 있으면 무시"로 두는 방법을 보조 안전장치로 쓸 수 있다 |
| 충전 조건 제약 | 처치 시(`OnKill`)는 발동 경로가 연결되지 않았으므로 조건으로 쓰지 않는다 |

## 4. 쌍권총 (DualPistols)

### 4.1 컨셉

> **특수탄 사수 — 단일 평타에 특수탄이 터져 범위를 만들고, 난사와 레이저로 쓸어낸다**

- **중거리 범위 딜러**다. 평타는 한 놈만 쏘고, 온히트마다 확률로 터지는 **특수탄**이 소범위 폭발·관통으로 범위를 만든다.
- **여러 종류의 특수탄**(폭발탄, 관통탄)이 기본 축이고, **탄막 난사**(지속 사격)와 **궤도 레이저**(추적 폭딜)가 전투의 하이라이트를 맡는다.
- 6번은 **전투 중 쿨타임마다 터지는 폭주 구간**이다. 폭주 중에는 특수탄·탄막이 두 배로 자주 터지고, 끝나면 쿨타임이 돈다. **휴식 구간이 항상 있다.**
- 마스터리 보너스가 치명타 피해(`OPT_CRIT_DAMAGE_ADD`)다. 치명타율은 100%에 가까운 전제(1.4절)이므로 치명타 피해가 곧 데미지 배율이다.
- 직접 이동을 조작하므로 **강제 이동이 없다.** 대시·구르기·지뢰는 쓰지 않는다. "적 사이를 누빈다"는 인상은 총알과 이동속도 버프(퀵스텝)가 맡는다.

### 4.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 효과 |
|---|---|---|---|
| 기본 | 쌍총 사격 | 평타 | 중거리. 가까운 **1체를 단발 1히트**. 좌우 총을 번갈아 쏜다. 탄막 중에는 모션 없이 데미지만 |
| 1 | 폭발탄 (특수탄) | 온히트 시 확률 | 특수탄이 **대상 위치에서 소범위 폭발** |
| 2 | 탄막 난사 | 온히트 시 확률 | **모션 있음.** 캐릭터 중심 원형으로 돌면서 다단히트가 지속된다. 평타와 병행. 재발동 시 지속 갱신 |
| 3 | 관통탄 (특수탄) | 온히트 시 확률 | 다른 종류의 특수탄. **관통 발사체**가 직선상의 적에게 데미지 |
| 4 | 퀵스텝 | 온히트 시 확률 | 방어 버프: **회피율 + 이동속도** |
| 5 | 궤도 레이저 | 쿨타임 | **모션 없음.** 하늘에서 레이저 **한 줄기**가 내려와 대상을 따라다니며 **중간 크기 원형 범위**를 반복 타격. **보스 우선**, 없으면 가까운 적 |
| 6 | 이퀼리브리엄 | 쿨타임 + 전투 중 자동 발동 | 쿨타임이 돌아와 있고 전투 중이면 발동. 지속 시간 동안 **확률 발동 스킬 전체의 발동 확률 2배** |

- 메인 스킬 6개는 모두 단독 노드다. 특수탄 종류는 폭발탄(1)과 관통탄(3) 둘이고, 세 번째 이후는 노드 확장으로 둔다 (예: 연쇄, 소이).

### 4.3 스킬 상세

#### 기본 공격 — 쌍총 사격

- 사거리 안에서 **가까운 1체를 단발 1히트**한다. 좌우 총을 **번갈아** 한 발씩 쏜다.
- 평타 효과만 온히트를 켠다. 모든 특수탄·탄막·레이저 효과는 온히트를 끈다.
- 탄막이 진행 중이면 평타는 **모션 없이 데미지만** 들어간다 (4.4절).

#### 폭발탄 (1)

- 온히트 시 확률로 **특수탄**을 쏜다.
- 특수탄은 처음부터 **대상 위치에서 소범위로 폭발**한다. 평타는 한 놈만 쏘지만 특수탄이 터지면서 주변까지 번지는 것이 "단일 → 범위" 변환이다.

#### 탄막 난사 (2)

- 온히트 시 확률로 발동한다. 캐릭터가 **돌면서 주위에 총질**하는 느낌이며(데빌헌터 스타일), **캐릭터 중심 원형 범위 안의 적 모두**를 다단히트한다.
- **탄막 연출만 쓰고 실제 발사체는 쏘지 않는다.**
- **모션이 나오고**, 그 동안 평타는 모션 없이 데미지만 계속 들어간다. 평타가 멈추지 않으므로 **게이지가 계속 쌓이고 온히트 루프도 유지된다.**
- 탄막이 진행 중일 때 확률이 다시 걸려 재발동하면 새로 겹치지 않고 **남은 지속 시간을 갱신**한다. 6번이 켜져 확률이 2배가 되면 탄막이 거의 끊기지 않는 **무한 탄막**이 된다.
- 탄막의 타격은 온히트를 켜지 않는다.
- 이동은 플레이어 조작이므로 막지 않는다.

#### 관통탄 (3)

- 온히트 시 확률로 **다른 종류의 특수탄**을 쏜다.
- 관통 발사체가 대상을 뚫고 지나가며 **직선상의 적 모두**에게 데미지를 준다.

#### 퀵스텝 (4)

- 온히트 시 확률로 자신에게 **짧은 버프**를 건다. 효과는 **회피율 증가 + 이동속도 증가**.
- 강제 이동은 없다. 이동속도 증가로 직접 조작하는 움직임이 빨라진다.
- 쌍검은 회피(가속), 룬검은 막기(방패)이고 쌍권총은 **회피 + 이동**으로 갈린다.
- 지속시간·중첩 여부는 `미정`.

#### 궤도 레이저 (5)

- 쿨타임으로 발동한다. **모션이 없고** 연출은 하늘에서 레이저가 내려오는 FX다.

| 항목 | 내용 |
|---|---|
| 줄기 수 | **한 줄기** |
| 범위 | 레이저 위치 중심 **중간 크기 원형** |
| 타격 | 지속 시간 동안 일정 간격으로 반복 타격 |
| 대상 | **보스 우선.** 보스가 없으면 가까운 적 |
| 대상이 죽었을 때 | 같은 규칙(보스 우선, 없으면 가까운 적)으로 다음 대상을 다시 고른다 |
| 온히트 | 없음 |

- 레이저는 대상을 **따라다니며** 원형 범위로 때리므로 보스를 쫓는 동안 주변 잡몹도 함께 맞는다.
- 보스 우선은 **추적 대상 선정에만** 적용하고 보스에게 주는 추가 데미지는 없다. 석궁(보스 딜 마스터리)과 정체성이 겹치지 않도록 한다.
- 탄막이 캐릭터 중심의 지속 사격이라면 레이저는 하늘에서 오는 **추적형 폭딜**이다.

#### 이퀼리브리엄 (6)

**전투 중 쿨타임마다 터지는 폭주 구간**이다.

```
쿨타임 중   게이지가 시간에 따라 차오른다 (쿨타임 진행도)
준비 완료   쿨타임이 끝나면 게이지가 가득 차 대기한다. 전투 중이 아니면 발동하지 않는다
발동        전투 중이면 자동 발동. 게이지가 빛나며 지속 시간 동안 줄어든다
종료        지속이 끝나면 게이지가 비고 쿨타임이 다시 흐른다
```

| 항목 | 내용 |
|---|---|
| 발동 조건 | 쿨타임이 돌아와 있고 **전투 중**일 것 (1.5절). 전투 중이면 쿨타임이 돌 때마다 사용한다 |
| 효과 | 활성 중 **확률로 발동하는 스킬 전체의 발동 확률이 2배**가 된다 (폭발탄, 탄막 난사, 관통탄, 퀵스텝) |
| 영향 없는 스킬 | 쿨타임으로 발동하는 궤도 레이저 |
| 상한 | 확률은 100%를 넘지 않는다 |
| 쿨타임 | `미정` |
| 지속 시간 | `미정` (초기 구상은 15초) |
| 휴식 구간 | **항상 존재한다.** 쿨타임을 지속 시간 이상으로 두므로 구조적으로 보장된다 |

- 전투 중이 아닐 때 쿨타임이 끝나면 **대기**하다가 전투가 시작되는 순간 발동한다. 적이 없는 구간에서 낭비되지 않는다.
- **상시 발동은 하지 않는다.** 폭주가 가끔 와야 센 구간으로 느껴지고, 항상 켜져 있으면 2배가 기준선이 되어 평소 확률을 다시 낮춰야 한다.
- 후반 성장은 쿨타임 감소와 지속 증가로 하되, 휴식이 사실상 사라지지 않도록 쿨타임의 하한을 밸런스 규칙으로 둔다.
- 쿨타임 진행도를 보여 주는 이 게이지는 1.4절의 공통 게이지 위젯의 사례다.

### 4.4 규칙과 안전장치

| 규칙 | 내용 |
|---|---|
| 온히트를 켜는 곳 | **평타의 발만.** 특수탄·탄막·레이저·퀵스텝의 효과는 모두 끈다 |
| 다단히트 금지 | 다단히트(`HitCount > 1`)에는 온히트를 켜지 않는다. 적 수 × 타수만큼 확률이 굴러 폭주한다. 탄막의 타격이 온히트를 켜지 않는 이유다 |
| 모션 우선 규칙 | **큰 모션(탄막)이 진행 중이면 평타는 모션 없이 효과만 발동한다.** 이미 모션 없이 효과만 나가는 스킬(`AnimName` 공백)과 같은 방식이다. 평타가 멈추지 않아 게이지가 쌓인다 |
| 탄막 재발동 | 탄막 중 확률이 다시 걸리면 새로 겹치지 않고 **지속 시간을 갱신**한다. 동시에 한 개만 돌아 데미지 상한이 일정하다 |
| 탄막의 대가 | 탄막 자체는 대가가 없는 추가 딜이므로 발동 확률과 지속 시간으로 밸런스를 맞춘다 |
| 폭주 휴식 | 이퀼리브리엄은 발동 후 쿨타임이 돌아야 다시 나가며 쿨타임을 지속 시간 이상으로 둔다. 상시화 수단을 두지 않는다 |

### 4.5 구현 시 확인할 사항

| 항목 | 내용 |
|---|---|
| 폭주 게이지 | 쿨타임이 있는 자기 대상 버프 스킬을 **전투 중에만 자동 발동**하는 조건을 추가한다. 게이지는 쿨타임 진행도를 보여 준다 |
| 전투 중 상태 | 공용 시스템(1.5절). 피해를 주고받는 처리 지점에서 마지막 전투 시각을 갱신하고, 지금 시각과 비교해 전투 중인지 판단한다 |
| 게이지 위젯 | 채우기·빛나기·줄어들기 연출을 보여 주는 공통 게이지 위젯이 필요하다. 충전 기준(타격 횟수 / 시간)만 마스터리마다 다르다 |
| 확률 2배 | 확률 발동 판정(`triggerByChance`)은 스킬의 발동 확률 값과 난수를 비교한다. **발동 확률 증폭 스탯**(가칭 `Stat_TriggerChanceAmp`)을 추가하고 판정에서 곱하면 된다. 버프는 스탯 변경을 이미 지원하므로 6번 활성 구간을 버프로 걸 수 있다. 쌍검 초각성 I의 확률 2배에도 공용으로 쓸 수 있다 |
| 탄막 | 코드 스킬(`ISkillBehavior`)로 만들고 지속 상태와 갱신을 직접 관리한다. 재발동 시 새 인스턴스를 만들지 않고 남은 시간을 늘린다 |
| 평타 모션 억제 | 현재 시전 중(모션 진행 중)에는 다른 스킬 시전이 막힌다. 탄막이 진행 중일 때 **평타만 모션 없이 효과를 실행하는 분기**를 추가해야 한다 |
| 이동 허용 | 탄막 중에도 이동이 가능해야 한다. 코드 스킬이 이동을 잠그는지 확인한다 |
| 궤도 레이저 | **대상을 쫓아다니는 소환물**(`Chase` 동작)이 자기 위치 주변을 일정 간격으로 타격하는 구조(스파크와 같은 방식)가 후보다. 레이저 FX는 소환물에 붙인다 |
| 보스 우선 선정 | 대상 탐색에 우선순위 규칙(보스 우선, 없으면 가까운 적)을 추가하는 신규 작업이다. 대상이 죽었을 때 재선정도 같은 규칙을 쓴다 |
| 관통 발사체 | 투사체가 대상을 관통하며 경로의 적에게 데미지를 주는 속성이 현재 있는지 확인이 필요하다 |
| 번갈아 쏘는 연출 | 평타가 좌우 총을 교대로 쏘는 모션이 필요하다 |

### 4.6 채택하지 않은 안

| 안 | 이유 |
|---|---|
| 대시·구르기·연속 대시 | 직접 이동 조작과 충돌하는 강제 이동 |
| 지뢰 계열 | 요청에 따라 제외 |
| 장전·탄창 게이지 | 룬검의 검 충전·소비와 구조가 겹치고, 특수탄이 확률 발동만 해도 개성이 충분하다. 특수탄 종류 확장은 노드로 한다 |
| 폭발 변환 노드 (단일 → 범위) | 폭발탄을 처음부터 소범위로 두어 쌍권총이 단일 딜로 기울지 않게 했다 |
| 탄막이 평타를 대체 | 평타가 멈추면 게이지가 쌓이지 않고 온히트 루프가 끊겨 불만이 생긴다. 평타는 모션만 억제한다 |
| 탄막·난사에 온히트 부여 | 적 수 × 타수만큼 확률이 굴러 폭주한다. 대신 6번이 발동 확률 자체를 올린다 |
| 난사 계열 상호 배타 | 탄막이 평타를 대체하지 않고 병행하게 되어 불필요해졌다 |
| 데드아이 (표식 + 연타, 표식 일제 폭발) | 매 발 폭발이면 과하고, 폭발 횟수를 줄이면 표식 연출만 남아 궤도 레이저로 대체했다 |
| 수류탄 / 지원 요청 / 전방위 일제 사격 | 연출이 답답하거나 톤이 다르다. 하늘에서 내려와 추적하는 레이저로 정리했다 |
| 6번 평타 양손 2발 변경 | 평타를 일시 교체하거나 버프로 변형값을 붙이는 경로가 필요해 구현이 크다. 확률 2배로 대체했다 |
| 6번 N타 적중 게이지 / 특수탄 발동 횟수 / 이동 거리 / 명중한 적 수 충전 | 쌍검의 N타 게이지와 개성이 겹치거나 구현이 크다. 마스터리마다 폭주 방식을 다르게 하려고 쿨타임 + 전투 중 발동으로 정했다 |
| 6번 쿨타임 단축 (특수탄 발동 시) | 규칙이 복잡해지고 폭주 주기를 예측하기 어려워진다 |
| 6번 전투 진입 순간에만 발동 | 적이 계속 이어지는 구간에서는 한 번 쓰고 다음 전투까지 못 쓴다. 전투 중 쿨타임마다 쓰는 방식으로 정했다 |
| 6번 확률 활성 | 업타임 편차가 크다. 룬검이 이 방식을 쓰므로 쌍권총은 다른 방식으로 구분했다 |
| 6번 상시화·이월 노드 | 휴식 구간이 있어야 폭주가 센 구간으로 느껴진다 |
| 기본 공격 2체 동시 타격 | 6번 효과와 무관해지고 보스 딜 영역과 겹친다. 1체 단발로 바꿨다 |

## 5. 구현 시 확인할 사항 (쌍검)

현재 시스템에서 바로 되지 않는 항목만 모았다. 문서 확정 후 구현 단계에서 다룬다.

| 항목 | 내용 |
|---|---|
| 카운트 2배 | 현재 판정은 `카운터 % 주기 == 0` 이다. +2로 올리면 짝수 주기는 유지된다. 초각성 활성이 시작·종료되는 시점과 무기를 교체하는 시점에 카운터가 홀수면 영구히 맞지 않으므로 전환 시 짝수로 보정해야 한다 |
| 처형 | 랜덤 다수 선정 + 대상별 소범위 + 부족 시 배분 중첩. 현재 구조(탐색은 스킬이 한 번)에서 한 스킬로 되지 않는다. 투사체 착탄, 소환, 스킬 행동 시퀀스 중 구현 방식을 고른다 |
| 가속 중첩 | 기존 공속 버프의 `IndependentShared`(수명 공유, 새로 쌓일 때 갱신)가 후보다 |
| 공속 상한 | 상한은 스탯 정의의 `MaxValue` 다. 활성 중에만 올려야 하는데 노드나 버프가 상한을 바꾸는 경로가 현재 없다. 애니메이션 상한(5.0)에는 걸리지 않는다 |
| 폭주 게이지 | 쌍권총 6번과 같은 상태 기계와 공통 위젯을 쓴다. 충전 기준이 평타 적중 횟수다. 콤보 카운터는 공유·리셋 없음이라 별도의 전용 게이지 카운터를 둔다 |
| 확률 2배 | 쌍권총과 같은 발동 확률 증폭 스탯을 공용으로 쓴다 (4.5절) |
| 온히트 연쇄 | 평타만 온히트를 켠다. 나머지 스킬이 켜면 스킬이 다시 확률을 굴린다. 평타는 단발이어야 한다 |
