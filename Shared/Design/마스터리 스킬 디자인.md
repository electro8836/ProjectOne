# 마스터리 스킬 디자인

*무기 마스터리별 스킬 컨셉 · 구성 | 2D 탑다운 핵앤슬래시 · 싱글플레이 · Unity C#*

> **이 문서는 컨셉과 스킬 구성만 다룬다.** 확률·데미지·범위 크기·주기·지속시간 같은 **수치는 확정하지 않는다.** 밸런스 단계에서 바뀔 가능성이 높기 때문이다. 문서에 수치가 보이면 방향을 설명하는 `가안`이며, 테이블 작성 단계에서 다시 정한다.
>
> 기존 쌍검 스킬(콤보 액티브, 스파크 소환, 기존 18노드 트리)은 고려하지 않는다. 새 스킬 세트로 전면 교체한다는 전제다.

**목차**

1. 설계 전제
2. 쌍검 (DualBlades)
3. 룬검 (RuneSword)
4. 쌍권총 (DualPistols)
5. 석궁 (CrossBow)
6. 구현 시 확인할 사항 (쌍검)
7. 미정 항목

## 1. 설계 전제

### 1.1 마스터리당 스킬 구성

| 구분 | 개수 | 비고 |
|---|---|---|
| 기본 공격 | 1 | 평타. 공속 배율을 받는 유일한 스킬 |
| 메인 스킬 | 6 | 스킬 트리의 습득 노드로 배운다 |

이후 단계에서 각 스킬에 강화 노드를 붙여 확장한다. 이 문서는 **어떤 스킬을 만들지**만 정한다.

### 1.2 마스터리 정체성

직업 개념이 없으므로 무기마다 전투 방식이 구분되어야 한다. 구분 축은 **범위 형태**다.

| 무기 | 범위 형태 | 보상 |
|---|---|---|
| 쌍검 | 부채꼴·직선 위주, 범위가 작다 | 범위가 좁은 대신 데미지를 높게 잡는다 |
| 룬검 | **발도**: 좁은 부채꼴 + 긴 사거리 평타, 시전자 기준 직선·원형 기술 | 검기를 모아 직선과 원으로 소모한다 |
| 쌍권총 | 중거리 **단일 타겟** 단발 평타 + 특수탄 폭발, 수류탄, 채널링 탄막 | 평타를 특수탄이 범위로 번지게 한다 |
| 석궁 | 장거리 **단일 대상** 일자 직선 평타 + 긴 직선·전방 부채꼴·벼락 | 한 대상에 은화살 약점을 쌓아 터뜨리고, 궁극기 다크 스트림에서는 평타가 어둠의 라인으로 바뀌어 속사한다 |
| 다른 무기 | 원형 범위 위주 | ‒ |

### 1.3 발동 방식 용어

| 용어 | 시스템 대응 | 설명 |
|---|---|---|
| N타 적중 | `OnCombo` | 평타가 **실제로 적중**한 횟수. 스윙 1회 = 1카운트이고 여러 명을 맞춰도 1이다 |
| 온히트 | `OnHit` | `SkillEffect.OnHitTrigger = TRUE` 인 효과가 **적중할 때** 발동하는 계열. 평타에 맞은 적마다 개별로 판정한다. 온히트를 켜는 공격은 마스터리마다 정한다 |
| 온스윙 시 확률 | `OnSwingHit` | 평타 **스윙 1회당 1번** 확률을 굴린다. 맞은 적이 몇 명이든 판정은 한 번이다 |

**기본 발동 방식은 N타 적중이다.** 확률(온히트·온스윙)로 발동하는 스킬은 예외로 스킬마다 따로 지정한다.

쌍검과 룬검은 온히트를 켜는 공격이 평타뿐이다. 쌍권총은 평타와 이퀼리브리엄 추가 사격이 온히트를 켠다 (4.4절). 석궁은 평타와 다크 스트림 교체 평타가 온히트를 켠다 (5.4절).

### 1.4 공통 전제

| 전제 | 내용 |
|---|---|
| 치명타율·공속 | 모든 캐릭터가 **치명타율 100%** 와 **공격 속도 300%** 에 어렵지 않게 도달하도록 설계한다. 쌍검만 오버드라이브 지속 중 공속이 상한 350%로 고정된다. 그래서 치명타율 증가 효과는 가치가 낮고 치명타 피해가 데미지 배율의 중심이 된다 |
| 방향 기준 | 직선·부채꼴의 방향은 **캐릭터가 잡은 현재 타겟 방향**이다. 가장 가까운 적이 아니라 우선 타겟을 따른다 (보스가 우선 타겟이면 가까운 잡몹이 있어도 보스 쪽으로 쏜다) |
| 이동 | 이동은 플레이어가 **직접 조작**한다. 스킬이 캐릭터를 강제로 이동시키지 않는다 |
| 방어 스킬 | 현재 모든 마스터리에서 **방어 스킬을 두지 않는다.** 공격 컨셉을 먼저 정한 뒤 필요하면 다시 검토한다. 쌍검 3번 소드실드(연타 스택 블럭율), 룬검 3번 심안(검기 비례 회피율), 쌍권총 3번 쉐도우스텝(짧은 시간 회피율)만 예외로 둔다 |
| 추가 게이지 | **특수 게이지류를 두지 않는다.** 폭주 구간과 쿨타임에도 별도 게이지 위젯이나 게이지 방식 충전을 쓰지 않는다 |
| 폭주 구간 규칙 | 4개 마스터리의 6번(궁극기)은 모두 **쿨타임으로 쓰는 시간제 폭주 구간**이다. 기본값은 쿨타임 30초·지속 10초 `가안`이고, 쿨타임이 돌아오면 **버튼을 눌러** 쓴다. 버튼을 자동으로 누르는 기능(전투 중 자동 사용)을 추가할 예정이다. **쿨타임은 사용하자마자 흐르기 시작**하고 쿨타임과 지속은 따로 흐른다 (30초/10초면 휴식 20초). 나중에 특정 행위가 일어나면 쿨타임을 초 단위·퍼센트로 줄이는 기능을 추가할 예정이다 |
| 전투 중 상태 | **공용 시스템.** 피해를 주거나 받으면 전투 중이 되고, 마지막 전투 행동 후 10초(`가안`) 동안 없으면 해제된다. 현재 이 상태를 쓰는 스킬은 없다. 1.5절 참고 |

### 1.5 전투 중 상태 (공용 시스템)

마스터리와 무관한 **공용 시스템**이다. 전투 중에만 처리할 항목은 이 시스템에 붙인다.

| 항목 | 내용 |
|---|---|
| 진입 | 피해를 **주거나 받으면** 전투 중이 된다 |
| 해제 | 마지막 전투 행동(주거나 받음) 이후 **10초**(`가안`) 동안 아무 일도 없으면 해제된다 |
| 갱신 | 전투 행동이 있을 때마다 해제 시한이 새로 시작된다 |

**전투 중에 처리하는 항목**

| 항목 | 내용 |
|---|---|
| 현재 없음 | 전투 중에만 동작하는 스킬 항목은 아직 없다 |
| 추후 추가 | 전투 중에만 동작해야 하는 항목이 생기면 여기에 더한다 |

- 구현은 "마지막 전투 행동 시각"을 저장하고 지금 시각과 비교하는 방식이 단순하다. 매 프레임 카운터를 돌릴 필요가 없다.
- 시각 갱신은 피해를 주고받는 처리 지점에서 한다. 스킬 발동 경로(`OnDamaged` 등)와는 별개라 그 경로가 미연결이어도 영향이 없다.
- 해제 시간, 장시간 보스전 예외, 무적 같은 특수 상태에서의 처리는 `미정`이다.

## 2. 쌍검 (DualBlades)

### 2.1 컨셉

> **연타 + 마무리 딜러**

- **연타**: 평타를 계속 적중시키는 것이 곧 카운트 스킬의 발동 조건이다. 공속이 곧 딜이 된다.
- **마무리**: 체력이 낮아진 적을 평타가 맞을 때마다 추가로 베어 낸다 (페이탈 어택).
- **단단함**: 연타하는 동안 블럭율 스택이 쌓여 점점 단단해진다 (소드실드).
- 범위는 작게, 데미지는 높게. 광역은 다른 무기에 맡기고 쌍검은 좁고 깊게 간다.

### 2.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 범위 | 역할 |
|---|---|---|---|---|
| 기본 | 기본 공격 | 평타 | 전방 작은 부채꼴 | 카운트·온히트·온스윙의 기점 |
| 1 | 스팅어 | N타 적중 (짧은 주기) | 직선 | 빠르게 도는 직선 공격 |
| 2 | 퓨리 | N타 적중 (긴 주기) | 시전자 중심 원형 | 주변 정리 (다단히트) |
| 3 | 소드실드 | 패시브 (노드 1개, 5레벨) | 자신 | 연타 스택 블럭율 |
| 4 | 페이탈 어택 (가칭) | 평타 온히트마다 | 맞은 적 1체 (체력 조건) | 체력이 낮은 적 마무리 |
| 5 | 팬텀 디바이드 | 온스윙 확률 (10% `가안`) | 전방 큰 부채꼴 | 드물게 터지는 큰 한 방 |
| 6 | 오버드라이브 | 쿨타임 (30초 `가안`) · 지속 10초 `가안` | 자신 | 공속 최대치 고정 + 최종 데미지 증가 |

- 카운트 스킬은 스팅어와 퓨리 둘이다. 두 스킬은 카운터 하나를 공유하므로 주기를 서로 겹치지 않게 정한다. 구체적인 타수는 `미정`이다.
- 모든 스킬은 모션 없이 이펙트만 나간다. 평타 연타가 끊기지 않는다.

### 2.3 스킬 상세

#### 기본 공격

- 사거리 안에 적이 있으면 자동으로 휘두른다.
- 시전자 중심 **작은 부채꼴**, 방향은 **현재 타겟 방향**, 범위 안 적 **전부**를 단발 1히트로 타격한다.
- **스윙 1회가 1카운트**다. 여러 명을 맞혀도 1이다.
- 이 공격의 적중이 모든 카운트·온히트·온스윙 발동의 기점이다. 평타 효과만 온히트를 켠다.

#### 스팅어

- 평타가 일정 횟수 적중할 때마다 발동한다 (가장 짧은 주기).
- **시전자 위치**에서 시작해 **현재 타겟 방향**으로 뻗는 **직선**이다.
- 직선 안 적 전부를 1히트 단발로 타격한다.
- 모션 없이 이펙트만 나가고 온히트는 켜지 않는다.

#### 퓨리

- 평타가 일정 횟수 적중할 때마다 발동한다 (스팅어보다 긴 주기).
- **시전자 중심 원형** 범위를 타격한다. 쌍검에서 유일한 원형 범위다.
- 발동 시점에 범위 안 적을 **스냅샷으로 고정**한 뒤 그 적들을 **다단히트**한다. 히트 사이에 들어온 적은 맞지 않고, 빠져나간 적은 계속 맞는다.
- 모션 없이 이펙트만 나가고 온히트는 켜지 않는다.

#### 소드실드

- **패시브**다. 노드 하나에 5레벨이고, 마스터리가 활성일 때만 적용된다.
- 평타가 적중할 때마다 **블럭율 스택이 +1** 쌓인다. 스택당 블럭율 +3%(`가안`), 최대 5스택, 최대 **15%**다. 블럭은 막기 판정에 성공하면 그 피해를 0으로 만든다.
- 스택 전체가 수명을 공유하고, 평타가 적중할 때마다 지속 시간이 갱신된다. 연타를 멈추면 지속이 끝날 때 한꺼번에 사라진다.
- 레벨이 오를수록 스택당 수치가 커진다 (레벨별 수치 `미정`).
- 쌍검의 평타 적중이 매우 잦아 스택은 사실상 늘 가득 찬다. 소드실드는 "연타하는 동안의 상시 블럭율"로 본다.
- 모든 마스터리에서 방어 스킬을 두지 않는다는 원칙(1.4절)의 **쌍검 한정 예외**다.

#### 페이탈 어택 (가칭)

- **평타가 맞을 때마다** 판정한다 (확률도 N타도 아니다). 평타로 맞은 적을 **적마다 개별**로 본다.
- 평타 피해를 받은 **뒤의 체력**이 기준 이하이면 그 적에게 **단일 데미지**를 추가로 준다.
- 기준은 노드 레벨에 따라 넓어진다: **Lv1 25% → Lv5 50%**.
- **보스에게도 적용**한다.
- 모션 없이 이펙트만 나가고, 이 스킬의 데미지는 온히트를 켜지 않는다.
- 부채꼴로 여러 명을 맞히면 조건에 맞는 적마다 한 번씩 들어가므로 잡몹 정리에도 쓰인다.
- 피해 계수는 `미정`이다.

#### 팬텀 디바이드

- **평타 스윙 1회당 1번** 확률(10% `가안`)을 굴린다. 맞은 적이 몇 명이든 판정은 한 번이다 (`OnSwingHit`).
- 시전자 중심 **큰 부채꼴**이고, 방향은 **현재 타겟 방향**이다.
- 범위 안 적 전부를 1히트 단발로 타격한다. 쌍검에서 가장 넓은 범위다.
- 모션 없이 이펙트만 나가고 온히트는 켜지 않는다.

#### 오버드라이브

**쿨타임으로 쓰는 시간제 폭주 구간**이다. **노드는 하나**다.

| 항목 | 내용 |
|---|---|
| 사용 | 쿨타임이 돌아오면 **버튼을 눌러** 쓴다. 버튼을 자동으로 누르는 기능(전투 중 자동 사용)을 추가할 예정이다 |
| 쿨타임 | 30초 `가안` |
| 지속 | 10초 `가안` |
| 쿨타임 시작 | **사용하자마자 흐르기 시작한다.** 쿨타임과 지속은 따로 흐른다 |
| 효과 1 | 지속 동안 공격 속도 **상한이 +50%** 늘어난다 |
| 효과 2 | 지속 동안 공격 속도가 **상한까지 최대치로 고정**된다 (표준 300% + 50% = 350%) |
| 효과 3 | 지속 동안 시전자의 **최종 데미지가 증가**한다 (수치는 작게 시작) |

- 예: 쿨타임 30초, 지속 10초일 때 사용 직후 쿨타임이 돈다. 10초 뒤 지속이 끝나고, 쿨타임이 20초 남은 채로 흘러 20초 뒤 다시 쓸 수 있다. 쉬는 구간이 20초다.
- 장비의 공속 합계와 무관하게 지속 중에는 350%가 되므로, 공속이 부족한 빌드에서도 효과가 있다.
- 나중에 "특정 행위가 일어나면 쿨타임을 초 단위 또는 퍼센트로 줄이는" 기능이 추가될 예정이다. 이미 있는 `CooldownReduce`가 초 단위·비율을 모두 지원한다.

## 3. 룬검 (RuneSword)

### 3.1 컨셉

> **발도 — 검기를 모으고, 모은 검기로 직선과 원을 벤다**

- 평타는 좁은 부채꼴에 사거리가 긴 **발도술**이다. 평타가 3번 적중할 때마다 **검기**가 1개 쌓인다.
- 검기는 **소모하는 자원**이다 (최대 8). 일섬·회축·참격이 검기를 쓰고, 심안이 시간이 지나면서 검기를 채워 준다.
- 검기를 많이 가질수록 회피율이 오른다 (심안). 검기를 쓰면 회피율도 같이 줄어드는 긴장이 있다.
- 기술은 시전자 기준 **직선**(참격, 일섬, 연격)과 **원형**(회축)이다. 소환물은 쓰지 않는다.
- 6번 만해는 검기를 가득 채우고 지속 동안 검기를 쓰지 않게 하는 **시간제 폭주 구간**이다.
- 방어 스킬을 두지 않는 원칙(1.4절)의 **룬검 한정 예외**가 심안(검기 비례 회피율)이다.

### 3.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 검기 | 효과 |
|---|---|---|---|---|
| 기본 | 룬 베기 (발도술) | 평타 | 3회 적중마다 +1 | **좁은 부채꼴 각도 + 긴 사거리**, 현재 타겟 방향 |
| 1 | 참격 | 온스윙 35% | 1 소모 | 시전자 기준 직선 (가볍고 좁음) |
| 2 | 회축 | 온스윙 100%, 쿨타임 5초 | 1 소모 | 시전자 중심 원형 |
| 3 | 심안 | 2초마다 (주기 틱) | +1 | 검기 개당 **회피율 +2.5%** |
| 4 | 일섬 | 온스윙 100%, 쿨타임 10초 | 1 소모 | 시전자 기준 직선 (넓고 길고 강함) |
| 5 | 연격 | 참격이 발동될 때 50% | 소모 없음 | 참격과 같은 방향으로 직선을 한 번 더 |
| 6 | 만해 | 쿨타임 (30초 `가안`) · 지속 10초 `가안` | 최대치로 채움, 지속 중 소모 없음 | 일섬·회축 쿨타임 절반 |

- 모든 스킬은 모션 없이 이펙트만 나간다. 평타 연타가 끊기지 않는다.
- 온히트를 켜는 공격은 평타뿐이고, 나머지 스킬의 데미지 효과는 모두 끈다.
- 모든 직선·부채꼴의 방향은 **캐릭터가 잡은 현재 타겟 방향**이다 (1.4절).

### 3.3 검기 시스템

| 항목 | 내용 |
|---|---|
| 보유 수 | 최대 8 |
| 획득 | 평타 **3회 적중**마다 +1, 심안이 **2초마다** +1 `가안`, 만해 사용 시 최대치로 채움 |
| 소모 | 일섬 1, 회축 1, 참격 1. **연격은 소모하지 않는다** |
| 최대치에서 | 이미 가득이면 획득은 소멸한다 |
| 만료 | 시간이 지나도 사라지지 않는다 |
| 회피율 | 검기 개당 +2.5% (최대 20%). 검기를 쓰면 같이 줄어든다 |
| 초기화 | 시점은 `미정` (7절) |

**소모 우선순위: 일섬 → 회축 → 참격.** 한 스윙에서 검기가 부족하면 앞선 스킬이 먼저 검기를 가져간다.

**검기 선조건:** 일섬과 회축은 검기가 있을 때만 발동을 시작한다. 검기가 없으면 발동도 쿨타임도 시작하지 않고 검기가 생길 때까지 대기한다. 참격은 검기가 없으면 불발한다 (쿨타임이 없어 손해가 없다).

**공급과 소모의 균형:** 공속 300% 기준 공급은 평타 3회 적중당 약 1/초와 심안, 소모는 참격 약 1/초(35% × 3스윙)에 회축·일섬이다. 공급이 소모보다 크면 검기가 늘 가득 차서 만해의 체감이 사라지므로, 심안 주기를 1초가 아닌 2초 이상으로 잡는다. 수치는 밸런스 단계에서 정한다.

### 3.4 스킬 상세

#### 기본 공격 — 룬 베기 (발도술)

- 사거리 안에 적이 있으면 자동으로 휘두른다.
- 시전자 중심 **좁은 부채꼴 각도 + 긴 사거리**이고 방향은 **현재 타겟 방향**이다. 범위 안 적 전부를 단발 1히트로 타격한다.
- **스윙 1회가 1카운트**다. 여러 명을 맞혀도 1이다.
- **평타 3회 적중마다 검기가 +1** 쌓인다. 카운터 하나를 쓰는 N타 적중(3타)으로 구현한다.
- 평타 효과만 온히트를 켠다. 쌍검 평타와 규칙은 같고 범위 형태만 다르다.

#### 참격 (1)

- 평타가 적중한 스윙마다 **35%** 확률(`가안`)을 한 번 굴린다 (온스윙).
- 검기 1개를 소모하고, 시전자 기준 **직선 라인**을 현재 타겟 방향으로 낸다. 검기가 없으면 불발이다.
- 라인 안 적 전부를 1히트 단발로 타격한다. **가볍고 좁은 라인**이다 (일섬과 폭·길이로 구분).
- 소모 우선순위는 가장 마지막이다. 라인 폭·길이는 `미정`.

#### 회축 (2)

- 평타가 적중한 스윙마다 발동한다 (온스윙 100%, **쿨타임 5초**).
- 검기 1개를 소모하고, 시전자 중심 **원형** 범위 안 적 전부를 1히트 단발로 타격한다.
- 검기가 없으면 발동도 쿨타임도 시작하지 않고 대기한다. 반경은 `미정`.

#### 심안 (3)

- **2초마다** 검기를 +1 한다 (최대 8). 가득이면 소멸한다.
- 검기를 보유한 동안 **개당 회피율 +2.5%** (최대 20%)를 준다. 검기 수에 비례하는 버프다.
- 방어 스킬 없음 원칙의 예외다. 쌍검 소드실드에 이은 두 번째 예외다.

#### 일섬 (4)

- 평타가 적중한 스윙마다 발동한다 (온스윙 100%, **쿨타임 10초**).
- 검기 1개를 소모하고, 시전자 기준 **넓고 긴 강한 직선 라인**을 현재 타겟 방향으로 낸다. 라인 안 전부 1히트 단발이다.
- 검기가 없으면 발동도 쿨타임도 시작하지 않고 대기한다. **소모 우선순위가 가장 높다.**
- 라인 폭·길이와 피해 계수는 `미정`.

#### 연격 (5)

- **참격이 발동될 때 50%** 확률로 참격과 같은 방향으로 직선 라인을 **한 번 더** 낸다.
- 검기를 소모하지 않는다 (참격의 1개만 쓴다). 추가 라인은 짧은 지연 후 시간차로 나가고 1히트 단발이다.
- 참격이 35%라서 평타 적중 스윙당 약 17.5%로 나간다.

#### 만해 (6)

**쿨타임으로 쓰는 시간제 폭주 구간**이다. **노드는 하나**다.

| 항목 | 내용 |
|---|---|
| 사용 | 쿨타임이 돌아오면 **버튼을 눌러** 쓴다. 버튼을 자동으로 누르는 기능(전투 중 자동 사용)을 추가할 예정이다 |
| 쿨타임 | 30초 `가안`, 사용하자마자 흐르기 시작한다. 쿨타임과 지속은 따로 흐른다 |
| 지속 | 10초 `가안` |
| 효과 1 | 사용 시 검기를 **최대치(8)로 채운다** |
| 효과 2 | 지속 동안 **검기 소모 없음** |
| 효과 3 | 지속 동안 일섬·회축의 **쿨타임이 절반**으로 돈다 |
| 지속 종료 | 검기는 8개 그대로 남는다 |

- 검기가 가득 차 있으므로 회피율도 20%까지 오른다.
- 나중에 "특정 행위가 일어나면 쿨타임을 초 단위·퍼센트로 줄이는" 기능이 추가될 예정이다.

### 3.5 한 스윙의 처리 순서

평타가 적중한 스윙 한 번에 온스윙 스킬이 검기를 확인하는 순서다.

```
1. 일섬   쿨타임이 돌아와 있고 검기가 있으면 발동, 검기 1 소모
2. 회축   쿨타임이 돌아와 있고 검기가 있으면 발동, 검기 1 소모
3. 참격   35% 판정을 통과하고 검기가 있으면 발동, 검기 1 소모
4. 연격   참격이 발동했으면 50%로 추가 라인 (검기 소모 없음)
```

- 검기가 충분하면 한 스윙에서 여러 스킬이 함께 나간다.
- 검기 획득(3회 적중마다 +1)은 스윙의 카운트 처리에서 일어난다.

### 3.6 구현 시 확인할 사항

| 항목 | 내용 |
|---|---|
| 온스윙 | `OnSwingHit` 발동 경로가 필요하다 (쌍검 팬텀 디바이드와 공용). 참격·회축·일섬이 쓴다 |
| 검기 = 버프 스택 | 검기를 버프 스택(최대 8)으로 관리하고 시간 만료가 없어야 한다 (아주 긴 지속시간으로 대체 가능). 회피율은 스택 수에 비례하는 `Stat_EvasionRate` 버프로 만든다 |
| 검기 선조건 | 일섬·회축은 "검기가 있을 때만 발동 시작"이 필요하다. 설계서에 언급된 `CostBuffID`/`CostStack`은 코드에 없고, 지금은 `BuffConsume` 게이트가 실패해도 쿨타임이 시작된다 (`SkillContainer.cs:1050`) |
| 소모 우선순위 | 같은 스윙에서 일섬 → 회축 → 참격 순서로 판정되도록 보유 스킬 목록을 정렬해야 한다 |
| 검기 획득 | 평타 3회 적중마다 +1은 `OnCombo`(3)로 구현한다. 룬검은 다른 N타 스킬이 없어 카운터를 공유해도 충돌이 없다 |
| 심안 | `Aura`(주기 틱)로 만든다. 이미 있는 캐스팅 타입이다 |
| 연격 | `Buff` 효과의 `Chance` 판정과 `ChainEffectIDs` 연쇄로 만든다 (설계서 5.5절). 순환은 없다 |
| 만해 쿨타임 절반 | 쿨타임 배율을 줄이는 스탯이 없다. `CooldownReduce`는 진행 중인 쿨타임을 깎는 일회성이라 다르다. 쿨타임 배율 스탯을 새로 만들어야 한다 |
| 만해 사용 | 쿨타임 기반 직접 시전(`Instant`)이다. 버튼과 자동 사용은 전투 UI 쪽 작업이다 |
| 온히트 연쇄 | 평타만 온히트를 켠다. 나머지 스킬의 데미지 효과는 모두 `FALSE`로 둔다. 평타는 단발이어야 한다 |

## 4. 쌍권총 (DualPistols)

### 4.1 컨셉

> **특수탄 사수 — 평타 한 발이 맞을 때마다 특수탄이 터져 범위를 만들고, 탄막으로 쓸어낸다**

- **중거리 단일 타겟 사수**다. 평타는 현재 타겟 1체에 쏘는 단발 1발(히트스캔)이고, 온히트마다 확률로 터지는 특수탄이 폭발로 범위를 만든다.
- 수류탄은 시전자 주변을 쓸고, **탄막 난사**는 캐릭터가 돌면서 주위를 난사하는 **채널링**이다. 전탄발사가 탄막과 연계해 한 번 더 터진다.
- 6번 이퀼리브리엄은 활성 중 평타가 나갈 때마다 **추가 사격이 한 발 더** 나가 온히트 판정이 평타 1회에 2번이 되는 시간제 폭주 구간이다.
- 마스터리 보너스가 치명타 피해(`OPT_CRIT_DAMAGE_ADD`)다. 치명타율은 100%에 가까운 전제(1.4절)이므로 치명타 피해가 곧 데미지 배율이다.
- 이동은 플레이어가 직접 조작하므로 강제 이동이 없다. 방어 스킬을 두지 않는 원칙(1.4절)의 **쌍권총 한정 예외**가 3번 쉐도우스텝(짧은 시간 회피율 상승)이다.

### 4.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 효과 |
|---|---|---|---|
| 기본 | 쌍총 사격 | 평타 | **현재 타겟 1체**에 단발 1발 (히트스캔) |
| 1 | 폭발탄 (특수탄) | 온히트 확률 | 맞은 대상 위치에서 소범위 원형 폭발 |
| 2 | 탄막 난사 | 온히트 확률 | **채널링.** 캐릭터가 돌며 시전자 중심 원형을 틱마다 타격. 재발동 시 지속 갱신 |
| 3 | 쉐도우스텝 | 쿨타임 (15초 `가안`) · 지속 5초 `가안` | 짧은 시간 회피율 +45% `가안` |
| 4 | 수류탄 | 온히트 확률 | 발동 시점 시전자 위치에 고정한 원형 폭발 |
| 5 | 전탄발사 | 탄막 난사가 발동할 때마다 | 시전자 중심 원형 1히트 |
| 6 | 이퀼리브리엄 | 쿨타임 (30초 `가안`) · 지속 10초 `가안` | 활성 중 평타마다 **추가 사격 한 발** (온히트 켬) |

- 메인 스킬 6개는 모두 단독 노드다.
- 모션은 탄막 난사 하나뿐이다. 나머지는 모션 없이 이펙트만 나간다.

### 4.3 스킬 상세

#### 기본 공격 — 쌍총 사격

- 사거리 안에 적이 있으면 자동으로 쏜다.
- **현재 타겟 1체**에 **단발 1발**을 쏜다. 두 정으로 쏘는 연출은 이펙트로 표현한다.
- 히트스캔(즉발)이다. 총알은 이펙트일 뿐 날아가는 시간이 없다.
- **평타 1회가 1카운트**이고, 온히트 판정은 평타 1회에 1번이다. 평타 효과만 온히트를 켠다 (이퀼리브리엄 추가 사격은 예외, 4.4절).
- 평소 특수탄이 자주 터지므로 특수탄 확률은 낮게 시작한다.

#### 폭발탄 (1)

- 온히트 확률로 **특수탄**이 터진다.
- **맞은 대상 위치에서 즉시** 소범위 원형으로 폭발한다 (좌표 고정). 원 안 적 전부를 1히트 단발로 타격하고 모션은 없다.
- 단일 타겟 평타가 폭발로 주변까지 번지는 것이 "단일 → 범위" 변환이다. 중첩 피해를 허용한다.

#### 탄막 난사 (2)

- 온히트 확률로 발동하는 **채널링 스킬**이다. 캐릭터가 **돌면서 주위에 총질**하는 느낌이다(데빌헌터 스타일).
- 모션이 루프하는 동안 **시작 즉시 첫 틱**부터 일정 간격(공속 무관)마다 **시전자 중심 원형** 안의 적 모두를 타격한다. 틱마다 범위 안 적을 **다시 탐색**한다.
- **재발동하면 지속 시간을 전체 지속으로 갱신한다.** 예: 2초짜리 채널링, 0.2초 틱일 때 1초 동안 5번 쏜 뒤 재발동하면 남은 시간이 다시 2초가 된다. 새로 겹치지 않는다.
- 탄막 중에도 **평타는 모션 없이 효과만 계속 나간다.** 평타가 멈추지 않아 온히트 루프가 유지된다.
- **이동은 막지 않는다.**
- 탄막의 타격은 온히트를 켜지 않는다.

#### 쉐도우스텝 (3)

**순간가속 개념의 방어 스킬**이다. 짧은 시간 동안 회피율을 크게 올린다.

| 항목 | 내용 |
|---|---|
| 사용 | 쿨타임이 돌아오면 **자동으로 시전**한다 (일반 액티브 스킬) |
| 쿨타임 | 15초 `가안`, 사용하자마자 흐르기 시작한다. 쿨타임과 지속은 따로 흐른다 |
| 지속 | 5초 `가안` |
| 효과 | 지속 동안 **회피율 +45%** `가안` |
| 재발동 | 쿨타임 기반이라 중첩되지 않는다 |

- 15초 쿨타임에 5초 지속이므로 휴식 구간이 10초다.
- 이동이나 위치 변경 없이 회피율만 오른다. 강제 이동이 없다는 원칙(1.4절)을 지킨다.
- 방어 스킬 없음 원칙의 예외다. 쌍검 소드실드, 룬검 심안에 이은 세 번째 예외다.

#### 수류탄 (4)

- 온히트 확률로 수류탄을 던진다.
- **발동 시점의 시전자 위치**에 좌표를 고정하고, 짧은 지연 뒤 그 자리에서 원형으로 폭발한다. 캐릭터가 이동해도 따라오지 않는다.
- 원 안 적 전부를 1히트 단발로 타격한다. 모션 없이 수류탄 이펙트만 나가고 중첩 피해를 허용한다.
- 범위 크기와 지연 시간은 `미정`.

#### 전탄발사 (5)

- **탄막 난사가 발동할 때마다** 시전자 중심 원형 범위에 전탄이 1히트로 터진다.
- 탄막이 새로 시작될 때와 재발동으로 갱신될 때 모두 한 번씩 터진다.
- 모션 없이 이펙트만 나가고 온히트는 켜지 않는다. 탄막을 배우지 않았으면 발동하지 않는다.
- 반경과 피해 계수는 `미정`.

#### 이퀼리브리엄 (6)

**쿨타임으로 쓰는 시간제 폭주 구간**이다. **노드는 하나**다.

| 항목 | 내용 |
|---|---|
| 사용 | 쿨타임이 돌아오면 **버튼을 눌러** 쓴다. 버튼을 자동으로 누르는 기능(전투 중 자동 사용)을 추가할 예정이다 |
| 쿨타임 | 30초 `가안`, 사용하자마자 흐르기 시작한다. 쿨타임과 지속은 따로 흐른다 |
| 지속 | 10초 `가안` |
| 효과 | 지속 동안 평타가 나갈 때마다 평타와 비슷한 **추가 사격이 한 발 더** 나간다. **온히트를 켠다** |
| 추가 사격 대상 | **현재 타겟 외 가장 가까운 적을 우선**, 없으면 현재 타겟 |

- 결과적으로 평타 1회에 온히트가 2번 굴러 특수탄이 터질 기회가 2배가 된다.
- 특수탄은 타겟마다 개별로 판정된다.
- 나중에 "특정 행위가 일어나면 쿨타임을 초 단위·퍼센트로 줄이는" 기능이 추가될 예정이다.

### 4.4 규칙과 안전장치

| 규칙 | 내용 |
|---|---|
| 온히트를 켜는 곳 | **평타**와 **이퀼리브리엄 추가 사격.** 특수탄·탄막·수류탄·전탄의 효과는 모두 끈다 |
| 다단히트 금지 | 다단히트(`HitCount > 1`)에는 온히트를 켜지 않는다. 적 수 × 타수만큼 확률이 굴러 폭주한다. 탄막의 타격이 온히트를 켜지 않는 이유다 |
| 모션 우선 규칙 | **탄막이 진행 중이면 평타는 모션 없이 효과만 발동한다.** 평타가 멈추지 않아 온히트 루프가 유지된다 |
| 탄막 재발동 | 새로 겹치지 않고 **지속 시간을 전체 지속으로 갱신**한다. 동시에 한 개만 돌아 데미지 상한이 일정하다 |
| 폭주 휴식 | 이퀼리브리엄은 쿨타임과 지속이 따로 흘러 휴식 구간이 항상 있다 (30/10이면 20초) |
| 순환 | 온히트를 켜는 것이 평타와 추가 사격뿐이고 특수탄은 다시 온히트를 켜지 않아 순환이 생기지 않는다 |

### 4.5 구현 시 확인할 사항

| 항목 | 내용 |
|---|---|
| 탄막 채널링 | 코드 스킬(`ISkillBehavior`)로 만든다. `Tick`에서 틱마다 시전자 주변을 새로 탐색해 효과를 적용한다 (`SkillDashAttack` 방식). **재발동 시 같은 스킬이 이미 돌고 있으면 남은 시간만 갱신하는 분기**가 필요하다. 현재 `BeginBehavior`는 진행 중인 것을 종료하고 새로 시작한다 |
| 루프 모션 | 애니메이터에는 `Attack`/`Skill`/`Hit`/`Die` 트리거와 `IsMoving`/`IsCasting`/`Debuff` bool뿐이다. 채널링용 bool 파라미터와 루프 클립/상태를 새로 만든다 |
| 평타 모션 억제 | 탄막 중에는 평타의 `Attack` 트리거를 건너뛰고 효과만 낸다. 코드 스킬은 `beginAction`을 부르지 않아 `IsInAction`이 켜지지 않으므로 평타 자체는 막히지 않는다. 탄막에서 `BlockSkill`을 걸면 안 된다 |
| 코드 스킬 슬롯 | 유닛당 1개다. 쌍권총은 탄막이 유일한 코드 스킬이라 충돌이 없다 |
| 전탄발사 | 탄막 코드 스킬이 시작·갱신될 때 전탄 효과를 호출한다. 탄막 코드 스킬 안에서 전탄 스킬 보유 여부를 확인한다 |
| 이퀼리브리엄 | 활성 버프를 걸고, 온스윙 100% 추가 사격 스킬을 "활성 버프가 있을 때만 발동 시작" 선조건으로 만든다. 추가 사격 대상은 현재 타겟 외 가장 가까운 적을 우선 선정한다 |
| 온스윙 | 추가 사격이 `OnSwingHit` 발동 경로를 쓴다 (쌍검·룬검과 공용) |
| 수류탄 | 순간 단발 원형 피해. 던지는 연출은 짧게 한다. 좌표 고정(`Location`) 규칙을 쓴다 |
| 쉐도우스텝 | 쿨타임 기반 직접 시전(`Instant`) 자동 시전이다. `Stat_EvasionRate`(Percent, 상한 약 0.8)를 지속 동안 올리는 버프로 만든다 |
| 온히트 연쇄 | 평타와 추가 사격만 온히트를 켜고 나머지 데미지 효과는 모두 `FALSE`로 둔다 |

## 5. 석궁 (CrossBow)

### 5.1 컨셉

> **타락한 성기사 악마 사냥꾼 — 은화살로 낙인을 새기고, 성스러운 직선과 벼락으로 쓸고, 궁극기에서는 어둠을 쏟아붓는다**

- **장거리 단일 대상 사수**다. 평타는 현재 타겟 방향으로 나가는 **일자 직선 투사체 한 발**(비유도)이고, 맞을 때마다 대상에 약점이 쌓여 3번째 타격에서 터진다. 은화살은 **자주 터지는 단일 추가 데미지**다.
- 설정은 **서약을 어기고 어둠의 힘을 얻은 성기사**다. 1~4번은 성스러운 힘(은화살·홀리 디바이드·서약·천벌), 5~6번은 타락한 힘(나이트폴·다크 스트림)이다. 궁극기에서만 어둠으로 폭주한다는 대비를 연출에 쓴다.
- 범위는 세 갈래로 나눈다. 홀리 디바이드가 **긴 직선**, 나이트폴이 **넓은 전방 부채꼴**, 천벌이 **무작위 적 위치 3곳의 소범위 벼락**을 맡는다.
- 서약은 나를 따라다니는 오라다. 주변 적의 이동속도를 낮추고 내 공격력을 올린다.
- 6번 다크 스트림은 **쿨타임으로 쓰는 시간제 폭주 구간**이다. 활성 중에는 평타가 **좁고 긴 어둠의 라인 단타**(교체 평타)로 바뀌고 기본 간격이 짧아 속사가 된다. **휴식 구간이 항상 있다.**
- 이동은 플레이어가 직접 조작하므로 강제 이동이 없다. 방어 스킬도 두지 않는다 (1.4절). 서약의 이동속도 감소는 적을 약화하는 유틸이고 내 방어 수치를 올리지 않으므로 예외가 아니다.

### 5.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 효과 |
|---|---|---|---|
| 기본 | 석궁 사격 | 평타 | 장거리 **단일 대상** 일자 직선 투사체 1발 (비유도, 관통 없음) |
| 1 | 은화살 | 평타 온히트마다 | 맞은 대상에 약점 **+1**, **3번째 타격에서 터져** 단일 추가 데미지 |
| 2 | 홀리 디바이드 | N타 적중 (긴 주기) | 시전자 위치에서 현재 타겟 방향으로 **길고 좁은 직선 1히트** 강타 |
| 3 | 서약 | 오라 (틱마다) | 범위 안 **적의 이동속도 감소** + **내 공격력 증가** (상시) |
| 4 | 천벌 | 온스윙 30% `가안` | 주위 벼락 구체 3개에서 **무작위 적 위치 3곳**에 벼락. 작은 원형 1히트, 적이 1명뿐이면 3발 중첩 |
| 5 | 나이트폴 | N타 적중 (긴 주기, 10회 `가안`) | 시전자 중심 현재 타겟 방향 **넓은 전방 부채꼴 즉발 1히트** |
| 6 | 다크 스트림 | 쿨타임 (30초 `가안`) · 지속 10초 `가안` | 활성 중 평타가 **어둠의 라인 단타 교체 평타**로 바뀐다 (기본 간격 0.5초 `가안`, 온히트 켬) |

- 메인 스킬 6개는 모두 단독 노드다.
- 스킬 노드는 석궁 마스터리가 활성일 때만 동작한다.
- 모션은 평타와 교체 평타만 쓴다. 나머지는 모션 없이 이펙트만 나간다.

### 5.3 스킬 상세

#### 기본 공격 — 석궁 사격

- 사거리 안에 적이 있으면 자동으로 쏜다.
- **현재 타겟 방향**으로 **일자 직선 투사체 1발**을 쏜다. 유도하지 않고 발사 시점의 방향을 유지하며 **관통하지 않는다.**
- **평타 1회가 1카운트**이고, 온히트는 맞은 적마다 개별로 판정한다. 평타 효과가 온히트를 켠다.
- 평타는 은화살이 쌓이는 기점이며, 온스윙(천벌)과 N타 적중(홀리 디바이드·나이트폴)의 기준이다.

#### 은화살 (1)

**자주 터지는 단일 추가 데미지**다.

| 항목 | 내용 |
|---|---|
| 발동 | 평타가 **온히트**할 때마다 확정 (확률 판정 없음) |
| 약점 스택 | 맞은 **대상마다 따로** +1이 쌓인다. 시전자가 아니라 대상에 카운터가 있다 |
| 터짐 | **3번째 타격에서** 스택을 모두 소모하고 그 대상에게 **단일 추가 데미지**를 준다 |
| 쌓는 공격 | 평타와 다크 스트림 교체 평타 (온히트를 켜는 공격만) |
| 쌓지 않는 공격 | 은화살의 추가 데미지, 홀리 디바이드, 서약, 천벌, 나이트폴 |
| 대상 변경 | 리셋하지 않는다. 스택은 지속 시간 동안 대상에 남고 다시 맞히면 갱신된다 |
| 피해 기준 | 공격력 계수. 최대 체력 비례는 쓰지 않는다 |

- 잡몹은 3스택 전에 죽을 수 있어 보스·엘리트에 특히 강하다.
- 추가 데미지는 온히트를 켜지 않는다.

#### 홀리 디바이드 (2)

- **N타 적중(긴 주기)** 으로 발동한다.
- **시전자 위치에서 현재 타겟 방향**으로 성스러운 빛의 화살이 **길고 좁은 직선**을 1히트로 강타한다. 직선 안 적 전부가 대상이고 평타보다 훨씬 강하다.
- 모션 없이 이펙트만 나간다.
- **온히트를 켜지 않는다.** 약점도 쌓지 않는다.

#### 서약 (3)

**오라**로 만든 유틸 스킬이다. 몸에 두른 서약의 기운이 적을 묶고 나를 강하게 한다.

| 항목 | 내용 |
|---|---|
| 발동 | `Aura`. 일정 틱마다 스킬 전체를 다시 실행한다. 쿨타임이 없다 |
| 범위 | 시전자 중심 원형 |
| 적 효과 | 범위 안 적의 **이동속도 감소** (짧은 지속 디버프를 틱마다 갱신). 범위를 벗어나면 지속이 끝나며 풀린다 |
| 내 효과 | **공격력 증가.** 조건 없이 **상시**다. 범위 안에 적이 없어도 틱마다 짧은 지속 버프를 갱신한다 |

- 지속 버프의 지속 시간은 틱 간격보다 길게 두어 끊기지 않게 한다.
- 모션이 없고 온히트를 켜지 않는다.

#### 천벌 (4)

- 시전자 **주위에 벼락 구체 3개**가 떠 있다 (연출).
- 평타가 **온스윙**일 때 **30%** `가안` 확률로 발동한다. 스윙 1회당 한 번 굴리고, 맞은 적이 몇 명이든 판정은 한 번이다.
- 발동하면 **무작위 적 위치 3곳**에 벼락을 내리고, 각 위치에 **작은 원형 범위**를 1히트로 타격한다.

| 항목 | 내용 |
|---|---|
| 탐색 | 시전자 중심 원형 반경 (평타 사거리 정도) 안의 적 |
| 분배 | **서로 다른 적을 우선**하고 부족하면 중복으로 채운다. 3명 이상이면 1발씩, 2명이면 2+1, 1명이면 **3발 중첩** |
| 피해 | 벼락마다 작은 원형 1히트. 중첩 피해를 허용한다 |
| 온히트 | 켜지 않는다. 약점을 쌓지 않는다 |

- 벼락을 내리는 좌표는 선택 시점의 적 위치로 고정한다.
- 다크 스트림 중에는 교체 평타의 스윙이 2배 빠르므로 발동 빈도도 2배가 된다.

#### 나이트폴 (5)

- **N타 적중(긴 주기, 10회 `가안`)** 으로 발동한다.
- **시전자 중심, 현재 타겟 방향의 넓은 전방 부채꼴**에 밤이 내려앉듯 어둠을 덮어 **즉발 1히트**로 강타한다. 지연이나 경고 표시가 없다.
- 타겟이 움직이거나 다크 스트림 중이라 시야가 좁아도 시전자 기준이라 빗나가지 않는다.
- 모션 없이 이펙트만 나간다. **온히트를 켜지 않는다.**

#### 다크 스트림 (6)

**쿨타임으로 쓰는 시간제 폭주 구간**이다. **노드는 하나**다.

| 항목 | 내용 |
|---|---|
| 사용 | 쿨타임이 돌아오면 **버튼을 눌러** 쓴다. 버튼을 자동으로 누르는 기능(전투 중 자동 사용)을 추가할 예정이다 |
| 쿨타임 | 30초 `가안`, 사용하자마자 흐르기 시작한다. 쿨타임과 지속은 따로 흐른다 |
| 지속 | 10초 `가안` |
| 효과 | 지속 동안 평타가 **교체 평타**로 바뀐다 |

**교체 평타**

| 항목 | 내용 |
|---|---|
| 판정 | **좁고 긴 직선(어둠의 라인) 범위** 공격. 현재 타겟 방향, 시전자 위치에서 시작 |
| 타수 | **단타 1히트.** 직선 안 적 전부가 맞는다 |
| 온히트 | **켠다.** 맞은 적마다 개별로 판정한다 |
| 기본 간격 | **0.5초** `가안`. 평타의 기본 1초보다 짧아 속사가 된다 |
| 데미지 | 교체 평타 스킬 행에 **따로 정의**한다 |
| 카운트 | 평타로 취급한다. 교체 평타 1회가 1카운트이고 온스윙도 판정한다 |

- 너무 빠르게 날아가 어둠의 줄처럼 보이는 속사가 콘셉트다. 연출은 성스러운 빛이 어둠으로 바뀌는 색 변화를 쓴다.
- 공속 상한 확장이나 최종 데미지 증감은 쓰지 않는다. **속도와 데미지는 교체 평타 행에서만 조정**한다.
- 교체 평타의 간격이 절반이라 N타 적중(홀리 디바이드·나이트폴)과 온스윙(천벌)의 발동 빈도가 약 2배가 된다.
- 은화살은 교체 평타에서도 쌓인다. 직선 안 적마다 개별로 +1이다.
- 나중에 "특정 행위가 일어나면 쿨타임을 초 단위·퍼센트로 줄이는" 기능이 추가될 예정이다. 다크 스트림 쿨타임 제어는 이 기능으로 별도 설계한다.

### 5.4 규칙과 안전장치

| 규칙 | 내용 |
|---|---|
| 온히트를 켜는 곳 | **평타와 다크 스트림 교체 평타만.** 은화살 추가 데미지·홀리 디바이드·서약·천벌·나이트폴은 모두 끈다 |
| 다단히트 금지 | 다단히트(`HitCount > 1`)에는 온히트를 켜지 않는다. 천벌의 벼락은 각각 1히트다 |
| 약점 스택 폭주 방지 | 약점을 쌓는 것은 온히트를 켜는 평타뿐이므로 N타 적중·온스윙 스킬이 스택을 늘리지 않는다 |
| 천벌 | 온스윙 판정은 스윙당 한 번이다. 벼락 3발은 한 번의 발동이다 |
| N타 카운터 공유 | 홀리 디바이드와 나이트폴은 같은 평타 적중 카운터를 쓴다. 주기가 겹치지 않게 정한다 (쌍검과 같은 규칙) |
| 폭주 휴식 | 다크 스트림은 쿨타임과 지속이 따로 흘러 휴식 구간이 항상 있다 (30/10이면 20초) |
| 순환 | 온히트를 켜는 것이 평타와 교체 평타뿐이라 순환이 생기지 않는다 |

### 5.5 구현 시 확인할 사항

| 항목 | 내용 |
|---|---|
| 평타 투사체 | 현재 `PJT_CrossBow_Bolt` 가 관통 1이다. 평타용은 **관통 0, 비유도**로 바꾼다 |
| 평타 적중 기준 | 비유도 직선이라 타겟이 움직이면 빗나갈 수 있다. N타 적중·온스윙·약점은 모두 **적중 기준**이므로 빗나간 발은 세지 않는다. 투사체 속도를 빠르게 두어 빗나감을 줄인다 |
| 은화살 | 대상에게 거는 스택형 디버프로 관리한다. **3번째에 스택을 소모해 발동하는 경로**가 필요하다. 현재 `BuffConsume` 은 시전자 버프 기준이다 |
| 홀리 디바이드·나이트폴 | 기존 `OnCombo` + `Line`/`Sector` 로 된다. 카운터를 공유하므로 주기의 배수 관계를 정한다. 방향은 현재 타겟 방향이다 |
| 서약 | `Aura`(주기 틱)로 만든다. 한 스킬이 **범위 안 적에게 디버프**와 **시전자 자신에게 버프**를 함께 거는 구성이 되는지 확인한다. 룬검 심안이 같은 `Aura` 방식이다 |
| 천벌 — 발동 | `OnSwingHit` 발동 경로를 쓴다 (쌍검·룬검·쌍권총과 공용) |
| 천벌 — 대상 선정 | 시전자 중심 원형 안의 적에서 **서로 다른 적 우선, 부족하면 중복**으로 3곳을 고르는 로직이 신규다 |
| 천벌 — 구체 | 구체 3개는 연출이다. 기존 소환의 Orbit(쌍검 패시브의 `Summon_Spark`)을 재사용할 수 있는지 확인한다. 석궁 마스터리가 활성일 때만 소환한다 |
| 다크 스트림 — 평타 교체 | 신규. 버프가 있는 동안 `GetBasicAttack()` 이 교체 평타를 반환하게 하거나, 평타 스킬의 판정과 `Cooldown` 을 덮어쓴다. 평타 간격은 `Cooldown / Stat_AtkSpeed` 이므로 교체 평타 행의 `Cooldown` 을 0.5로 두면 된다 |
| 다크 스트림 — 모션 | 평타 간격이 짧아지면 `GetActionTime` 이 모션 길이와 사이클 중 짧은 쪽을 쓴다. 교체 평타용 짧은 모션이나 모션 없는 발사를 쓴다 |
| 다크 스트림 — 사용 | 쿨타임 기반 직접 시전(`Instant`)이다. 버튼 사용과 자동 사용 기능은 전투 UI 쪽 작업이다 |
| 온히트 연쇄 | 평타와 교체 평타만 온히트를 켜고 나머지 데미지 효과는 모두 `FALSE`로 둔다 |

## 6. 구현 시 확인할 사항 (쌍검)

현재 시스템에서 바로 되지 않는 항목만 모았다. 문서 확정 후 구현 단계에서 다룬다. 룬검·쌍권총·석궁은 각 절의 구현 확인 표(3.6, 4.5, 5.5절)를 본다.

| 항목 | 내용 |
|---|---|
| 스팅어·퓨리 | 기존 `OnCombo`로 된다. 카운터를 공유하므로 두 주기의 배수 관계가 겹치지 않게 정한다. 방향은 시전자 조준 방향(현재 타겟)을 쓰므로 `Line`/`Sector`가 별도 처리 없이 타겟을 향한다 |
| 팬텀 디바이드 | `OnSwingHit` 발동 경로가 필요하다. enum 값은 추가되어 있으나 `SkillContainer`에서 쓰는 곳이 없다. 평타 스윙 집계가 끝난 뒤 스윙당 1회 확률을 굴리고, 방향은 현재 타겟 방향이다 (`OnCombo`의 통지 경로를 따른다) |
| 페이탈 어택 | 맞은 대상의 체력 비율을 조건으로 쓰는 발동 경로가 필요하다. 평타 효과가 `OnHitTrigger`로 부르며, 평타 피해가 들어간 뒤의 체력으로 판정한다. 기준 비율은 노드 레벨에서 가져온다. 현재 `OnLowHP`는 시전자 체력만 본다 |
| 소드실드 | 평타 적중 시 버프 스택 +1. `Stat_BlockRate`(Percent, 상한 약 0.8)를 쓰는 버프이고 스택 정책은 `IndependentShared`가 맞다. 막기 판정은 회피 뒤에 하고 성공하면 피해가 0이다 |
| 오버드라이브 — 공속 상한 | 공속 상한은 스탯 정의의 `MaxValue`(`Stat_AtkSpeed` 0.1~3)라서 버프로 직접 올릴 수 없다. **상한 보너스 스탯**(가칭 `Stat_AtkSpeedCapBonus`)을 새로 만들고 공속 클램프가 이 값을 더해 쓰게 한다. 애니메이션 상한(5.0)에는 걸리지 않는다 |
| 오버드라이브 — 공속 고정 | 상한 보너스와 함께 공속을 크게 올리는 가산 버프를 걸어, 클램프에서 상한값에 붙게 한다 |
| 오버드라이브 — 사용 | 쿨타임 기반 직접 시전(`Instant`)이다. 버튼 사용과 자동 사용 기능은 전투 UI 쪽 작업이다 |
| 온히트 연쇄 | 평타만 온히트를 켠다. 나머지 스킬의 데미지 효과는 모두 `FALSE`로 둔다. 페이탈 어택의 추가 데미지도 `FALSE`다. 평타는 단발이어야 한다 |
