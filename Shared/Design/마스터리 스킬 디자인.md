# 마스터리 스킬 디자인

*무기 마스터리별 스킬 컨셉 · 구성 | 2D 탑다운 핵앤슬래시 · 싱글플레이 · Unity C#*

> **이 문서는 컨셉과 스킬 구성만 다룬다.** 확률·데미지·범위 크기·주기·지속시간 같은 **수치는 확정하지 않는다.** 밸런스 단계에서 바뀔 가능성이 높기 때문이다. 문서에 수치가 보이면 방향을 설명하는 `가안`이며, 테이블 작성 단계에서 다시 정한다.
>
> 기존 쌍검 스킬(콤보 액티브, 스파크 소환, 기존 18노드 트리)은 고려하지 않는다. 새 스킬 세트로 전면 교체한다는 전제다.

**목차**

1. 설계 전제
2. 쌍검 (DualBlades)
3. 룬검 (RuneSword)
4. 쌍권총 (DualPistols)
5. 구현 시 확인할 사항 (쌍검)
6. 미정 항목

## 1. 설계 전제

### 1.1 마스터리당 스킬 구성

| 구분 | 개수 | 비고 |
|---|---|---|
| 기본 공격 | 1 | 평타. 공속 배율을 받는 유일한 스킬 |
| 메인 스킬 | 6 | 스킬 트리의 습득 노드로 배운다 |

이후 단계에서 각 스킬에 강화 노드를 붙여 확장한다. 이 문서는 **어떤 스킬을 만들지**만 정한다.

### 1.2 마스터리 정체성

직업 개념이 없으므로 무기마다 전투 방식이 구분되어야 한다. 구분 축은 **범위 형태**다.

| 무기 | 범위 형태 | 보상 |
|---|---|---|
| 쌍검 | 부채꼴·직선 위주, 범위가 작다 | 범위가 좁은 대신 데미지를 높게 잡는다 |
| 룬검 | 원형·착탄 폭발 등 **범위기 위주** | 범위기에 강한 마스터리 |
| 쌍권총 | 중거리 2발 동시 평타 + 특수탄 폭발·관통·연쇄, 수류탄, 원형 난사 | 평타를 특수탄이 범위로 번지게 한다 |
| 다른 무기 | 원형 범위 위주 | ‒ |

### 1.3 발동 방식 용어

| 용어 | 시스템 대응 | 설명 |
|---|---|---|
| N타 적중 | `OnCombo` | 평타가 **실제로 적중**한 횟수. 스윙 1회 = 1카운트이고 여러 명을 맞춰도 1이다 |
| 온히트 시 확률 | `OnHit` | `SkillEffect.OnHitTrigger = TRUE` 인 효과가 **적중할 때** 확률로 발동. 온히트를 켜는 공격은 마스터리마다 정한다 |

쌍검과 룬검은 온히트를 켜는 공격이 평타뿐이라 "평타 적중 시"와 "온히트 시"가 같은 뜻이다. 쌍권총도 평타의 발만 온히트를 켠다 (4.4절).

### 1.4 공통 전제

| 전제 | 내용 |
|---|---|
| 치명타율·공속 | 모든 캐릭터가 **치명타율 100%** 와 **공격 속도 300%** 에 어렵지 않게 도달하도록 설계한다. 쌍검만 가속 패시브로 공속 상한이 최대 350%다. 그래서 치명타율 증가 효과는 가치가 낮고 치명타 피해가 데미지 배율의 중심이 된다 |
| 이동 | 이동은 플레이어가 **직접 조작**한다. 스킬이 캐릭터를 강제로 이동시키지 않는다 |
| 방어 스킬 | 현재 모든 마스터리에서 **방어 스킬을 두지 않는다.** 공격 컨셉을 먼저 정한 뒤 필요하면 다시 검토한다. 방어 스킬이 있던 자리는 쌍검 3번이 가속으로 채워졌고 쌍권총 4번은 비어 있다 |
| 추가 게이지 | 마스터리의 폭주 구간은 **공통 게이지 위젯**으로 보여 준다. 충전 기준만 마스터리마다 다르다: 쌍검은 평타 적중 횟수, 쌍권총은 쿨타임 진행도. 룬검 개방은 확률 발동이라 폭주 게이지가 없다 (검기 스택은 별도 자원) |
| 폭주 구간 규칙 | 3개 마스터리의 6번은 모두 **가끔 오는 시간제 폭주 구간**이다. 지속 시간이 끝나면 반드시 휴식 구간이 있고, 상시 발동 수단은 두지 않는다. 마스터리마다 발동 방식이 다르다: 쌍검 = 평타 N번 타격, 룬검 = 온히트 시 확률(쿨타임 ≥ 지속), 쌍권총 = 쿨타임 + 전투 중 자동 발동 |
| 전투 중 상태 | **공용 시스템.** 피해를 주거나 받으면 전투 중이 되고, 마지막 전투 행동 후 10초(`가안`) 동안 없으면 해제된다. 1.5절 참고 |

### 1.5 전투 중 상태 (공용 시스템)

마스터리와 무관한 **공용 시스템**이다. 전투 중에만 처리할 항목은 이 시스템에 붙인다.

| 항목 | 내용 |
|---|---|
| 진입 | 피해를 **주거나 받으면** 전투 중이 된다 |
| 해제 | 마지막 전투 행동(주거나 받음) 이후 **10초**(`가안`) 동안 아무 일도 없으면 해제된다 |
| 갱신 | 전투 행동이 있을 때마다 해제 시한이 새로 시작된다 |

**전투 중에 처리하는 항목**

| 항목 | 내용 |
|---|---|
| 쌍권총 6번 전탄발사 | 쿨타임이 돌아와 있고 전투 중이면 자동 발동 (4.3절) |
| 추후 추가 | 전투 중에만 동작해야 하는 항목이 생기면 여기에 더한다 |

- 구현은 "마지막 전투 행동 시각"을 저장하고 지금 시각과 비교하는 방식이 단순하다. 매 프레임 카운터를 돌릴 필요가 없다.
- 시각 갱신은 피해를 주고받는 처리 지점에서 한다. 스킬 발동 경로(`OnDamaged` 등)와는 별개라 그 경로가 미연결이어도 영향이 없다.
- 해제 시간, 장시간 보스전 예외, 무적 같은 특수 상태에서의 처리는 `미정`이다.

## 2. 쌍검 (DualBlades)

### 2.1 컨셉

> **연타 + 보스 딜러**

- **연타**: 평타를 계속 적중시키는 것이 곧 스킬 발동 조건이다. 공속이 곧 딜이 된다.
- **보스 딜러**: 한 대상에게 공격이 몰리는 구조. 대상이 적을수록 처형이 한 대상에게 집중된다.
- 범위는 작게, 데미지는 높게. 광역은 다른 무기에 맡기고 쌍검은 좁고 깊게 간다.

### 2.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 범위 | 역할 |
|---|---|---|---|---|
| 기본 | 기본 공격 | 평타 | 전방 작은 부채꼴 | 카운트·확률 발동의 기점 |
| 1 | 일섬 | N타 적중 (짧은 주기) | 직선 | 빠르게 도는 직선 공격 |
| 2 | 난무 | N타 적중 (중간 주기) | 중간 원형 | 주변 정리 |
| 3 | 가속 | 패시브 (노드 1개, 5레벨) | 자신 | 레벨마다 공속 상한 +10%p (최대 350%) |
| 4 | 처형 | N타 적중 (긴 주기) | 원형 탐색 → 랜덤 다수 | 보스 집중 딜 |
| 5 | 공간참 | 온히트 시 낮은 확률 | 전방 큰 부채꼴 | 드물게 터지는 큰 한 방 |
| 6 | 초각성 | 게이지 (평타 N번 타격) | 자신 | 활성 중 확률·카운트 2배 |

주기는 **일섬 < 난무 < 처형** 순으로 길어지고, 서로 겹치는 일이 드물게 한다. 구체적인 타수는 `미정`이다.

### 2.3 스킬 상세

#### 기본 공격

- 전방 **작은 부채꼴** 범위의 근접 단발 공격.
- 이 공격의 적중이 모든 카운트·확률 발동의 기점이다. 평타 효과만 온히트를 켠다.

#### 일섬

- 평타가 일정 횟수 적중할 때마다 발동한다 (가장 짧은 주기).
- **직선** 범위를 타격한다.

#### 난무

- 평타가 일정 횟수 적중할 때마다 발동한다 (중간 주기).
- **중간 크기 원형** 범위를 타격한다. 쌍검에서 유일한 원형 범위다.

#### 가속

- **패시브**다. 버프가 아니라 **배울수록 영구히 늘어난다.**
- **노드 하나에 5레벨**이고, 레벨마다 **공격 속도 상한이 +10%p** 오른다. 최대 +50%p, 즉 **300% → 350%**다 (정해진 값).
- 공속 자체를 올려 주는 것이 아니라 **상한만 늘린다.** 상한은 장비·옵션으로 쌓은 공속 합계가 300%를 넘을 때 의미가 있다. 공속을 쌓는 연타 마스터리라는 쌍검의 정체성과 맞는다.
- 방어 요소는 없다.

#### 처형

- 평타가 일정 횟수 적중할 때마다 발동한다 (가장 긴 주기).
- 동작 순서

```
1. 시전자 중심 원형 범위 안의 적을 탐색한다
2. 그중 여러 체를 랜덤으로 선정한다 (최대 수는 가안 5체)
3. 선정된 적의 위치마다 작은 원형 범위 데미지를 입힌다
```

- **대상이 최대 수보다 적으면 중첩한다.** 타격 횟수를 선정된 대상에게 돌려가며 배분한다. 예: 최대 5회에 대상이 1체면 5회 전부 그 대상에게 들어간다.
- 보스 1체와 싸울 때 모든 타격이 보스에게 들어가므로 **보스 딜러 컨셉의 핵심 스킬**이다. 잡몹이 많으면 분산된다.

#### 공간참

- 온히트 시 **낮은 확률**로 발동한다 (가안 5%).
- 전방 **큰 부채꼴** 범위를 타격한다. 쌍검에서 가장 넓고 가장 드문 공격이다.

#### 초각성

**평타 N번 타격으로 게이지를 채워 터뜨리는 시간제 폭주 구간**이다. **노드는 하나**다.

```
채우는 중   평타가 적중할 때마다 게이지가 차오른다 (필요 타수 N은 미정)
발동        가득 차면 자동 발동. 게이지가 빛난다
종료        지속 시간이 끝나면 게이지가 0으로 줄어들고 다시 채운다
```

| 효과 | 내용 |
|---|---|
| 확률 2배 | 활성 중 공간참의 발동 확률이 **2배**가 된다 (100% 상한) |
| 카운트 2배 | 활성 중 평타 1회 적중에 콤보 카운터가 **2** 오른다. 일섬·난무·처형이 두 배로 자주 나간다 |

- **카운트 스킬의 주기는 항상 짝수로 둔다.** 카운트 2배가 정수 연산으로 맞도록 하기 위한 규칙이며, 수치를 바꿀 때도 지킨다.
- **카운터가 두 종류다.** N타 스킬용 **콤보 카운터**(공유, 리셋 없음, 활성 중 2배)와 초각성용 **폭주 게이지**(리셋됨)다. 폭주 게이지는 **평타 적중 횟수 그대로** 세며 카운트 2배의 영향을 받지 않는다.
- **상시 발동은 하지 않는다.** 지속이 끝나면 게이지가 0에서 다시 시작하므로 휴식 구간이 항상 있다. 후반 성장은 N 감소와 지속 증가로 하되 휴식이 사라지지 않도록 N의 하한을 밸런스 규칙으로 둔다. N은 공속 300%가 표준이라는 전제(1.4절)에서 정한다.
- 이 게이지는 1.4절의 공통 게이지 위젯의 사례다.

## 3. 룬검 (RuneSword)

### 3.1 컨셉

> **마검사 → 검기를 쌓아 쓰는 검사**

- **초반 — 마검사**: 룬을 두른 검으로 직접 휘둘러 범위기를 터뜨린다. 검기와 무관하게 완결되는 스킬이다.
- **후반 — 검기 사용**: 검기를 모아 **등 뒤에 룬검으로 띄우고**, 칼질하면서 그 검기를 소모해 사출·제왕검으로 터뜨린다. 캐릭터가 원거리 유닛이 되지 않는다.
- 소환물은 쓰지 않는다. 등 뒤에 보이는 룬검은 검기 스택을 눈으로 보여 주는 표시다.
- 룬검은 **범위기에 강한 마스터리**다.
- 순환 구조: **모으기(충전) → 쓰기(소모) → 폭주(소모 없음 + 증폭)**. 모아 두면 공격력 증폭이 붙고, 쓰면 강한 공격이 나가며, 6번이 켜지면 쓰면서도 줄지 않는다.
- 방어 스킬은 두지 않는다 (1.4절).

### 3.2 스킬 구성 한눈에 보기

| # | 단계 | 이름 | 발동 | 효과 |
|---|---|---|---|---|
| 기본 | 초반 | 룬 베기 | 평타 | **쌍검보다 큰 부채꼴** 근접 범위 공격 |
| 1 | 초반 | 룬 폭발 | N타 적중 | **적 위치** 기준 원형 범위 공격 |
| 2 | 후반 | 검기 충전 | 온히트 시 확률 | 검기 **+1** (등 뒤 룬검 1개 생성). 스택당 공격력 증폭 +2% (`가안`), 최대 5 |
| 3 | 후반 | 룬 진동 (가칭) | **n초마다 (전투 중)** | 캐릭터 주위 **원형 범위 피해 + 검기 충전**. 검기가 최대면 피해 **×1.5** (`가안`) |
| 4 | 후반 | 검 사출 | 온히트 시 확률, 검기 보유 | 검기 1개 소모, 목표 지점에서 **원형 폭발** |
| 5 | 후반 | 제왕검 | 온히트 시 확률, 검기 보유 | 검기 1개 소모, 전방 **라인형 넓은 범위** 데미지 1회 |
| 6 | 후반 | 검 개방 | 온히트 시 확률 (쿨타임 ≥ 지속) | 궁극기. **검기 소모 없음 + 최종 데미지 증폭** |

- 초반 스킬(1)은 검기를 쓰지 않는다. 후반 스킬(2~6)이 검기 계열이다.
- 모든 메인 스킬은 단독 노드다.

### 3.3 검기 시스템

| 용어 | 뜻 |
|---|---|
| **검기** | 소비·충전의 대상이 되는 자원. 버프 스택으로 구현한다 |
| **룬검** | 검기 스택 수만큼 등 뒤에 떠 있는 검. 스택을 눈으로 보여 주는 표시이며 소환물이 아니다 |

| 항목 | 내용 |
|---|---|
| 보유 수 | 최대 5개 (`가안`) |
| 보유 보상 | 스택 1개당 **공격력 증폭 +2%** (`가안`), 최대 +10% |
| 충전 경로 | 두 가지: **검기 충전**(2번, 온히트 시 확률 +1)과 **룬 진동**(3번, n초마다 +1) |
| 소모 | **검 사출**과 **제왕검**이 각각 검기 1개를 소모한다. 둘 다 확률 발동이라 서로 같은 조건에서 경쟁하며 한쪽만 굶지 않는다 |
| 최대치 보상 | 최대치에서는 충전이 낭비되므로 **룬 진동의 피해가 ×1.5**가 된다 (`가안`) |
| 6번 중 | 검기가 줄지 않아 최대치가 유지된다. 공격력 증폭 +10%와 진동 ×1.5가 계속 적용된다 |

- **쓸까, 모을까**: 검기를 모아 두면 공격력 증폭과 진동 보너스를 받고, 사출·제왕검으로 쓰면 강한 공격이 나가지만 보상이 줄어든다.
- **충전 경로가 두 개인 이유**: 적중에 의존하는 확률 충전과, 적중과 무관한 주기 충전이 서로 보완한다. 평타가 끊겨도 검기가 모인다.
- 균형 기준은 `평균 충전량(2번 + 3번) ≥ 평균 소모(4번 + 5번)` 이다. 수치는 밸런스 단계에서 정한다.

### 3.4 스킬 상세

#### 기본 공격 — 룬 베기

- 전방 **큰 부채꼴** 근접 범위 공격. 쌍검 평타보다 넓다.
- 단발이며, 적중이 충전·소모·폭주 발동의 기점이다. **평타 효과만 온히트를 켠다.**

#### 룬 폭발 (1)

- 평타가 일정 횟수 적중할 때마다 발동한다.
- **대상 적의 위치**를 중심으로 원형 범위를 타격한다. 주기는 `미정`.

#### 검기 충전 (2)

- 온히트 시 **확률로** 검기를 **+1** 충전한다. 충전과 동시에 등 뒤에 룬검이 하나 생긴다.
- 검기는 스택 1개당 공격력 증폭 +2%(`가안`)를 주며 최대 5스택이다.
- 충전량은 +1 고정이다. 충전 확률과 룬 진동의 주기로 공급량을 조절한다.

#### 룬 진동 (3)

- **n초마다** 자동 발동한다. 전투 중에만 돈다 (1.5절).
- 캐릭터 주위 **원형 범위**에 피해를 주고 검기를 +1 충전한다.
- **검기가 이미 최대치일 때**는 충전이 낭비되므로 그 틱의 피해가 **×1.5**가 된다. 최대치에서의 충전을 보상으로 바꾼 규칙이다.
- 사출과 제왕검에는 이런 최대치 보너스가 없다.
- 전투 중에만 도는 이유: 전투 밖에서도 돌면 전투 시작 때 항상 검기가 최대가 되어 모으고 쓰는 긴장이 약해진다.

#### 검 사출 (4)

- 온히트 시 **확률로** 발동한다. 검기가 있어야 한다.
- 동작 순서

```
1. 온히트 시 확률 판정
2. 통과하고 검기가 있으면 검기 1개를 소모한다 (검기가 없으면 아무 일도 일어나지 않는다)
3. 등 뒤의 룬검이 적을 향해 날아간다
4. 목표 지점(적 위치) 땅에 닿으면 원형 범위로 폭발한다
```

- 검기 1개당 폭발 1회다.

#### 제왕검 (5)

- 온히트 시 **확률로** 발동한다. 검기가 있어야 한다.
- 검기 1개를 소모하고 전방 **라인형 넓은 범위**에 데미지를 **1회** 준다 (단발).

#### 검 개방 (6)

- 룬검의 **궁극기**다. 온히트 시 확률로 발동한다.
- 효과

| 효과 | 내용 |
|---|---|
| 검기 소모 없음 | 사출·제왕검이 검기를 소모하지 않는다 |
| 최종 데미지 증폭 | 시전자의 **모든 데미지**에 적용된다. 수치는 작게 시작한다 |

- **지속 시간 N초(`미정`)** 동안 유지된다.
- **유지되는 동안은 재발동하지 않는다.** 확률 판정 자체를 건너뛰며, 지속 시간을 연장하거나 갱신하지 않는다. 지속이 끝나면 다시 온히트 시 확률 판정을 시작한다. 폭주가 끊김 없이 이어지는 "무한 발동"을 막기 위한 규칙이다.
- 활성 중에는 검기가 줄지 않아 **최대치가 유지**되므로 공격력 증폭 +10%와 진동 ×1.5가 계속 적용된다. 별도 장치 없이 기존 규칙의 합으로 폭주 효과가 만들어진다.
- 곱해지는 요소가 많으므로 최종 데미지 증폭 수치는 작게 시작해 총량을 점검한다.
- 평타 범위 증가는 넣지 않는다. 구현이 어렵기 때문이다 (3.6 참고).

### 3.5 온히트 시 판정되는 스킬

| 스킬 | 판정 |
|---|---|
| 검기 충전 (2) | 확률 |
| 검 사출 (4) | 확률 (검기 보유 시) |
| 제왕검 (5) | 확률 (검기 보유 시) |
| 검 개방 (6) | 확률 (활성 중에는 판정하지 않음) |

- 룬 폭발(1)은 N타 적중 기준, 룬 진동(3)은 주기 기준이라 이 표와 별개다.
- 평타 한 번에 최대 네 가지가 동시에 나갈 수 있다. 각자 독립적으로 판정한다.

### 3.6 구현 시 확인할 사항

| 항목 | 내용 |
|---|---|
| 검기 = 버프 스택 | 검기를 버프 스택(최대 5)으로 관리하고 스택마다 공격력 증폭 효과를 붙인다. 시간이 지나도 사라지지 않아야 하므로 **만료 없는 지속시간**이 가능한지 확인한다. 안 되면 아주 긴 지속시간으로 대체한다 |
| 소모 게이트 | `BuffConsume`(스택 소모, 성공 시 `ChainEffectIDs` 실행)로 "검기가 있을 때만 발동"을 만든다. 코드는 있으나 **실제 데이터 행이 0개**다 |
| 소모 면제 분기 | "버프가 있으면 소모를 건너뛴다"는 분기는 현재 없다. 신규 작업이다 |
| 룬 진동 | 주기 발동(`Aura`)과 전투 중 조건, 검기 스택 확인(최대일 때 배율 ×1.5 전달)이 필요해 **코드 스킬**로 만든다. 시전 시점에 배율을 스냅샷으로 넘기는 구조가 이미 있다 |
| 제왕검 | 전방 라인 범위를 단발로 타격한다. 라인 폭과 길이는 탐색 형태(`Line`)의 파라미터로 정한다 |
| 착탄 폭발 | 투사체의 착탄 폭발 속성을 사용한다. 목표 지점이 적 위치가 되도록 하는 방식은 구현 단계에서 정한다 |
| 등 뒤 룬검 비주얼 | 스택 수에 맞춰 등 뒤 룬검 개수를 표시하는 연출이 필요하다. 시스템에 없는 신규 작업이다 |
| 온히트 연쇄 | 평타만 온히트를 켠다. 나머지 스킬의 데미지 효과는 모두 **FALSE** 로 둔다. TRUE 이면 스킬이 다시 확률을 굴린다. 평타는 단발이어야 한다 |
| 재발동 방지 (검 개방) | 확률 발동 판정은 쿨타임 중인 스킬을 제외하고, 발동하면 그 스킬의 쿨타임을 시작한다. **검 개방의 쿨타임을 버프 지속시간 이상으로 설정**하면 활성 중에는 판정에서 빠진다. 쿨타임은 공속 배율을 받지 않는 실제 시간이다 |
| 특정 스킬만 증폭 불가 | 공격력 증폭·피해 보너스·최종 증폭은 모두 시전자의 모든 데미지에 걸린다. 스킬별 증폭은 스킬 트리 노드·장비의 `SkillModifier`로만 가능하고 버프에는 붙일 수 없다 |
| 평타 범위 증가 불가 | 범위 스탯이 없고 버프가 스킬 변형값을 붙이는 경로도 없다. 구현하려면 "버프 → 변형값 → 스킬 재계산 + 이펙트 크기 동기화"를 새로 만들어야 해서 보류했다 |
| 충전 조건 제약 | 처치 시(`OnKill`)는 발동 경로가 연결되지 않았으므로 조건으로 쓰지 않는다 |

### 3.7 채택하지 않은 안

| 안 | 이유 |
|---|---|
| 룬 방패 (공격력 + 막기 버프) | 방어 스킬을 모든 마스터리에서 제거했다 |
| 소환 룬검 (날아다니는 소환물) | 검기 스택으로 단순화했다. 소환물 AI와 환급 연동 작업이 사라졌다 |
| 검기 베기 (쿨타임 5초 확정) | 제왕검(확률 발동, 단발 라인)으로 대체했다 |
| 충전 연쇄 판정 (+1~3) | 충전량은 +1 고정으로 하고 공급은 두 경로와 확률로 조절한다 |
| 평타를 검 발사로 일시 교체 | 컨셉이 "칼질하면서 검이 거든다"이고, 평타 일시 교체 경로가 새로 필요하다 |
| 검 개방의 사출 빈도 증가·주기 발사·검 비·거대 룬검 마무리 | 소모 없음 + 최종 증폭으로 단순화했다 |
| 사출·제왕검의 최대치 보너스 | 보너스는 룬 진동에만 둔다 (최대치 충전 낭비의 보상) |
| 소모 없음만 두는 검 개방 | 체감이 약할 수 있어 최종 증폭을 작게 유지한다 |

## 4. 쌍권총 (DualPistols)

### 4.1 컨셉

> **특수탄 사수 — 두 정으로 쏘는 평타에 특수탄이 터져 범위를 만들고, 수류탄·탄막·도탄으로 쓸어낸다**

- **중거리 범위 딜러**다. 평타는 두 정이 동시에 쏘는 사격(가까운 최대 2체)이고, 온히트마다 확률로 터지는 **특수탄**이 폭발·관통·연쇄로 범위를 만든다.
- **여러 종류의 특수탄**(폭발탄, 관통탄, 도탄)이 기본 축이다. 수류탄과 탄막 난사가 캐릭터 주위를 쓸고, 6번 전탄발사가 탄막을 폭주시킨다.
- 6번은 **전투 중 쿨타임마다 켜지는 시간제 폭주 구간**이다. 활성 중에는 탄막이 터질 때마다 전탄이 발사되고 그 적중이 온히트를 일으킨다. **휴식 구간이 항상 있다.**
- 마스터리 보너스가 치명타 피해(`OPT_CRIT_DAMAGE_ADD`)다. 치명타율은 100%에 가까운 전제(1.4절)이므로 치명타 피해가 곧 데미지 배율이다.
- 직접 이동을 조작하므로 **강제 이동이 없다.** 방어 스킬도 두지 않는다 (1.4절). "적 사이를 누빈다"는 인상은 총알(관통탄, 도탄)이 맡는다.

### 4.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 효과 |
|---|---|---|---|
| 기본 | 쌍총 사격 | 평타 | 중거리. 가까운 **최대 2체**에 한 발씩 동시 사격. 대상이 1체면 그 1체에 2발 (중복 조준) |
| 1 | 폭발탄 (특수탄) | 온히트 시 확률 | 특수탄이 **대상 위치에서 소범위 폭발** |
| 2 | 탄막 난사 | 온히트 시 확률 | **모션 있음.** 캐릭터 중심 원형으로 돌면서 다단히트가 지속된다. 평타와 병행. 재발동 시 지속 갱신 |
| 3 | 관통탄 (특수탄) | 온히트 시 확률 | 다른 종류의 특수탄. **관통 발사체**가 직선상의 적에게 데미지 |
| 4 | 수류탄 | 온히트 시 확률 | 수류탄을 던져 **캐릭터 주위 원형 범위** 데미지 (순간 단발) |
| 5 | 도탄 사격 (특수탄) | 온히트 시 확률 | 쏜 총알이 적에게 맞고 **튕겨 주변 적을 차례로 연쇄 타격** |
| 6 | 전탄발사 | 쿨타임 + 전투 중 자동 발동 | 활성 중 탄막이 발동할 때마다 캐릭터 주위 **원형 범위 1히트 피해**, **온히트 켬** |

- 메인 스킬 6개는 모두 단독 노드다. 특수탄 종류는 폭발탄(1), 관통탄(3), 도탄(5)이다. 네 번째 이후는 노드 확장으로 둔다.

### 4.3 스킬 상세

#### 기본 공격 — 쌍총 사격

- 사거리 안에서 **가까운 순으로 최대 2체**를 골라 **한 발씩 동시에** 쏜다. 쌍권총의 두 정이 함께 쏘는 모습이다.
- **대상이 1체뿐이면 그 1체에 2발**이 들어간다 (중복 조준).
- 모든 발은 **단발 1히트**다. **온히트 판정은 발마다** 하므로 평타 한 번에 최대 2번이다.
- 평타의 발만 온히트를 켠다 (6번 활성 중의 전탄발사는 예외, 4.4절).
- 평소 특수탄이 자주 터지므로 발동 확률은 낮게 시작한다.

#### 폭발탄 (1)

- 온히트 시 확률로 **특수탄**을 쏜다.
- 특수탄은 **대상 위치에서 소범위로 폭발**한다. 평타는 두 대상을 쏘지만 특수탄이 터지면서 주변까지 번지는 것이 "단일 → 범위" 변환이다.

#### 탄막 난사 (2)

- 온히트 시 확률로 발동한다. 캐릭터가 **돌면서 주위에 총질**하는 느낌이며(데빌헌터 스타일), **캐릭터 중심 원형 범위 안의 적 모두**를 다단히트한다.
- **탄막 연출만 쓰고 실제 발사체는 쏘지 않는다.**
- **모션이 나오고**, 그 동안 평타는 모션 없이 데미지만 계속 들어간다. 평타가 멈추지 않으므로 온히트 루프가 유지된다.
- 탄막이 진행 중일 때 확률이 다시 걸려 재발동하면 새로 겹치지 않고 **남은 지속 시간을 갱신**한다.
- 탄막의 타격은 온히트를 켜지 않는다.
- 이동은 플레이어 조작이므로 막지 않는다.

#### 관통탄 (3)

- 온히트 시 확률로 **다른 종류의 특수탄**을 쏜다.
- 관통 발사체가 대상을 뚫고 지나가며 **직선상의 적 모두**에게 데미지를 준다.

#### 수류탄 (4)

- 온히트 시 확률로 수류탄을 던져 **캐릭터 주위 원형 범위**에 데미지를 준다.
- **순간 단발**이다. 탄막이 지속 다단히트이고 수류탄은 한 번 터지는 것으로 구분한다.
- 던지는 동작은 짧게 하고 폭발을 빠르게 한다. 연출이 길어지면 답답하다.
- 범위 크기는 `미정`.

#### 도탄 사격 (5)

- 온히트 시 확률로 총알을 쏜다. 총알은 적을 맞히면 **튕겨 가장 가까운 다음 적**으로 이동하며 연쇄 타격한다.
- "적 사이를 누빈다"는 처음 구상을 캐릭터 이동이 아니라 **총알의 이동**으로 살린 스킬이다.

| 항목 | 내용 |
|---|---|
| 튕김 횟수 | 상한이 있다 (`가안` 3~5회) |
| 중복 타격 | 한 번 맞은 적은 같은 도탄에 다시 맞지 않는다 |
| 온히트 | 첫 타격과 연쇄 타격 모두 켜지 않는다 (연쇄 폭주 방지) |

#### 전탄발사 (6)

탄막을 폭주시키는 **시간제 폭주 구간**이다.

```
쿨타임 중   게이지가 시간에 따라 차오른다 (쿨타임 진행도)
준비 완료   쿨타임이 끝나면 게이지가 가득 차 대기한다. 전투 중이 아니면 발동하지 않는다
발동        전투 중이면 자동 발동. 게이지가 빛나며 지속 시간 동안 줄어든다
종료        지속이 끝나면 게이지가 비고 쿨타임이 다시 흐른다
```

| 항목 | 내용 |
|---|---|
| 발동 조건 | 쿨타임이 돌아와 있고 **전투 중**일 것 (1.5절) |
| 활성 중 동작 | 6번이 활성인 동안에만, **탄막 난사가 발동할 때마다 전탄을 발사**한다 |
| 전탄 발사 | 캐릭터 주위 **원형 범위**에 데미지 **1히트**(단발) |
| 온히트 | **켠다.** 전탄 발사의 적중이 온히트를 일으켜 특수탄이 터질 기회가 늘어난다 |
| 쿨타임 | `미정` |
| 지속 시간 | `미정` |
| 휴식 구간 | **항상 존재한다.** 쿨타임을 지속 시간 이상으로 두므로 구조적으로 보장된다 |

- 전탄 발사가 단발이라 다단히트 온히트 금지 규칙(4.4절)을 어기지 않는다. 대신 적중한 적마다 온히트 판정이 굴러가므로 적이 많을수록 특수탄이 터질 기회가 많아진다.
- **순환을 반드시 막아야 한다.** `탄막 발동 → 전탄 발사 → 온히트 → 탄막 재발동 → 전탄 발사 …` 순환이 이어질 수 있다 (4.4절).
- **상시 발동은 하지 않는다.** 폭주가 가끔 와야 센 구간으로 느껴진다. 후반 성장은 쿨타임 감소와 지속 증가로 하되, 휴식이 사실상 사라지지 않도록 쿨타임의 하한을 밸런스 규칙으로 둔다.
- 쿨타임 진행도를 보여 주는 이 게이지는 1.4절의 공통 게이지 위젯의 사례다.

### 4.4 규칙과 안전장치

| 규칙 | 내용 |
|---|---|
| 온히트를 켜는 곳 | **평타의 발**과, **6번 활성 중의 전탄 발사.** 특수탄·탄막·수류탄·도탄의 효과는 모두 끈다 |
| 다단히트 금지 | 다단히트(`HitCount > 1`)에는 온히트를 켜지 않는다. 적 수 × 타수만큼 확률이 굴러 폭주한다. 탄막의 타격이 온히트를 켜지 않는 이유다 |
| 모션 우선 규칙 | **큰 모션(탄막)이 진행 중이면 평타는 모션 없이 효과만 발동한다.** 이미 모션 없이 효과만 나가는 스킬(`AnimName` 공백)과 같은 방식이다. 평타가 멈추지 않아 온히트 루프가 유지된다 |
| 탄막 재발동 | 탄막 중 확률이 다시 걸리면 새로 겹치지 않고 **지속 시간을 갱신**한다. 동시에 한 개만 돌아 데미지 상한이 일정하다 |
| 탄막의 대가 | 탄막 자체는 대가가 없는 추가 딜이므로 발동 확률과 지속 시간으로 밸런스를 맞춘다 |
| 폭주 순환 방지 | 전탄발사의 순환(탄막 → 전탄 → 온히트 → 탄막)을 막기 위해 **전탄 발사에 최소 간격**을 둔다. 필요하면 한 번의 전탄 발사에서 온히트를 일으키는 적중 대상 수에 상한을 둔다 (`미정`) |
| 폭주 휴식 | 전탄발사는 발동 후 쿨타임이 돌아야 다시 나가며 쿨타임을 지속 시간 이상으로 둔다. 상시화 수단을 두지 않는다 |

### 4.5 구현 시 확인할 사항

| 항목 | 내용 |
|---|---|
| 평타 2체 동시 사격 | "N발을 대상에게 배분, 모자라면 중첩"이 필요하다. 쌍검 처형과 공용 구현이 가능하며 대상당 최대 N발 한도 파라미터가 필요하다. 평타는 발마다 단발 효과로 구성한다 |
| 온히트 판정 단위 | 평타 발마다 판정한다. 평소 최대 2번이라 특수탄 발동 기회가 많다 |
| 폭주 게이지 | 쿨타임이 있는 자기 대상 버프 스킬을 **전투 중에만 자동 발동**하는 조건을 추가한다. 게이지는 쿨타임 진행도를 보여 준다 |
| 전투 중 상태 | 공용 시스템(1.5절). 피해를 주고받는 처리 지점에서 마지막 전투 시각을 갱신하고, 지금 시각과 비교해 전투 중인지 판단한다 |
| 게이지 위젯 | 채우기·빛나기·줄어들기 연출을 보여 주는 공통 게이지 위젯이 필요하다. 충전 기준(타격 횟수 / 시간)만 마스터리마다 다르다 |
| 전탄발사 | 탄막(코드 스킬)이 발동할 때 **6번 활성 버프가 있는지 확인**하고 있으면 전탄 발사 효과를 호출한다. 최소 간격과 대상 수 상한은 코드 스킬 안에서 처리한다 |
| 탄막 | 코드 스킬(`ISkillBehavior`)로 만들고 지속 상태와 갱신을 직접 관리한다. 재발동 시 새 인스턴스를 만들지 않고 남은 시간을 늘린다 |
| 평타 모션 억제 | 현재 시전 중(모션 진행 중)에는 다른 스킬 시전이 막힌다. 탄막이 진행 중일 때 **평타만 모션 없이 효과를 실행하는 분기**를 추가해야 한다 |
| 이동 허용 | 탄막 중에도 이동이 가능해야 한다. 코드 스킬이 이동을 잠그는지 확인한다 |
| 도탄 사격 | 코드 스킬로 "마지막 맞은 적에서 가장 가까운 미타격 적"을 선정해 튕김을 반복한다. 튕김 상한과 중복 방지가 필요하다 |
| 수류탄 | 순간 단발 원형 피해. 던지는 연출은 짧게 한다 |
| 관통 발사체 | 투사체가 대상을 관통하며 경로의 적에게 데미지를 주는 속성이 현재 있는지 확인이 필요하다 |

### 4.6 채택하지 않은 안

| 안 | 이유 |
|---|---|
| 대시·구르기·연속 대시 | 직접 이동 조작과 충돌하는 강제 이동 |
| 지뢰 계열 | 요청에 따라 제외 |
| 장전·탄창 게이지 | 룬검의 검기 충전·소모와 구조가 겹치고, 특수탄이 확률 발동만 해도 개성이 충분하다 |
| 폭발 변환 노드 (단일 → 범위) | 폭발탄을 처음부터 소범위로 두어 쌍권총이 단일 딜로 기울지 않게 했다 |
| 탄막이 평타를 대체 | 평타가 멈추면 온히트 루프가 끊겨 불만이 생긴다. 평타는 모션만 억제한다 |
| 탄막·난사에 상시 온히트 부여 | 적 수 × 타수만큼 확률이 굴러 폭주한다. 6번 활성 중 단발인 전탄 발사에만 온히트를 둔다 |
| 난사 계열 상호 배타 | 탄막이 평타를 대체하지 않고 병행하게 되어 불필요해졌다 |
| 데드아이 (표식 + 연타, 표식 일제 폭발) | 매 발 폭발이면 과하고, 폭발 횟수를 줄이면 표식 연출만 남았다 |
| 궤도 레이저 / 지원 요청 / 일발 포격 | 지속 연출이 화면을 가리고, 하늘에서 오는 지원 느낌이 "내가 쏜 느낌"과 맞지 않는다 |
| 리볼버 일발 (N타 대구경 한 발) | 5번을 도탄 사격으로 정했다. 필요하면 후보로 되살린다 |
| 평타 1체 단발 + 쌍발 사격 패시브 | 쌍권총이 한 발씩 쏘는 것이 어색하다. 기본 공격이 최대 2체를 동시에 쏘는 것으로 흡수했다 |
| 이퀼리브리엄 (활성 중 확률 발동 스킬 전체 2배) | 전탄발사가 활성 중 폭주를 맡는다 |
| 퀵스텝 (회피 + 이동속도 방어 버프) | 방어 스킬을 모든 마스터리에서 제거했다 |
| 6번 N타 적중 게이지 / 특수탄 발동 횟수 / 이동 거리 / 명중한 적 수 충전 | 쌍검의 N타 게이지와 개성이 겹치거나 구현이 크다. 마스터리마다 폭주 방식을 다르게 하려고 쿨타임 + 전투 중 발동으로 정했다 |
| 6번 쿨타임 단축 (특수탄 발동 시) | 규칙이 복잡해지고 폭주 주기를 예측하기 어려워진다 |
| 6번 전투 진입 순간에만 발동 | 적이 계속 이어지는 구간에서는 한 번 쓰고 다음 전투까지 못 쓴다. 전투 중 쿨타임마다 쓰는 방식으로 정했다 |
| 6번 확률 활성 | 업타임 편차가 크다. 룬검이 이 방식을 쓰므로 쌍권총은 다른 방식으로 구분했다 |
| 6번 상시화·이월 노드 | 휴식 구간이 있어야 폭주가 센 구간으로 느껴진다 |

## 5. 구현 시 확인할 사항 (쌍검)

현재 시스템에서 바로 되지 않는 항목만 모았다. 문서 확정 후 구현 단계에서 다룬다.

| 항목 | 내용 |
|---|---|
| 카운트 2배 | 현재 판정은 `카운터 % 주기 == 0` 이다. +2로 올리면 짝수 주기는 유지된다. 초각성 활성이 시작·종료되는 시점과 무기를 교체하는 시점에 카운터가 홀수면 영구히 맞지 않으므로 전환 시 짝수로 보정해야 한다 |
| 처형 | 랜덤 다수 선정 + 대상별 소범위 + 부족 시 배분 중첩. 현재 구조(탐색은 스킬이 한 번)에서 한 스킬로 되지 않는다. 투사체 착탄, 소환, 스킬 행동 시퀀스 중 구현 방식을 고른다 |
| 가속 (공속 상한 확장) | 공속 상한은 스탯 정의의 `MaxValue` 라서 노드로 직접 올릴 수 없다. **상한 보너스 스탯**(가칭 `Stat_AtkSpeedCapBonus`)을 새로 만들고 공속 클램프가 이 값을 더해 쓰게 해야 한다. 노드(1개, 5레벨)가 레벨당 +0.1을 올려 준다. 애니메이션 상한(5.0)에는 걸리지 않는다 |
| 폭주 게이지 | 쌍권총 6번(충전 기준이 쿨타임 진행도)과 같은 상태 기계와 공통 위젯을 쓴다. 쌍검은 충전 기준이 평타 적중 횟수다. 콤보 카운터는 공유·리셋 없음이라 별도의 전용 게이지 카운터를 둔다 |
| 확률 2배 | 확률 발동 판정(`triggerByChance`)은 스킬의 발동 확률 값과 난수를 비교한다. **발동 확률 증폭 스탯**(가칭 `Stat_TriggerChanceAmp`)을 추가하고 판정에서 곱하면 된다. 버프는 스탯 변경을 이미 지원하므로 초각성 활성 구간을 버프로 걸 수 있다 |
| 온히트 연쇄 | 평타만 온히트를 켠다. 나머지 스킬이 켜면 스킬이 다시 확률을 굴린다. 평타는 단발이어야 한다 |

## 6. 미정 항목

| 항목 | 내용 |
|---|---|
| 확률·데미지·범위·주기·버프 수치 | 전부 밸런스 단계에서 정한다 |
| 쌍검 — 가속 | 레벨당 +10%p가 맞는지. 상한이 의미를 가지려면 공속 합계가 300%를 넘는 빌드가 필요하므로 장비 공속 수급량을 확인 |
| 쌍검 — 처형 선정 | 대상이 최대 수 이상일 때 중복 선정을 허용할지 |
| 쌍검 — 초각성 | 필요 타수 N, 지속 시간, N 하한(휴식 보장) |
| 룬검 — 룬 폭발 | N타 적중 주기 |
| 룬검 — 검기 | 최대 스택(5 `가안`), 스택당 공격력 증폭(2% `가안`), 만료 없는 지속시간 가능 여부 |
| 룬검 — 충전 | 검기 충전 확률, 룬 진동 주기(n초). 충전량은 +1 고정 |
| 룬검 — 룬 진동 | 범위, 피해량, 최대치 보너스 배율(×1.5 `가안`), 전투 중 해제 시간 |
| 룬검 — 검 사출·제왕검 | 발동 확률, 폭발 범위, 라인 폭·길이 |
| 룬검 — 검 개방 | 지속시간 N초, 쿨타임(지속시간 이상으로 설정해 유지 중 재발동 방지), 최종 데미지 증폭 수치(작게 시작) |
