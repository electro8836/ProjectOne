# 마스터리 스킬 디자인

*무기 마스터리별 스킬 컨셉 · 구성 | 2D 탑다운 핵앤슬래시 · 싱글플레이 · Unity C#*

> **이 문서는 컨셉과 스킬 구성만 다룬다.** 확률·데미지·범위 크기·주기·지속시간 같은 **수치는 확정하지 않는다.** 밸런스 단계에서 바뀔 가능성이 높기 때문이다. 문서에 수치가 보이면 방향을 설명하는 `가안`이며, 테이블 작성 단계에서 다시 정한다.
>
> 기존 쌍검 스킬(콤보 액티브, 스파크 소환, 기존 18노드 트리)은 고려하지 않는다. 새 스킬 세트로 전면 교체한다는 전제다.

**목차**

1. 설계 전제
2. 쌍검 (DualBlades)
3. 룬검 (RuneSword)
4. 구현 시 확인할 사항 (쌍검)
5. 미정 항목

---

## 1. 설계 전제

### 1.1 마스터리당 스킬 구성

| 구분 | 개수 | 비고 |
|---|---|---|
| 기본 공격 | 1 | 평타. 공속 배율을 받는 유일한 스킬 |
| 메인 스킬 | 6 | 스킬 트리의 습득 노드로 배운다 |

이후 단계에서 각 스킬에 강화 노드를 붙여 확장한다. 이 문서는 **어떤 스킬을 만들지**만 정한다.

### 1.2 마스터리 정체성

직업 개념이 없으므로 무기마다 전투 방식이 구분되어야 한다. 구분 축은 **범위 형태**다.

| 무기 | 범위 형태 | 보상 |
|---|---|---|
| 쌍검 | 부채꼴·직선 위주, 범위가 작다 | 범위가 좁은 대신 데미지를 높게 잡는다 |
| 룬검 | 원형·착탄 폭발 등 **범위기 위주** | 범위기에 강한 마스터리 |
| 다른 무기 | 원형 범위 위주 | ‒ |

### 1.3 발동 방식 용어

| 용어 | 시스템 대응 | 설명 |
|---|---|---|
| N타 적중 | `OnCombo` | 평타가 **실제로 적중**한 횟수. 스윙 1회 = 1카운트이고 여러 명을 맞춰도 1이다 |
| 확률 발동 | `OnHit` | **평타가 적중할 때** 확률로 발동 |

## 2. 쌍검 (DualBlades)

### 2.1 컨셉

> **연타 + 보스 딜러**

- **연타**: 평타를 계속 적중시키는 것이 곧 스킬 발동 조건이다. 공속이 곧 딜이 된다.
- **보스 딜러**: 한 대상에게 공격이 몰리는 구조. 대상이 적을수록 처형이 한 대상에게 집중된다.
- 범위는 작게, 데미지는 높게. 광역은 다른 무기에 맡기고 쌍검은 좁고 깊게 간다.

### 2.2 스킬 구성 한눈에 보기

| # | 이름 | 발동 | 범위 | 역할 |
|---|---|---|---|---|
| 기본 | 기본 공격 | 평타 | 전방 작은 부채꼴 | 카운트·확률 발동의 기점 |
| 1 | 일섬 | N타 적중 (짧은 주기) | 직선 | 빠르게 도는 직선 공격 |
| 2 | 난무 | N타 적중 (중간 주기) | 중간 원형 | 주변 정리 |
| 3 | 가속 | 평타 적중 시 확률 | 자신 (버프) | 공격력·회피 스택 버프 |
| 4 | 처형 | N타 적중 (긴 주기) | 원형 탐색 → 랜덤 다수 | 보스 집중 딜 |
| 5 | 공간참 | 평타 적중 시 낮은 확률 | 전방 큰 부채꼴 | 드물게 터지는 큰 한 방 |
| 6 | 초각성 | 패시브 (노드 2개) | 자신 | 확률·카운트 2배, 공속 상한 확장 |

주기는 **일섬 < 난무 < 처형** 순으로 길어지고, 서로 겹치는 일이 드물게 한다. 구체적인 타수는 `미정`이다.

### 2.3 스킬 상세

#### 기본 공격

- 전방 **작은 부채꼴** 범위의 근접 단발 공격.
- 이 공격의 적중이 모든 카운트·확률 발동의 기점이다. 평타 효과만 온히트를 켠다.

#### 일섬

- 평타가 일정 횟수 적중할 때마다 발동한다 (가장 짧은 주기).
- **직선** 범위를 타격한다.

#### 난무

- 평타가 일정 횟수 적중할 때마다 발동한다 (중간 주기).
- **중간 크기 원형** 범위를 타격한다. 쌍검에서 유일한 원형 범위다.

#### 가속

- 평타가 적중할 때 **확률로** 자신에게 버프를 건다.
- 버프는 **짧게 지속되고 여러 번 중첩**된다. 스택마다 **공격력 증폭**과 **회피율**이 오른다.
- 연타 컨셉의 딜 증가와 보스전 생존을 한 스킬로 맡는다. 확정 회피는 없다. 기존 회피 규칙(확률 판정)을 그대로 쓴다.
- 지속시간·최대 중첩·스택당 수치는 `미정`이다. 처음 구상은 5초 · 3중첩 · 공격력 증폭 +5% · 회피율 +10%였다.

#### 처형

- 평타가 일정 횟수 적중할 때마다 발동한다 (가장 긴 주기).
- 동작 순서

```
1. 시전자 중심 원형 범위 안의 적을 탐색한다
2. 그중 여러 체를 랜덤으로 선정한다 (최대 수는 가안 5체)
3. 선정된 적의 위치마다 작은 원형 범위 데미지를 입힌다
```

- **대상이 최대 수보다 적으면 중첩한다.** 타격 횟수를 선정된 대상에게 돌려가며 배분한다. 예: 최대 5회에 대상이 1체면 5회 전부 그 대상에게 들어간다.
- 보스 1체와 싸울 때 모든 타격이 보스에게 들어가므로 **보스 딜러 컨셉의 핵심 스킬**이다. 잡몹이 많으면 분산된다.

#### 공간참

- 평타가 적중할 때 **낮은 확률**로 발동한다 (가안 5%).
- 전방 **큰 부채꼴** 범위를 타격한다. 쌍검에서 가장 넓고 가장 드문 공격이다.

#### 초각성

**패시브이며 두 개의 노드로 나뉜다.** 각각 따로 습득한다.

| 노드 | 효과 |
|---|---|
| 초각성 I | 확률 발동 확률 **2배**, N타 적중 카운트 **2배** |
| 초각성 II | 공격 속도 상한 **+50%p** (300% → 350%) |

- **확률 2배**: 공간참과 가속의 발동 확률이 모두 2배가 된다.
- **카운트 2배**: 평타 1회 적중에 카운터가 2 오른다. 이를 위해 **카운트 스킬의 주기는 항상 짝수로 둔다.** 수치를 바꿀 때도 지킬 규칙이다.
- **공속 상한**: 공속 자체를 올려주지는 않고 상한만 늘린다. 상한 수치(300% → 350%)만은 정해진 값이다.

## 3. 룬검 (RuneSword)

### 3.1 컨셉

> **마검사 → 검 소환사**

- **초반 — 마검사**: 룬을 두른 검으로 직접 휘둘러 범위기를 터뜨린다. 검 개수와 무관하게 완결되는 스킬이다.
- **후반 — 검 소환**: 평타로 검을 모아 **등 뒤에 띄우고**, **칼질을 하면서** 그 검이 추가로 돕는다. 캐릭터가 원거리 유닛이 되지 않는다.
- 스킬 트리에서 후반 스킬을 뒤쪽에 두는 것으로 두 단계를 만든다. 별도의 단계 전환 장치는 없다.
- 룬검은 **범위기에 강한 마스터리**다. 모든 스킬이 범위 데미지로 귀결된다.
- 순환 구조: **모으기(충전) → 쓰기(소비) → 폭주(소모 면제 + 증폭)**. 검이 쌓이면 쓰고, 6번 버프가 걸리면 쓰면서도 줄지 않는다.

### 3.2 스킬 구성 한눈에 보기

| # | 단계 | 가칭 | 발동 | 효과 |
|---|---|---|---|---|
| 기본 | 초반 | 룬 베기 | 평타 | **쌍검보다 큰 부채꼴** 근접 범위 공격 |
| 1 | 초반 | 룬 폭발 | N타 적중 | **적 위치** 기준 원형 범위 공격 |
| 2 | 초반 | 룬 파동 | N타 적중 (1번과 다른 주기) | **내 캐릭터 주변** 원형 범위 공격 |
| 3 | 초반 | 룬 방패 | 평타 적중 시 확률 | 공격력 증폭 + 막기확률 버프 (공격 없음) |
| 4-① | 후반 | 검 소환 | 평타 적중 시 확률 | 검 **+1~3 충전** (연쇄 판정) |
| 4-② | 후반 | 검기 베기 | 평타 적중 시 **검이 있으면**, 쿨타임 5초 | 검 1개 소비, 전방 일직선 넓고 긴 범위 공격 |
| 5 | 후반 | 검 사출 | 평타 적중 시 확률 | 검 1개 소비, 발사해 목표 지점에서 원형 폭발 |
| 6 | 후반 | 검 개방 | 평타 적중 시 확률 | 버프: **검 소모 면제 + 최종 데미지 증폭** |

- 메인 스킬은 6개이고, **4번만 노드 두 개짜리 체인**이다. 4-①(충전)을 배워야 이어진 노드 4-②(소비 공격)가 열린다.
- 초반 스킬(1~3)은 검을 쓰지 않는다. 후반 스킬(4~6)이 검 계열이다.

### 3.3 검 시스템

| 항목 | 내용 |
|---|---|
| 보유 수 | 최대 5개 (`가안`) |
| 표현 | 등 뒤에 보유 수만큼 검이 떠 있다 |
| 충전 | **4-① 하나뿐이다.** 평타 적중 시 확률로 +1~3 |
| 소비 | 4-②와 5번이 소비한다. 둘 다 1회에 검 1개 |
| 소비 면제 | 6번 버프가 걸려 있는 동안 4-②·5번이 검을 소비하지 않는다 |
| 가득 찬 상태 | 가득 차면 충전은 낭비된다. 소비 스킬이 이를 비워 준다 |

**소비 스킬이 둘이어도 되는 이유**

- 4-②는 **쿨타임 5초**로 소비량의 상한이 정해져 있다. 5초에 검 1개 이상을 쓰지 못한다.
- 5번은 확률 발동이라 검이 없을 때는 소비가 일어나지 않는다. 두 스킬이 같은 조건에서 경쟁하는 구조라 한쪽만 굶지 않는다.
- 충전이 부족한지는 밸런스 단계에서 확인한다. 기준은 `평균 충전량 ≥ 4-② 소비 + 5번 소비` 다.

**충전과 소비 공격을 한 스킬에 두지 않는 이유**

- 한 스킬은 발동 방식과 쿨타임을 하나씩만 가진다. 충전(확률)과 소비 공격(검 보유 + 쿨타임)을 같이 담을 수 없다.
- 소비 공격이 "검이 있을 때만 발동"하면 검 0개에서 충전도 못 하는 교착이 생긴다. 충전을 선행 노드로 분리해 해결한다.

### 3.4 스킬 상세

#### 기본 공격 — 룬 베기

- 전방 **큰 부채꼴** 근접 범위 공격. 쌍검 평타보다 넓다.
- 단발이며, 적중이 충전·소비·버프 발동의 기점이다. **평타 효과만 온히트를 켠다.**

#### 룬 폭발 (1)

- 평타가 일정 횟수 적중할 때마다 발동한다.
- **대상 적의 위치**를 중심으로 원형 범위를 타격한다. 주기는 `미정`.

#### 룬 파동 (2)

- 평타가 일정 횟수 적중할 때마다 발동한다. 1번과 **주기가 달라** 같은 타에 겹치지 않게 한다.
- **시전자 주변**을 원형으로 타격한다. 주기는 `미정`.
- 1번과 2번은 원형이라는 점은 같지만 **기준 위치가 다르다.** 1번은 적 위치, 2번은 내 위치다.

#### 룬 방패 (3)

- 평타가 적중할 때 **확률로** 발동한다. 공격은 하지 않는다.
- 버프 효과: **공격력 증폭 + 막기확률 증가.**
- 연출: 룬 방패가 캐릭터 주위를 돈다. 버프가 유지되는 동안만 표시한다.
- 지속시간·중첩 여부는 `미정`.
- 쌍검이 회피(가속)를 쓰므로 룬검은 **막기**를 방어 수단으로 쓴다. 회피와 막기는 표시가 구분된다 (MISS / BLOCK).

#### 검 소환 (4-①)

- 평타가 적중할 때 **확률로** 검을 충전한다. 한 번 발동하면 **+1~3개**다.
- **연쇄 판정**으로 개수를 정한다.

```
1차 판정 (가장 높은 확률)  → 통과하면 검 +1, 이어서
2차 판정 (더 낮은 확률)    → 통과하면 검 +1, 이어서
3차 판정 (가장 낮은 확률)  → 통과하면 검 +1
```

- 많이 나올수록 확률이 낮아져 가끔 3개가 한꺼번에 터지는 맛이 있다.
- 평균 충전량은 각 단계 확률로 조절한다. 수치는 밸런스 단계에서 정한다.
- 노드 레벨이 오르면 확률이 오르거나 연쇄 단계가 늘어나는 식으로 확장할 수 있다.
- 충전은 검 보유와 무관하게 돌아가므로 검이 0개여도 모인다.

#### 검기 베기 (4-②)

- 4-①을 배우면 열리는 **이어진 노드**다.
- 평타가 적중하고 **검이 있으면** 발동한다. 확률이 아니라 확정 발동이며, **쿨타임은 5초**다 (`가안`).
- 검 1개를 소비해 **전방 일직선으로 넓고 긴 범위**를 타격한다.
- 쌍검 일섬도 직선이지만 이쪽은 **넓고 길어서** 구분된다. 쌍검은 작은 범위 위주다.

#### 검 사출 (5)

- 평타가 적중할 때 **확률로** 발동한다.
- 동작 순서

```
1. 평타 적중 시 확률 판정
2. 통과하면 검 1개를 소비한다 (검이 없으면 아무 일도 일어나지 않는다)
3. 등 뒤의 검이 적을 향해 날아간다
4. 목표 지점(적 위치) 땅에 닿으면 원형 범위로 폭발한다
```

- 검이 0개면 확률만 통과해도 발사가 없다.
- 검 1개당 폭발 1회다.

#### 검 개방 (6)

- 평타가 적중할 때 **확률로** 버프를 건다. 이 버프가 룬검의 **폭주 구간**이다.
- 버프 효과

| 효과 | 내용 |
|---|---|
| 검 소모 면제 | 4-②·5번이 검을 소비하지 않는다 |
| 최종 데미지 증폭 | 시전자의 **모든 데미지**에 적용된다 |

- 지속시간은 `미정`.
- 3번 방패의 **공격력 증폭**과 6번의 **최종 데미지 증폭**은 서로 다른 레이어라, 두 버프가 동시에 걸리면 곱해진다. 둘 중 하나만 있을 때와 확연히 차이가 난다.
- 평타 범위 증가는 넣지 않는다. 구현이 어렵기 때문이다 (3.6 참고).

### 3.5 평타 적중 시 판정되는 스킬

| 스킬 | 판정 |
|---|---|
| 룬 방패 (3) | 확률 |
| 검 소환 (4-①) | 확률 |
| 검기 베기 (4-②) | **확정** (검 보유 + 쿨타임 5초) |
| 검 사출 (5) | 확률 |
| 검 개방 (6) | 확률 |

- 1·2번은 N타 적중 기준이라 이 표와 별개다.
- 평타 한 번에 최대 다섯 가지가 동시에 나갈 수 있다. 각자 독립적으로 판정한다.

### 3.6 구현 시 확인할 사항

| 항목 | 내용 |
|---|---|
| 검 = 버프 스택 | 검 개수를 버프 스택(최대 5)으로 관리한다. 소환물(`Summon`)은 최대 수 초과 시 가장 오래된 것부터 소멸하고, 하나를 골라 소비하는 경로가 없다 |
| 소비 게이트 | `BuffConsume`(스택 소모, 성공 시 `ChainEffectIDs` 실행)로 "검이 있을 때만 발동"을 만든다. 코드는 있으나 **실제 데이터 행이 0개**다 |
| 소모 면제 분기 | "버프가 있으면 소비를 건너뛴다"는 분기는 현재 없다. 신규 작업이다 |
| 충전 연쇄 판정 | 버프 효과는 `Chance` 판정을 통과해야 다음 효과(`ChainEffectIDs`)가 실행된다. 검 +1 효과를 3단으로 이으면 된다 |
| 4-② 쿨타임 | 확률 발동 계열(`OnHit`) 스킬에서 `Cooldown`이 정상 동작하는지 확인이 필요하다. 쿨타임은 공속 배율을 받지 않는 실제 시간이다 |
| 4-② 노드 체인 | 노드의 스킬 습득(`SkillGrant`)과 선행 노드 조건으로 구성한다 |
| 착탄 폭발 | 투사체의 착탄 폭발 속성을 사용한다. 목표 지점이 적 위치가 되도록 하는 방식은 구현 단계에서 정한다 |
| 등 뒤 검 비주얼 | 스택 수에 맞춰 등 뒤 검 개수를 표시하는 연출이 필요하다. 시스템에 없는 신규 작업이다 |
| 룬 방패 연출 | 방패가 캐릭터 주위를 도는 연출은 버프 유지 시간에 맞춰 켜고 끈다 |
| 온히트 연쇄 | 평타만 온히트를 켠다. 나머지 스킬의 데미지 효과는 모두 **FALSE** 로 둔다. TRUE 이면 스킬이 다시 확률을 굴린다. 평타는 단발이어야 한다 |
| 특정 스킬만 증폭 불가 | 공격력 증폭·피해 보너스·최종 증폭은 모두 시전자의 모든 데미지에 걸린다. 데미지 계산이 어느 스킬인지 모르기 때문이다. 스킬별 증폭은 스킬 트리 노드·장비의 `SkillModifier`로만 가능하고 버프에는 붙일 수 없다 |
| 평타 범위 증가 불가 | 범위 스탯이 없고 버프가 스킬 변형값을 붙이는 경로도 없다. 구현하려면 "버프 → 변형값 → 스킬 재계산 + 이펙트 크기 동기화"를 새로 만들어야 해서 보류했다 |
| 충전 조건 제약 | 처치 시(`OnKill`)는 발동 경로가 연결되지 않았으므로 조건으로 쓰지 않는다 |

## 4. 구현 시 확인할 사항 (쌍검)

현재 시스템에서 바로 되지 않는 항목만 모았다. 문서 확정 후 구현 단계에서 다룬다.

| 항목 | 내용 |
|---|---|
| 카운트 2배 | 현재 판정은 `카운터 % 주기 == 0` 이다. +2로 올리면 짝수 주기는 유지된다. 초각성 I 를 습득·해제하거나 무기를 교체하는 시점에 카운터가 홀수면 영구히 맞지 않으므로 전환 시 짝수로 보정해야 한다 |
| 처형 | 랜덤 다수 선정 + 대상별 소범위 + 부족 시 배분 중첩. 현재 구조(탐색은 스킬이 한 번)에서 한 스킬로 되지 않는다. 투사체 착탄, 소환, 스킬 행동 시퀀스 중 구현 방식을 고른다 |
| 가속 중첩 | 기존 공속 버프의 `IndependentShared`(수명 공유, 새로 쌓일 때 갱신)가 후보다 |
| 공속 상한 | 상한은 스탯 정의의 `MaxValue` 다. 노드가 상한을 올리는 경로가 현재 없다. 애니메이션 상한(5.0)에는 걸리지 않는다 |
| 온히트 연쇄 | 평타만 온히트를 켠다. 나머지 스킬이 켜면 스킬이 다시 확률을 굴린다. 평타는 단발이어야 한다 |
