# 월드 진행 설계

> 2D 탑다운 방치형 핵앤슬래시 (Unity, 싱글플레이) — 월드 / 구역 / 방치 / 제단 / 보스 / 목표 장치
> 관련 문서: `맵시스템_설계.md`, `몬스터시스템_설계.md`, `퀘스트시스템_설계.md`, `보상시스템_설계.md`, `소모품시스템_설계.md`, `무기마스터리시스템_설계.md`
> **이 문서는 아직 구현되지 않은 목표 설계를 기술한다.** 확정된 내용만 본문에 두고, 정하지 않은 것은 11장에 모았다. 현재 구현(마을 + 액트·필드 + 던전)은 `맵시스템_설계.md` 가 기술하며, 그중 액트·필드 구조는 이 문서의 월드 구조로 대체된다.

---

## 1. 핵심 컨셉

- **방치 = 유지와 축적, 직접 플레이 = 확장·컨트롤·고효율.**
- 방치할 때는 한 곳에 세워두고, 집중할 때는 직접 움직이며 사냥한다.
- 필수 플레이는 하루 약 30분. 더 하고 싶은 유저는 직접 사냥으로 더 할 수 있다.
- **일일 숙제(횟수 제한 콘텐츠)는 최소화한다.** 제한은 재화 보유량으로 건다.

## 2. 월드 구조

| 항목 | 내용 |
|---|---|
| 월드 수 | 1 ~ 5 |
| 월드당 체류 | 약 한 달 |
| 월드 간 이동 | 로딩 화면. **월드마다 Unity 씬 1개** |
| 월드 안 이동 | 구역 사이가 끊김 없이 이어진다. 구역은 내부 관리 단위다 |
| 월드 구성 | 전반부 → 중간 보스 → 후반부 → 월드 보스 |
| 위험구역 | 월드당 2곳 (전반 A, 후반 B) |
| 제단 | 월드당 1개 |
| 마을 | 유지한다. 월드 밖의 상시 이동 가능한 장소다 |

### 2.1 진행 관문

**퀘스트 진행 상태에 따라 길목을 장막으로 막는다.** 선행 퀘스트를 완료하면 장막이 걷힌다.

| 관문 | 개방 대상 |
|---|---|
| 중간 보스 첫 처치 | 후반부, 위험구역 B, 제단 상위 단계 |
| 월드 보스 첫 처치 | 다음 월드, 제단 최상위 단계 |

### 2.2 구역 역할

| 구역 | 위험도 | 역할 |
|---|---|---|
| 거점 | 안전 | 순간이동, 부활, 정비 |
| 일반 구역 | 보통 | 이동 중 가벼운 사냥, 비선공 몬스터 |
| 갈림길 | 보통 ~ 위험 | 정예, 숨은 상자, 지름길 |
| 제단 광장 | 안전 (제단 사용 시 위험) | 제단, 넓고 트인 공간 |
| 위험구역 | 위험 | 방치 사냥터, 선공 몬스터 다수 |
| 보스 구역 | ‒ | 막다른 아레나, 일반 몬스터 없음 |

## 3. 길 설계 원칙

- 길은 하나로만 두지 않는다. **큰 길(메인 진행) + 갈림길(선택 콘텐츠)** 구조다.
- 큰 길은 넓고 눈에 띄게 만들어 미니맵 없이도 진행 방향이 보이게 한다.
- **갈림길 끝에는 반드시 보상을 둔다.** 빈 막다른 길은 만들지 않는다.
- 지름길로 순환시켜 되돌아가는 지루함을 줄인다.
- 길 폭은 몬스터에 둘러싸여도 움직일 수 있게 넓게 둔다 (캐릭터 6~8명분 이상). 좁은 통로는 짧게만 둔다.
- 제단 광장과 위험구역 주변은 트인 공간으로 둔다 (몬스터가 끼이지 않게).

## 4. 이동 · 미니맵 · 지도

| 기능 | 내용 |
|---|---|
| 미니맵 | 우측 상단, 화면 높이 20~25%, 반투명. 내 위치·거점·보스·다음 목표·이벤트만 표시한다. 일반 몬스터는 표시하지 않는다 |
| 전체 지도 | 미니맵을 탭하면 열린다. 미탐험 지역은 안개로 가리고, 거점 상태와 위험구역을 표시한다 |
| 순간이동 | 확보한 거점끼리. 전체 지도에서 거점을 탭한다 |
| 방향 화살표 | 다음 목표가 화면 밖이면 화면 가장자리에 화살표를 띄운다 |
| 숨은 요소 | 지도에 표시하지 않는다. 근처에서 "?" 힌트만 보인다 |

## 5. 방치

- 방치는 **제자리 고정**이다. 캐릭터가 알아서 돌아다니지 않는다.
- 몬스터가 플레이어에게 몰려오고, 자동 공격·자동 스킬로 버틴다.
- 방치 장소는 **위험구역**이다. 위험구역 몬스터는 선공형이고 인식 범위가 넓어 서 있기만 해도 몰려온다.
- 아이템은 자동 획득한다.

### 5.1 위험도 단계

| 위험도 | 몬스터 밀도 | 리스폰 | 성향 |
|---|---|---|---|
| 안전 | 없음 | ‒ | ‒ |
| 보통 | 낮음 | 느림 | 비선공 |
| 위험 | 높음 | 빠름 | 선공, 인식 범위 넓음 |

### 5.2 위험구역 A / B

| 항목 | A (전반) | B (후반) |
|---|---|---|
| 개방 | 처음부터 | 중간 보스 처치 후 |
| 몬스터 | 선공형 다수 | 선공형 다수, 정예 비율 높음 |
| 주요 드랍 | 골드, 경험치 | 강화 재료 |
| 공통 | 영혼석, 일반 촉매 소량 | 영혼석, 일반 촉매 소량 |

A/B 의 드랍 성격을 다르게 해서 한 곳에만 쏠리지 않게 한다.

## 6. 영혼석

- 모든 월드 **공통 재화 하나**다. 용도는 **제단 사용**이다.
- 정수(정수 강화 트리 재화)와는 별개의 재화다.

### 6.1 획득처

| 획득처 | 내용 |
|---|---|
| 방치 (위험구역) | **방치 보관함**에 쌓인다. 상한 5000, 차면 더 쌓이지 않는다. 접속해서 수령한다 |
| 직접 사냥 (위험구역) | 방치보다 높은 효율로 획득한다 |

### 6.2 방치 보관함

- 상한은 지갑이 아니라 **방치 보관함**에 건다. 수령하면 지갑으로 이동한다.
- 상한은 **8~12시간 분량**을 목표로 맞춘다. 아침·저녁 접속 흐름을 만들기 위함이며, 4시간 이하는 스트레스가 된다.

---

## 7. 제단

### 7.1 기본 규칙

- 월드마다 제단 1개 (제단 광장).
- 제단에 다가가면 **단계 선택 UI** 가 뜨고, 단계에 맞는 영혼석(+촉매)을 소모한다.
- 소모하면 **1분 동안 제단 주변이 위험지역**이 되고, 다수의 몬스터가 스폰되어 몰려든다.
- **직접 조작 중에만 사용한다.** 방치에는 쓰지 않는다.
- **캐릭터가 사망하면 제단에서 부활한다.** 이벤트는 계속 진행된다.
- 월드마다 제단에서 나오는 **몬스터와 보상이 다르다.**
- **일일 횟수 제한이 없다.** 영혼석 보유량이 유일한 제한이다. 제단별 일일 첫 보상도 두지 않는다 (숙제화 방지).

### 7.2 단계

- 제단 단계를 **월드 진행도에 묶어** 제단 자체가 한 달 동안의 성장 축이 되게 한다 (2.1 진행 관문).
- 최고 단계만 **월드 고유 재료**(그 월드의 정예·보스 드랍)를 추가로 요구한다.

### 7.3 촉매 — 보상 방향 조절

- 제단별 고정 보상 대신, **소환 시 촉매를 추가로 넣어 원하는 보상 확률을 올린다.**
- 촉매 슬롯은 최대 2개. 확정이 아니라 **확률 2~3배** 정도다.
- 촉매에 **불운 보정(천장)** 을 적용한다.
- 처음엔 **부위 촉매 3종**(무기 / 방어구 / 장신구)만 구현하고 이후 확장한다.

### 7.4 정예 설계 원칙

정예는 컨트롤을 요구한다.

- 모든 위험한 공격은 **예고**한다 (바닥 범위 표시, 0.8~1.2초 후 공격).
- 피한 뒤 1~2초의 **반격 빈틈**을 둔다.
- 동시에 피해야 할 패턴은 1~2종으로 제한한다 (탄막 금지).
- **회피 버튼은 두지 않는다.** 예고 범위는 조이스틱 이동으로 피한다 (히어로 이동기 금지 규칙과 같다).

## 8. 보스

### 8.1 배치

- **중간 보스** — 전반부 끝, 막다른 아레나. 첫 처치 시 후반부 개방.
- **월드 보스** — 후반부 끝, 막다른 아레나. 첫 처치 시 다음 월드 개방.
- 보스는 **고가치 아이템**을 드랍한다.

### 8.2 리젠

- 월드마다 중간 보스와 월드 보스가 있으며, **현재 필드보스와 같은 규칙으로 하루 1회 리젠**된다 (콘텐츠 초기화 시각 06시, `몬스터시스템_설계.md`).
- **보스소환석** — 보스 구역에서 사용하면 그 보스가 즉시 리스폰한다.
  - 재화가 아니라 **소모품**이다 (`소모품시스템_설계.md`).
  - **전 보스 공용 1종**이다.

## 10. 재화 · 콘텐츠 흐름

```
방치 (위험구역, 제자리) ──▶ 영혼석(보관함 상한), 골드, 경험치, 일반 촉매
직접 사냥 (위험구역) ────▶ 영혼석 (방치보다 고효율)
                              │
                              ▼
제단 (직접 플레이, 1분) ──▶ 장비, 재료
                              │
                              ▼
보스 (하루 1회 / 보스소환석) ─▶ 고가치 장비, 월드 고유 재료 ─▶ 제단 최고 단계
```

| 콘텐츠 | 제한 방식 |
|---|---|
| 위험구역 방치 | 보관함 상한 (수령 필요) |
| 위험구역 직접 사냥 | 없음 |
| 제단 | 영혼석 보유량 |
| 보스 | 하루 1회 리젠 + 보스소환석 |

## 11. 미결

### 11.1 수치 · 세부

| 항목 | 가안 |
|---|---|
| 구역 수 | 전반부 4 + 후반부 4 + 보스 구역 2 |
| 맵 배치 | 전반: 시작 거점 → 초원(갈림길: 정예·상자) → 제단 광장 → 위험구역 A → 중간 보스. 후반: 후반 거점 → 협곡(숨은 길: 보물·제단 광장 지름길) → 위험구역 B → 최전선 거점 → 월드 보스 |
| 영혼석 추가 획득처 | 정예·보스 추가 획득 |
| 보관함 상한 기준 | 고정 5000 이 실제 몇 시간 분량인지 확인 필요. 시간 기준(현재 방치 효율 × N시간)으로 잡는 것도 검토 |
| 방치 중 사망 | 보상 감소 + 거점 자동 부활 |
| 제단 부활 대기 | 3초 |
| 제단 단계표 | 1단계 1개(처음부터, 일반 웨이브) / 2단계 3개(처음부터, 마지막 10초 정예 1) / 3단계 6개(중간 보스, 정예 다수·특성 2) / 4단계 10개(월드 보스, 강화 정예·특성 3) / 5단계 15개 + 월드 고유 재료(월드 보스, 최상위 보상 풀) |
| 촉매 종류 | 부위(장비 분해) / 속성(장비 분해·정예) / 세트(보스) / 정예 비율(정예) |
| 촉매 획득처 | 장비 분해 → 촉매 순환. 현재 분해는 주 재화 환급만 하므로 환급과의 관계 미정 |
| 제단 종료 보상 | 처치 몬스터 즉시 드랍 + 1분 종료 시 처치 수 기준 등급 상자 (예: 50마리 이상 금상자) |
| 정예 패턴 | 돌진(직선), 내려찍기(원형), 브레스(부채꼴), 장판, 졸개 호출 |
| 정예 특성 | 신속, 폭발, 분열, 보호막, 불꽃 길, 소환사. 단계가 높을수록 특성 수 증가 |
| 무피격 처치 보너스 | 정예 무피격 처치 시 보너스 |
| 보스 보상 | 중간 보스: 세트 촉매·상급 강화 재료·세트 장비 낮은 확률 / 월드 보스: 월드 고유 재료·세트 장비·최상급 장비 낮은 확률 / 공통: 고가치 아이템 천장 (예: 15회 내 최상급 1개) |
| 보스 패턴 | 정예 원칙을 더 강하게. 체력 구간별 패턴 변화 (중간 2구간, 월드 3구간) |
| 보스 난이도 | 자동 전투로도 도전 가능, 직접 조작하면 훨씬 낮은 스펙으로 처치 가능 |
| 월드 보스 첫 처치 시점 | 방치 위주 약 4주, 직접 플레이 적극적이면 2~3주 |
| 보스소환석 획득처 | 미정 |
| 도감 보상 | 채우면 영구 보너스 |
| 다음 목표 패널 | 화면 한쪽에 다음 목표 표시 |

### 11.2 플레이 흐름 가안

**하루 일정**

| 시간대 | 할 일 | 소요 |
|---|---|---|
| 아침 접속 | 방치 보관함 수령, 장비 정리·분해, 방치 위치 확인 | 3~5분 |
| 저녁 접속 | 제단 몇 회, 보스 처치, 강화, 방치 재설정 | 20~30분 |
| 여유 있는 날 | 갈림길 탐험, 위험구역 직접 사냥, 고단계 제단 | 자유 |

- 바쁜 날 아침 접속만 해도 손해가 크지 않게 한다.

**한 달 흐름 (월드 1개)**

| 주차 | 진행 |
|---|---|
| 1주차 | 전반부 탐험, 위험구역 A 방치, 제단 1~2단계, 중간 보스 첫 처치 |
| 2주차 | 후반부 개방, 위험구역 B 방치, 제단 3단계, 부위 촉매로 장비 채우기 |
| 3주차 | 속성 촉매로 빌드 정리, 중간 보스로 세트 수집, 월드 보스 도전 시작 |
| 4주차 | 월드 보스 첫 처치, 제단 4~5단계, 다음 월드 준비 |

- 월드 1은 방치 없이도 거의 깰 수 있게 쉽게 → 시스템 학습. 월드 2부터 방치 성장이 필요해지게.

### 11.3 나중에 검토

- 전체 지도 탭 자동 이동 (넣는다면 안개 밝힌 곳까지만)
- 나중에 얻는 능력·열쇠로 이전 월드의 막힌 길이 열리는 구조, 이전 월드 재방문 장치 (숨은 길, 재오염 엔드콘텐츠)
- 제단 처치 몬스터의 영혼석 일부 환급 (50~70%)
- 단판 균열 던전 (3~5분, 입장권 저장형, 제단·보스와 겹치지 않는 보상)
- 주간 월드 이벤트 (몬스터 대이동, 침공, 떠돌이 정예 등), 주차별로 열리는 숨은 구역
- 보스 하드 모드, 타임어택·무피격 기록
- 엔드콘텐츠: 균열 열쇠 + 변이 규칙
