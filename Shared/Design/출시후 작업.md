# 출시 후 작업 (2026-10-05 기준)

앱 출시 이후에야 할 수 있거나, 실제 유저·트래픽이 있어야 판단할 수 있는 작업만 모았다.
출시 전에 끝낼 것은 `출시전 작업.md`, 서버 처리 방법은 `뒤끝서버시스템_설계.md` 를 본다.

## 결제·수익화

스토어에 등록된 상품·광고 단위가 있어야 연동하고 검증할 수 있다.

### 인앱 결제 + 영수증 검증
- 지금(임시)
  - 현금(Cash) 가격 상품은 검증 없이 통과해 보상을 지급한다 — `Function_Shop.trySpendPrice` 의 `PriceType.Cash`
  - 히어로패스는 결제 없이 구매 처리된다 — `Function_Shop.buyHeroPass`(ShopBuy 의 `GoodsType.HeroPass` 분기), 클라 `ShopPresenter.requestHeroPass`
- 할 일: 스토어 영수증을 서버에서 검증한 뒤 지급하도록 두 경로를 교체한다

### 광고 SDK + 시청 검증
- 지금(임시)
  - 광고(Ad) 가격 상품은 검증 없이 통과한다 — `Function_Shop.trySpendPrice` 의 `PriceType.Ad`
  - 광고 제거(NoAd) 상품은 구매 횟수만 `USER_SHOP` 에 남고 효과가 없다
- 할 일: 광고 SDK 연동, 시청 완료 검증, NoAd 효과 구현

### 스토어 업로드 뒤 서명 키 등록
- 스토어에 올리면 Play 앱 서명 키로 다시 서명된다. 그 키의 SHA-1 을 구글 클라우드 콘솔에 Android 클라이언트로 추가해야 스토어 빌드에서 구글 로그인이 된다(`출시전 작업.md` 의 구글 로그인 절)

### 웹 구매 지급
- 외부에서 뒤끝 우편을 보내는 API 가 문서에 없다
- 할 일: 결제 웹훅을 받는 별도 서버를 두거나, 콘솔 개별 발송(수동)으로 처리한다

## 운영

실제 유저와 트래픽이 있어야 판단할 수 있다.

- **펑션 호출량 실측과 `FieldSettle` 주기 재조정**
  - 뒤끝 요금은 호출 수 기준이다(월 50,000회 무료, 이후 1회당 $0.0000333)
  - `FieldSettle` 20초 주기가 호출의 대부분이다(유저 1명 1시간 사냥 = 180회)
  - 출시 전 1차 점검은 `출시전 작업.md` 에 있다. 여기서는 실측 값으로 다시 맞춘다
- **비속어·금칙어 목록 보강** — 신고·운영 중 발견되는 단어를 `BanWord.xlsx` 에 추가하고, 오탐으로 뺀 단어 목록을 다시 본다
- **리더보드 항목 정리** — 항목 삭제는 콘솔에서만 된다(탈퇴·제재 계정)
- **서버 거절 사유별 안내 문구 확장** — 지금은 "부족"과 공통 문구 두 가지뿐이다(`NetworkMessages`). 실제로 자주 나오는 사유를 보고 늘린다

## 한계 보강 (선택)

- **재전송 중복 방지의 남은 틈** — 핸들러가 저장을 끝낸 직후 요청 번호를 기록하기 전에 펑션이 죽으면 재전송이 한 번 더 반영된다. 막으려면 번호 기록을 각 핸들러의 트랜잭션에 넣는다(`Function_Request.cs` `RequestOps`)
- **클라 값을 신뢰하는 항목**
  - 미궁 상자 등급
  - 필드보스가 실제로 어느 필드에 배치됐는지
  - 퀘스트 처치 카운터
- **히어로패스 경험치 지연** — 드랍이 바닥에 남은 처치는 최대 60초까지 서버 경험치에 반영되지 않는다. 그 사이 막 오른 레벨을 수령하면 거절될 수 있다
