Google 로그인 Google Cloud Console OAuth 클라이언트 ID (Android / iOS / Web) 무료 구글 계정만 Play Console 등록 $25 (1회) — 스토어 출시·구글 결제 시
Apple 로그인 Apple Developer Program → App ID + Sign in with Apple Key $99 / 년 테스트에도 필요 같은 멤버십으로 출시 커버
Facebook 로그인 Facebook for Developers → 앱 생성 (App ID / Secret) 무료 —
핵심: 구글 로그인만이면 유료 "개발자 계정"은 필요 없습니다(무료 OAuth로 충분).
유료가 필요한 시점 → ① 구글 스토어 출시/결제: Play Console $25(1회) · ② 애플 로그인: Apple Developer $99/년.
권장 진행 순서: 외부 계정 발급은 심사·대기가 있으니 먼저 시작하세요. 그 사이 유니티 측은 디바이스(게스트) 로그인으로 데이터 저장(BackndRepository)을 먼저 검증할 수 있습니다 — 외부 계정 없이 가능.
G
Google 로그인 설정
console.cloud.google.com
  • Google Cloud Console → 새 프로젝트 생성
  • OAuth 동의 화면 구성 (앱 이름, 지원 이메일, 게시 상태)
  • 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 를 유형별로 발급:
클라이언트 유형입력 값용도
Android패키지명 + 서명 인증서 SHA-1안드로이드 기기 로그인
iOS번들 IDiOS 기기 로그인
웹 애플리케이션—서버 검증용 (Backnd 필수) — Web Client ID
SHA-1 은 빌드에 쓰는 키스토어마다 다릅니다. 디버그 키 SHA-1(개발용)과 릴리즈/Play 앱 서명 SHA-1(출시용)을 모두 등록해야 합니다.
디버그 SHA-1: keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android
Backnd 콘솔에 등록할 값: Web Client ID (서버 검증용). Android/iOS Client ID 는 각 플랫폼 빌드 설정/플러그인에 사용.
A
Apple 로그인 설정
developer.apple.com
  • Apple Developer Program 가입 ($99/년) — Sign in with Apple 은 유료 멤버십 필수
  • Identifiers → App ID 생성, Sign In with Apple capability 활성화
  • Identifiers → Services ID 생성 (웹/서버 검증용 식별자)
  • Keys → 새 키 생성, Sign in with Apple 선택 → .p8 키 파일 다운로드 (재발급 불가, 안전 보관)
  • Team ID, Key ID, Bundle ID 기록
Backnd 콘솔에 등록출처
Team IDMembership 페이지
Key ID + .p8 Private KeyKeys 에서 생성
Bundle ID / Service IDIdentifiers
.p8 키는 다운로드 1회만 가능합니다. 분실 시 키를 폐기하고 새로 만들어야 합니다.
F
Facebook 로그인 설정
developers.facebook.com
  • Facebook for Developers 가입 (무료) → 개발자 계정 등록
  • 앱 만들기 → 유형 "게임" 또는 "소비자" 선택
  • 제품에서 Facebook 로그인 추가
  • 설정 → 기본 에서 App ID 와 App Secret 확인
  • Android: 패키지명 + 키 해시(Key Hash), iOS: 번들 ID 등록
  • OAuth 리디렉트 URI 에 Backnd 가 안내하는 콜백 URL 추가
Backnd 콘솔에 등록출처
App ID설정 → 기본
App Secret설정 → 기본 (표시 버튼)
실제 유저 대상 출시 전에는 앱을 "라이브" 모드로 전환하고 앱 검수(App Review)에서 public_profile 권한을 확인해야 합니다. 개발 중에는 테스터 계정으로 동작.
4
뒤끝 콘솔에 등록 + 데이터 테이블
console.thebackend.io

소셜 로그인 provider 등록

  • 콘솔 → 가입 인증 → 소셜 로그인(또는 외부 인증) 메뉴
  • Google: Web Client ID 입력
  • Apple: Team ID / Key ID / .p8 / Bundle(Service) ID 입력
  • Facebook: App ID / App Secret 입력

GameInfo 데이터 테이블 (데이터 레이어용)

클라이언트 저장 key 와 정확히 같은 이름으로 테이블 생성. BackndRepository 가 이 테이블에 읽고 쓴다.

테이블명저장 내용
character보유 캐릭터/레벨/장착
inventory아이템/강화 레벨
skill스킬 목록
currency재화 잔액
컬럼은 data(String, JSON 통째 저장) 1개면 충분. 유니티 JsonUtility 직렬화 문자열을 그대로 보관.

전체 순서 요약
이 순서로 진행
  1. (병렬 시작) Apple Developer $99/년 가입 — 심사 대기가 가장 김
  2. Google Cloud → OAuth 클라이언트 ID 3종(Android/iOS/Web) 발급
  3. Facebook for Developers → 앱 생성 → App ID/Secret
  4. 뒤끝 콘솔 → 소셜 로그인 3종 등록
  5. 뒤끝 콘솔 → GameInfo 테이블 4개 생성(character/inventory/skill/currency)
  6. (유니티) 디바이스 로그인 + BackndRepository 로 데이터 저장/로드 먼저 검증
  7. (유니티) 소셜 SDK(Google/Apple/Facebook) 설치 후 로그인부 교체
