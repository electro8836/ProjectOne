1
프로젝트 생성
뒤끝 콘솔 → https://console.thebackend.io
  • 회원가입 후 새 프로젝트 만들기 클릭
  • 프로젝트 이름: ProjectOne (임의 지정 가능)
  • 서버 지역: 한국(Seoul) 선택
  • 생성 완료 후 앱 ID와 Client App ID 복사해 둘 것
클라이언트 코드에서 Backend.Initialize() 호출 시 Client App ID가 필요합니다.
2
소셜 로그인 설정
콘솔 → 프로젝트 설정 → 소셜 로그인
플랫폼 설정 항목 값 출처 상태
Google OAuth 클라이언트 ID (Android), OAuth 클라이언트 ID (iOS), Web Client ID Google Cloud Console → 사용자 인증 정보 필수
Apple Team ID, Key ID, Private Key (.p8), Bundle ID Apple Developer → Certificates → Keys 필수
구글 OAuth는 Android용과 iOS용을 각각 발급받아야 합니다.
Web Client ID는 서버-서버 검증에 사용되므로 반드시 입력.
3
GameInfo 테이블 생성
콘솔 → 유저 → GameInfo → 테이블 추가

각 유저의 게임 데이터(캐릭터·인벤토리·스킬·재화)를 저장하는 테이블입니다.
테이블명은 클라이언트 코드의 key와 정확히 일치해야 합니다.

테이블명저장 내용비고
character캐릭터 소유 목록, 레벨, 경험치, 장착 프리셋CharacterData JSON
inventory아이템 소유 목록, 강화 레벨InventoryData JSON
skill스킬카드 소유 목록SkillData JSON
currency재화 잔액 (Gold, Dia, 티켓류)CurrencyData JSON
각 테이블의 컬럼은 data (String, JSON 통째로 저장) 1개면 충분합니다.
뒤끝 함수에서 개별 필드 업데이트가 필요하면 컬럼을 추가해도 됩니다.
4
뒤끝 함수 (서버 권위 연산)
콘솔 → 뒤끝 함수 → 함수 추가

뽑기·보상·강화처럼 클라이언트가 확률을 조작할 수 없어야 하는 연산은 뒤끝 함수로 처리합니다.

함수명역할상태
claimDungeonReward 던전 클리어 보상 계산, 인벤토리/재화/경험치 저장 후 반환 필수
drawSkillCard 스킬카드 뽑기 확률 계산, 재화 차감, 스킬 지급 필수
enchant 장비 강화 확률 롤, 재화/재료 차감, 강화 레벨 저장 필수
craft 아이템 제작 재료 검증, 차감, 결과 아이템 지급 필수
함수 코드는 Node.js (JavaScript) 로 작성합니다.
각 함수 안에서 Backend.GameInfo API로 유저 데이터를 읽고 저장해야 합니다. 
// drawSkillCard 함수 예시 구조
exports.handler = async (event) => {
  const { inDate, drawCount } = event.param;

  // 1. 재화 조회 및 차감 검증
  // 2. 확률 테이블 조회 (Chart / 뒤끝 차트)
  // 3. 뽑기 결과 계산 + 천장(pity) 처리
  // 4. SkillData 갱신 저장
  // 5. 결과 반환
  return { grantedSkillIds: [...], skill: {...}, currency: {...} };
};
5
뽑기 확률 차트 / 출석 / 우편 설정
콘솔 내장 기능 활용

뒤끝 차트 (뽑기 확률표)

  • 콘솔 → 차트 → 차트 추가: GachaPool_Skill
  • 컬럼 구성: skillId (int), probability (float), grade (int)
  • 뒤끝 함수 내에서 Backend.Chart.GetChartContents("GachaPool_Skill") 로 조회

출석 이벤트

  • 콘솔 → 출석 → 출석 이벤트 추가
  • 출석 기간, 보상 아이템 ID/수량 설정
  • 클라이언트: Backend.Attendance.GetAttendanceList() → Backend.Attendance.AttendanceCheck()

우편

  • 콘솔 → 우편 → 일반 우편 발송 (공지, 보상 지급 등)
  • 클라이언트: Backend.UPost.GetPostList() → Backend.UPost.ReceivePostItem()
  • 보상 아이템은 클라에서 수령 후 Inventory.Add() / CurrencyManager.Add() 로 직접 반영
6
인앱결제 설정
Google Play Console / App Store Connect + 뒤끝 영수증 검증
단계위치작업상태
① Google Play Console 앱 등록, 인앱 상품 ID 생성, 서비스 계정 JSON 키 발급 필수
② App Store Connect 앱 등록, 인앱 상품 ID 생성, Shared Secret 발급 필수
③ 뒤끝 콘솔 → 인앱결제 Google 서비스 계정 JSON 등록, Apple Shared Secret 등록 필수
④ 뒤끝 콘솔 → 상품 관리 상품 ID, 상품명, 지급 재화/아이템 설정 필수
⑤ Unity IAP 패키지 Package Manager에서 설치, 상품 ID 등록 필수
결제 흐름: Unity IAP 구매 완료 → 영수증 수신 → Backend.Receipt.IsValidateGooglePurchase() / IsValidateApplePurchase() → 검증 성공 시 재화 지급.
인앱결제 상품은 실제 앱이 스토어에 등록된 이후에만 테스트 가능합니다.
개발 중에는 Unity IAP Test Mode를 사용하세요.
7
SDK Unity 설치
뒤끝 SDK + 소셜 로그인 SDK
패키지설치 방법상태
뒤끝 SDK 뒤끝 콘솔 → SDK 다운로드 → .unitypackage 임포트 필수
Google Sign-In com.google.external-dependency-manager + Google Sign-In Unity Plugin 필수
Apple Sign In with Unity Package Manager → com.lupidan.apple-signin-unity 필수
Unity IAP Package Manager → In App Purchasing 인앱결제 단계
구글 로그인 플러그인은 External Dependency Manager(EDM4U)가 필수입니다.
임포트 후 Assets → External Dependency Manager → Android Resolver → Resolve 실행 필요.

전체 작업 순서 요약
이 순서대로 진행하면 막힘 없음
  1. 뒤끝 콘솔 → 프로젝트 생성 → Client App ID 복사
  2. 뒤끝 SDK + Google Sign-In + Apple Sign-In 패키지 Unity 설치
  3. Google Cloud Console → OAuth 클라이언트 ID 발급 → 뒤끝 콘솔 등록
  4. Apple Developer → Sign In with Apple Key 발급 → 뒤끝 콘솔 등록
  5. GameInfo 테이블 4개 생성: character / inventory / skill / currency
  6. 뒤끝 차트 생성: GachaPool_Skill
  7. 뒤끝 함수 4개 작성: claimDungeonReward / drawSkillCard / enchant / craft
  8. 출석 이벤트, 우편 설정
  9. Google Play / App Store 앱 등록 → 인앱결제 상품 ID 생성 → 뒤끝 연동
