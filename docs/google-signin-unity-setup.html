Google Sign-In 플러그인 설치 & 설정

Unity + Backnd 페데레이션 로그인 · 웹 클라이언트 ID 준비 완료 기준 · 2026-06-18

Google Sign-In 플러그인 → idToken 획득 → Backend.BMember.AuthorizeFederation → 뒤끝 로그인
전제: 구글 클라우드에 웹 클라이언트 ID(완료) + Android 클라이언트 ID(패키지명+SHA-1)가 같은 프로젝트에 존재해야 합니다. 웹 ID는 Backnd 콘솔 등록 + 아래 WebClientId 에, Android ID는 "존재만" 하면 됩니다.
1
플러그인 설치
Google Sign-In Plugin for Unity
  • google-signin-unity 릴리스에서 GoogleSignIn-*.unitypackage 다운로드 (github.com/googlesamples/google-signin-unity)
  • Unity → Assets → Import Package → Custom Package 로 임포트
  • 함께 들어오는 External Dependency Manager (EDM4U) 도 같이 임포트 (이미 있으면 최신 유지)
이 플러그인이 Android 의 play-services-auth, iOS 의 GoogleSignIn 네이티브를 끌어와 idToken 발급을 담당합니다.
2
의존성 Resolve (Android)
EDM4U Android Resolver
  • Assets → External Dependency Manager → Android Resolver → Resolve 실행
  • Plugins/Android 에 play-services-auth 관련 aar 들이 받아지는지 확인
  • Player Settings → Custom Main Gradle Template / Custom Gradle Properties 활성화 권장
Resolve 가 실패하면 대부분 JDK/Android SDK 경로 또는 Gradle 문제입니다. Unity → Preferences → External Tools 경로 확인.
3
플랫폼 설정
패키지명 / SHA-1 / iOS URL Scheme
플랫폼설정
Android Player Settings 의 패키지명 = 구글 콘솔 Android 클라이언트의 패키지명 일치. 빌드 키스토어의 SHA-1 이 구글 콘솔에 등록돼 있어야 함(디버그/릴리스 둘 다).
iOS iOS 클라이언트 ID 필요. Info.plist 에 역방향 클라이언트 ID(REVERSED_CLIENT_ID)를 URL Scheme 으로 추가.
디버그 SHA-1: keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android
출시 시엔 Play 앱 서명 SHA-1(Play Console 발급)도 추가 등록.
4
코드 설정값 (참고)
유니티 코드는 이쪽에서 작성 — 웹 클라이언트 ID 만 넣으면 됨

플러그인 설치/Resolve 가 끝나면, 페데레이션 로그인 코드는 제가 작성합니다. 핵심은 WebClientId 에 웹 클라이언트 ID 를 넣고 RequestIdToken = true 로 idToken 을 받는 것: 

// 설정 — 웹 클라이언트 ID 사용 (Android/iOS 클라이언트 ID 아님!)
GoogleSignIn.Configuration = new GoogleSignInConfiguration {
    WebClientId = "627792620661-...apps.googleusercontent.com",
    RequestIdToken = true,
    UseGameSignIn = false
};

// 로그인 → idToken 획득 → 뒤끝으로 전달
// GoogleSignIn.DefaultInstance.SignIn() → user.IdToken
// Backend.BMember.AuthorizeFederation(idToken, FederationType.Google, ...)
반드시 WebClientId 에 "웹 애플리케이션" 타입 ID 를 넣습니다. Android/iOS 타입 ID 를 넣으면 idToken audience 가 안 맞아 Backnd 검증이 실패합니다.
✓
진행 순서
  1. Backnd 콘솔 → 소셜 로그인 Google 에 웹 클라이언트 ID 등록
  2. 구글 콘솔에 Android 클라이언트 ID(패키지명+SHA-1) 추가
  3. Google Sign-In 플러그인 임포트 + EDM Resolve
  4. 패키지명/SHA-1/iOS URL Scheme 설정
  5. (코드) 페데레이션 로그인 작성 — BackndInitializer 에 구글 로그인 추가
1~4 가 끝나면 알려주세요. BackndInitializer 에 구글 로그인 메서드 + idToken→AuthorizeFederation 코드를 바로 작성합니다.
